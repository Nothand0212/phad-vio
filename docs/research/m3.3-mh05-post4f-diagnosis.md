## 2. 关键发现

### 2.1 ④f 已消化 ④c/④e 的灾难形态，且 ATE 优于 ④b

- 相对 ④e：**4.565 → 3.057**（Δ≈−1.51）；`drops_skipped=1` 落在 i=425 大剔。
- 相对 ④b：**3.449 → 3.057**（④f 更好，不是「回到 ④b 还差一截」）。
- ④e 的 i=430–438「高 RMS 5–9 px / `culled=0`」平台在 ④f **消失**
  （④f 全 run `reproj_after>2 ∧ culled==0` 仅 i=426、i=1498 两帧）。

结论：④f skip-drop 对症了前序主因；剩余债是 **新的 / 更淡的** 形态，
不是「④e 平台还在」。

### 2.2 原始轨迹：至 i=426 与 ④b 逐字节相同

`est.tum` / `diag` 关键字段在 **i≤426 完全一致**（含 i=425 大剔 24 +
reopt，`after_cull=0.18`；i=426 `shared=13` / `obs=68`）。  
首个位姿差在 **diag i=427**（tum index 422；Δxyz ≈ 0.23 m）。

因此：对齐后「前段 ATE 就差一截」是 **全局 SE3 被后半段带偏** 的假象
（pre-425 的 `err_4b−err_4f` 均值 ≈0.67、标准差 ≈0.01，近乎常数偏移）。

要点：

   **各少约 16**（与大剔规模同量级），`obs` 仍相同 → 不是前端观测条数变少，
   而是 **可入图 / 可共享的 landmark 集合变稀**。
2. i=429 两侧都撞 `lm_iterations=100`；④f `max_window_pose_shift_m≈2.94`，

3. ④b 独有 i=436 二次大剔+reopt；④f 无。但 ④f **全程 ATE 更好** →
   「复现 ④b 二次自救」**不是**逼近 &lt;1 m 的充分目标。

### 2.4 高 ATE ≠ 高重投影（剩余形态）

④f 上 `err_trans>3` 且 `culled==0`：**485 / 2216**；这些帧
`reproj_after` 中位 **0.30**、最大 **0.62**（**无** &gt;2 px）。  
→ 剩余是 **自洽但偏了的轨迹**，不是「满图外点残差待 cull」。

shared 缺口在 i≈451 后基本愈合（451–2200 两侧 shared/landmarks 均值接近），
但误差平台已锁在 ~2–3 m。

## 3. 假说检验

| 假说 | 判定 | 证据 |
|---|---|---|
| 末轮 Huber 遮罩外点（作首选刀） | **反对** | 高 ATE 帧 reproj 已很低；无「被压低却不 cull」的高残差平台 |
| mean-cull 盲区 → 观测级 / max（作首选） | **反对** | ④e 式高 RMS/`culled≈0` 平台在 ④f 已消失；仅偶发单帧 |
| skip-drop 后仍丢二次自救（作首选） | **反对** | ④f 无 i=436 大剔，但 ATE **优于**有二次自救的 ④b；缺二次爆炸是更健康路径的伴随现象 |
| 前端跟踪 / PnP 外点（非 estimator cull） | **部分 / 不足** | i=427 `pnp_inliers` 10 vs 26 支持连通变稀；但 `obs` 相同、后续 shared 愈合，18 列无法判定是 zombie-track、block 拒复生，还是 PnP 误匹配 |
| 再拧 `max_outlier_reopts` | **否决** | ④f 仅 1 次 `culled≥4`；无第二轮触发前提 |
| **慢性自洽漂移在 i=429 锁定**（主剩余形态） | **支持（形态）** | 位姿至 426 相同；427 shared 腰斩；429 lm 封顶 + shift≈2.9 m + err 跳到 ~3 m；此后低 reproj 高 ATE |

## 4. 机制解读（简）

1. i=425：两侧同样大剔 24 + reopt；④f `drops_skipped=1` 避免 ④c/④e
   「凡大剔必 drop」导致的高 RMS 平台 → 软门达成。  
2. i=426：仍与 ④b 相同（skip-drop 把路径接到 ④b 一侧）。  
3. i=427+：在 **保持 `block_culled_rebirth`** 的前提下，④f 的可用
   shared/landmarks 相对 ④b 腰斩（疑为「保留被 cull 的 track + 拒复生」
   与 ④b「drop 后重新建点」的差异，**未直接证实**）。  
4. i=429：窗口大位移 + LM 封顶，误差跳到 ~3 m 后以低 reproj 自洽运行。  
5. 外点剔除族对 MH_05 **灾难发散** 的杠杆已基本用尽；逼近 &lt;1 m 需要
   能解释 i=427–429 锁定的新证据，而不是再加一道 mean-cull 变体。

## 5. 结论（出口）

### 唯一推荐下一刀

**升级探针 B（慢性漂移 / i=427–429 锁定归因）** — 现有 18 列 `diag.csv`
足够 **否决**「去 Huber / 观测级 / 再拧 reopts / 追 ④b 二次大剔」作首选，
但 **不足以** 在机制层点名该改 `block`、精确 drop、shift 门还是别的。

B 清单（最小集，仍只读 / 诊断开关优先）：

1. **i=425 被 cull 的 landmark id** 在 426–450 是否仍出现在前端 track、
   是否被 estimator 拒观测（zombie-track × `block_culled_rebirth`）。  
2. **i=427–429** 每帧新增 / 拒绝 / 共享 landmark 计数；对照 ④b 同窗。  
3. **i=429** 优化前后窗口位姿位移分解（哪几帧、哪几点拉飞）与
   per-landmark 残差（mean vs max）；仅当残差直方图支持时，才把
   「末轮去 Huber」升回候选。  
4. （可选）滑动窗局部 Umeyama 尺度，排除纯尺度漂为唯一主因。

机制片编号（④g+）**等 B 或等价 A/B 出数后再开**；本片不占号。

### 否决项（本轮不打）

| 项 | 原因 |
|---|---|
| 单独「末轮去 Huber」 | 无遮罩平台；高 ATE 帧 reproj 已低 |
| 单独观测级 / max 判据 | ④f 已无高 RMS/`culled≈0` 平台 |
| 再拧 `max_outlier_reopts` | 无第二次 `culled≥4` |
| 以「复现 ④b i=436 二次大剔」为硬目标 | ④f 已更优；路径不应往爆炸上靠 |
| 直接开 Slice ⑤ | 与 M4 耦合；MH_05 剩余形态未归因 |
| 无新证据改默认阈值蒙混过 &lt;1 m | 与前序债纪律一致 |
