## 1. 唯一问题

B5 的 activation held-out gate 只证明：当前 alignment 对未来视觉位移的 one-step
disagreement RMS 为 `1.901 mm`，validation ratio=`0.5510`。进入 full graph 后，标准
`ImuFactor` 却只消费由 IMU white noise 与 numerical integration covariance 传播出的
`preintMeasCov()`。

MH_01 factor-cost probe 观测到：

- newest IMU initial `|dP|` median=`3.995 mm`，与 held-out disagreement 同量级；
- newest IMU initial cost median=`15046.1`，而全部 stereo initial cost median
  只有 `122.1`；
- optimizer 把 `|dP|` 压到 median=`0.610 um`；
- posterior 相对 graph visual/PnP initial 的位移修正 median=`3.490 mm`，与
  newest `|dP|` correlation=`0.956`；
- B5 full suffix ATE/RPE=`0.279138/0.022456 m`，paired VO 为
  `0.079058/0.020864 m`。

本探针只回答：**把 activation 已实测、但 raw PIM covariance 未表达的模型一致性
误差加入 full factor covariance，能否让 MH_01 VIO ATE/RPE 同时严格优于 paired
VO？**

## 2. 一手合同与工程边界

固定 GTSAM revision
[`2f3e56c`](https://github.com/borglab/gtsam/tree/2f3e56c0ddbd3a1aa54ed043643b553d26a069f6)：

1. `PreintegratedImuMeasurements` 的 covariance 顺序是 rotation、position、velocity；
   `integrateMeasurement()` 按 Jacobian 传播 accelerometer/gyroscope covariance，并只在
   position block 加 `integrationCovariance * dt`：
   [`ImuFactor.h L73-L87`](https://github.com/borglab/gtsam/blob/2f3e56c0ddbd3a1aa54ed043643b553d26a069f6/gtsam/navigation/ImuFactor.h#L73-L87)、
   [`ImuFactor.cpp L73-L91`](https://github.com/borglab/gtsam/blob/2f3e56c0ddbd3a1aa54ed043643b553d26a069f6/gtsam/navigation/ImuFactor.cpp#L73-L91)；
2. `ImuFactor` 默认直接以 `preintMeasCov()` 构造 Gaussian noise：
   [`ImuFactor.h L214-L225`](https://github.com/borglab/gtsam/blob/2f3e56c0ddbd3a1aa54ed043643b553d26a069f6/gtsam/navigation/ImuFactor.h#L214-L225)；
3. `NoiseModelFactor::cloneWithNewNoiseModel()` 会保留具体 factor/residual，只替换
   noise model：
   [`NonlinearFactor.h L297-L306`](https://github.com/borglab/gtsam/blob/2f3e56c0ddbd3a1aa54ed043643b553d26a069f6/gtsam/nonlinear/NonlinearFactor.h#L297-L306)、
   [`NonlinearFactor.cpp L91-L96`](https://github.com/borglab/gtsam/blob/2f3e56c0ddbd3a1aa54ed043643b553d26a069f6/gtsam/nonlinear/NonlinearFactor.cpp#L91-L96)；
4. Forster 等人的 preintegration 模型对 measurement noise 做一阶传播，并保留 bias
   correction；它不声称传感器 white-noise covariance 能覆盖视觉、离散模型、同步与
   calibration 的全部 disagreement：
   [RSS 2015 paper](https://www.roboticsproceedings.org/rss11/p06.html)、
   [supplement](https://repository.gatech.edu/entities/publication/654569e1-92c3-4c2d-b39c-3d381119b153)。

这里新增的是 **effective cross-sensor/model discrepancy**，不是改写 EuRoC sensor
noise 标定。它含 visual disagreement，不能报告为 IMU measurement covariance，也不
能证明概率模型已完成标定。已有 B4 对 gyro alignment residual 的 9 点 scale sweep
没有 MH_01 双门甜区，所以本探针固定 amplitude=`1`，不恢复 scale knob。

## 3. 最小数据流

alignment 已产生但当前未保存的 `inertial_visual_rms_m` 在 activation transaction
中写入 estimator state。每条 full edge 仍按原样重建同一个 PIM，再生成：

```text
C_eff = C_pim + diag(v_R I3, v_P I3, v_V I3)

v_R = gyro_alignment_residual_rms_rad^2 / 3
v_P = imu_alignment_residual_rms_m^2 / 3
v_V = v_P / delta_t_ij^2
```

其中：

- `/3` 把 3D residual norm RMS 转成各轴 isotropic variance；
- `v_R` 延续 full activation 前 `PoseAhrsFactor` 已消费的同一 rotation consistency
  scale，避免 mode switch 把 rotation 突然恢复成 raw sensor-only confidence；
- held-out 视觉位姿没有独立 endpoint velocity truth，`v_V` 只把同一个 position
  discrepancy 换算到该 edge 的速度尺度，不伪造第二份观测；
- `C_pim` 的 off-diagonal/cross-block 原样保留，只加 PSD diagonal；
- residual、keys、PIM bias correction 与 prediction 全部不变。

实现直接构造标准 `gtsam::ImuFactor`，再调用 `cloneWithNewNoiseModel()`；不新增 factor
subclass、CLI/config knob 或双 production 路径。factor-cost helper 仍能通过
`dynamic_cast<gtsam::ImuFactor>` 识别它。

## 4. 状态、错误与诊断

新增 estimator-private state：

- `imu_alignment_residual_rms_m`；

并在 `UpdateDiagnostics`/`vio_state.csv` 暴露：

- activation 的 `imu_alignment_residual_rms_m`；
- full row 实际使用的 newest edge `rotation/position/velocity` consistency sigma
  （标准差，不是 variance）。

transaction 规则：

- alignment accepted 时与 `g_W/ba/V` 同时提交 RMS；
- rejected/pending 不更新；demotion 清零；rollback 恢复；
- full graph 要求 RMS finite、`>=0`，edge `dt>0`，`C_eff` finite/symmetric；Gaussian
  noise 构造异常沿现有 graph-build `kFailed` 返回，不能回退 raw covariance；
- IMU-off/vision/gyro row 的 full consistency diagnostics 不存在，不写假有效值。

## 5. 测试先行

先写红测试，再实现：

1. 纯 helper：给定含 off-diagonal 的 `C_pim`、两个 RMS 与 `dt`，只增加指定三个

   noise covariance 等于公式；newest diagnostics 等于实际 covariance 增量；
4. activation 下一帧才消费新 covariance；alignment pending/rejected、gap demotion 与
   failed update 均遵守 transaction；
5. `vio_state.csv` schema/value/missing/nonfinite 合同；
6. 定向 tests、完整 unit、Python probes 与 `git diff --check`。

## 9. 决策

该臂违反全程与 full suffix 的 ATE/RPE 四个严格门，结论为**否决**：

- 不运行 MH_05；
- 不扫 covariance amplitude、sensor noise、prior 或 bias；
- production graph 恢复标准 `ImuFactor` 的 raw PIM covariance；
- 保留 alignment held-out RMS、factor-cost 与 Python sidecar 修复，作为后续只读证据；
- 下一步先量化 frozen prefix 与 full suffix 的对齐相位差，再设计 no-write
  transition/window-history shadow，不能把“过置信已解除”等同于“VIO 已优于 VO”。

本结果只否决当前 effective covariance 公式；它不证明 raw covariance 正确，也不证明
窗口历史或 activation transition 无问题。M4.4 仍未完成。
