## 1. 目标与非目标

**唯一目标**：在保持 `block_culled_rebirth=true` 的前提下，用可配置的
「`outliers_culled ≥ N` 时跳过本帧 `dropTracks`」消化 MH_05 上 ④c「凡 cull
必 drop」导致的回归（默认 ATE 4.565 → A/B no_drop ≈ 3.97）；MH_01 不劣于
锚 **0.098784** m（`seg/re=1/0`）。

不做：

- 改 `block_culled_rebirth` 默认；生产路径双关（no drop ∧ no block）；
- 延迟 drop / TrackId≠LandmarkId 拆分；
- 观测级外点、末轮去 Huber、改 mean-cull 默认阈值；
- Slice ⑤、IMU、边缘化、改 `phad::eval`；
- 扩 `diag.csv`（仍 **18** 列）。

## 2. 已对齐的决策

| 决策点 | 结论 |
|---|---|
| 主形态 | 大剔跳过 drop；小剔仍 drop；block 始终默认 true |
| 判据 | **`outliers_culled`（仅 mean-cull）** ≥ N；不用 `culled_landmark_ids.size()` |
| N | `session.skip_drop_min_culled` 默认 **4**；进 `config_hash`；`0` = 不跳过 |
| 与 bool 叠 | 两级门：先 `drop_culled_tracks`；再比 N（见 §4） |
| 诊断 bool | 保留 `--no-drop-culled-tracks`（永不 drop） |
| estimator / frontend | **不**感知 skip 策略；仍只在 apps session |
| diag | 仍 18 列；跳过 **不**进 warnings |
| summary | `robustness.drops_skipped` = 跳过 drop 的**帧数** |
| 出口 | MH_01 硬门 → MH_05 软门 → 基线；全序列另议 |
| MH_01 | ATE ≤ **0.098784**；seg/re=1/0；期望 `drops_skipped=0` |
| MH_05 | 相对 4.565 明显下降（朝 ~3.97）；`drops_skipped≥1`；不硬门 &lt;1 m |
| Slice ⑤ | 不开 |
| 票务 | 续 [#24](https://github.com/Nothand0212/phad-vio/issues/24)；称 **Slice ④f** |

### A/B 证据摘要

| 实验 | 结果 |
|---|---|
| 只关 block | MH_05 tum 与默认 identical；无效 |
| 只关 drop | ATE **4.565→3.972**；无二次大剔但仍软改善 |
| 双关 | ATE **35.7**、failed=498；禁止 |
| no_drop+T=3 | 相对 no_drop+T=4 持平；T 非剩余杠杆 |
| MH_01 cull 直方图 | 仅 size=1 → 默认 N=4 不改变 MH_01 drop 行为 |
| MH_05 cull 直方图 | 一大剔 24 + 若干 1 → N=4 只跳过大剔 |

### 新选项

```cpp
struct OfflineVoSessionOptions
{
  // …既有…
  bool drop_culled_tracks     = true;
  int  skip_drop_min_culled   = 4;  // ≥0；0 → 关闭「大剔跳过」
};

struct FrameCounts
{
  // …既有…
  std::uint64_t drops_skipped = 0;  // 因 outliers_culled ≥ N 跳过 drop 的帧数
};
```

CLI：

```text
phad_vo_bench … [--no-drop-culled-tracks] [--skip-drop-min-culled <n>]
```

- `--skip-drop-min-culled` 须 `≥ 0`；非法 → 非 0 退出
- 两键进 `flattenConfig` → `config_hash`

## 3. 模块边界

```text
apps/offline_vo_session
  drop_culled_tracks + skip_drop_min_culled
  update 后两级门 → 可选 dropTracks；累计 drops_skipped
apps/phad_vo_bench
  CLI + flattenConfig + summary.robustness.drops_skipped
phad::bench run_summary
  RobustnessCounters / JSON 增加 drops_skipped
tests/apps …
docs：本设计；基线节；roadmap；AGENTS
```

| 允许 | 禁止 |
|---|---|
| apps → frontend `dropTracks` | estimator → frontend |
| session 读 `UpdateDiagnostics.outliers_culled` | frontend 知道 N / skip 策略 |

## 4. 数据流

```text
estimator.update → diagnostics.{outliers_culled, culled_landmark_ids}
        ↓
session:
  if drop_culled_tracks
     && !culled_landmark_ids.empty()
     && (skip_drop_min_culled == 0
         || outliers_culled < skip_drop_min_culled)
        dropTracks(culled_landmark_ids)
  else if drop_culled_tracks
     && !culled_landmark_ids.empty()
     && skip_drop_min_culled > 0
     && outliers_culled >= skip_drop_min_culled
        ++drops_skipped   // 本帧跳过
  // drop_culled_tracks=false → 永不 drop（不计入 drops_skipped）
```

等价伪代码：

```cpp
if ( options.drop_culled_tracks && !ids.empty() )
{
  const bool skip =
      options.skip_drop_min_culled > 0 &&
      update.diagnostics.outliers_culled >=
          static_cast<std::uint32_t>( options.skip_drop_min_culled );
  if ( skip )
  {
    ++result.counts.drops_skipped;
  }
  else
  {
    tracker.dropTracks( ids );
  }
}
```

不变量：

| 项 | 规则 |
|---|---|
| block | 默认 true；本片不改 |
| 列表 | 仍含 mean-cull ∪ cheirality；skip 时整表不 drop |
| `outliers_culled` | 语义不变（不含 cheirality） |
| N=0 | 与「凡非空列表必 drop」的 ④c 行为一致（在 drop bool 为 true 时） |

## 5. 错误与诊断

- CLI：`skip_drop_min_culled < 0` → 非 0 退出  
- 跳过 drop **不**进 `warnings`  
- probe stdout：打印 `drops_skipped=`  
- `diag.csv` 不追加列  

## 6. 测试与验收

1. 单测：默认 N=4；构造/契约级断言两级门与 `drops_skipped`；N=0 不跳过；非法 CLI（若有解析测）  
2. **MH_01**：默认配置；ATE ≤ 0.098784；seg/re=1/0；`drops_skipped=0`  
3. **MH_05**：ATE 相对 `0ced28b`/`3a21162e` 的 4.565 **明显下降**（朝 ~3.97）；`drops_skipped≥1`；记录 i=425 附近时间线  
4. 通过 → 基线 + roadmap；不够 → 不改默认蒙混；不开 ⑤
