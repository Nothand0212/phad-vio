## 1. 目标与非目标

**唯一目标**：把右目匹配从「无约束的 2D LK + 事后 epipolar 门」改为「沿
epipolar 行、显式视差区间的一维 SAD + 亚像素 + 同行反向一致性」，以降低
`no_right_match` 全局常态、提高每帧 `valid` 观测数，并减少 Slice ① 之后仍偏高的
`reanchors`。

不做：

- 右目时序 track（Basalt / R2）；
- 启用 `last_disp_px` 作 LK 初值（R3；开源无先例）；
- NCC / `matchTemplate` 第二套打分（本片只留实现缝，默认 SAD）；
- ORB 式 SAD 全局中位数批剔；
- 单帧左目 LK 全灭的专门缓解；
- RANSAC/PnP（Slice ③）、chi2 外点（Slice ④）、关键帧（Slice ⑤）；
- 改 `phad::estimator` / `phad::eval` / `FrameTracks` 对外字段契约。

## 2. 已对齐的决策

| 决策点 | 结论 | 依据 |
|---|---|---|
| 主路线 | **R1 一维化** | 开源对照：显式视差范围 + 行约束是 Kimera / ORB-SLAM3 / SVO 多数派；现行 25% `no_right_match` 主因是 2D LK 允许 y 乱漂 |
| 匹配器 | **SAD + 抛物线亚像素**；半宽/行容差可配；本片不做 NCC | 对齐 ORB-SLAM3；NCC 留缝不双轨 |
| 行容差 | 默认 `stereo_row_tol_px = 0`；选项进 `config_hash` 可扫 | 对齐 Kimera 默认只搜同行；余量用配置而非默认放宽 |
| 事后剔除 | 几何门 + **同行反向一维 SAD**；去掉立体路径上的 FB-LK；不做中位数批剔 | 双向思想贴近 VINS，但形态贴一维模型 |
| 双向阈值 | 新选项 `stereo_bidir_px`（默认 0.5），与时序 `forward_backward_px` 解耦 | 立体与时序可独立扫 |
| SAD 半宽 | `stereo_sad_half_win_px = 5`（11×11） | ORB-SLAM3 `w = 5` |
| 视差记忆 | **删除 `LiveTrack::last_disp_px`** | 字段当前不生效；R1 每帧独立搜索；开源无 per-track 标量视差先例 |
| 搜索区间 | `d ∈ [max(min_disparity_px, fx·b/max_depth), fx·b/min_depth]` | 把已有 depth 门从「事后」提升为「搜索边界」 |
| 对外契约 | `TrackObservation` / 四档 `StereoStatus` / probe CSV 列不变 | estimator 无感 |
| 配置身份 | 三个新 `tracker.stereo_*` 进 `flattenConfig()`，新 `config_hash` | 产物落新目录 |
| MH_01 锚 | ATE 不劣于 0.150155 m，`segments=1` / `reanchors=0`；**不再要求** `est.tum` 逐字节相同 | 匹配器变更必然改观测 |

## 3. 模块边界

不新增库。改动集中在：

```text
phad::frontend   StereoTracker::matchRight  ← 2D LK → 一维 SAD
                 StereoTrackerOptions       ← 三个新字段
                 LiveTrack                  ← 删除 last_disp_px
        ↓
apps/phad_vo_bench                          ← flattenConfig 新 tracker.stereo_*
tests/frontend                              ← 合成场景覆盖新路径
docs                                        ← frontend README + 本设计 + 出口基线
```

左目时序 LK 仍使用 `lk_window_px` / `lk_pyramid_levels` / `forward_backward_px`。
立体路径不再调用 `calcOpticalFlowPyrLK`。

### 新选项

```cpp
struct StereoTrackerOptions
{
  // …既有字段…
  int    stereo_sad_half_win_px = 5;    // SAD 半宽；块边长 2*w+1
  int    stereo_row_tol_px      = 0;    // 行容差；0 = 只搜 y_L
  double stereo_bidir_px        = 0.5;  // 同行反向一维一致性阈值
};
```

## 4. 数据流

`process()` 顺序不变：左目时序 LK → GFTT 补点 → `matchRight()` → 组装
`FrameTracks`。

`matchRight()` 对每个存活左点：

```text
计算视差搜索区间
  d_min = max(min_disparity_px, fx*b/max_depth_m)
  d_max = fx*b/min_depth_m
  若 d_max < d_min → kNoRightMatch

在右图对 y ∈ [y_L - row_tol, y_L + row_tol]、
x ∈ [x_L - d_max, x_L - d_min] 做整数 SAD（半宽 stereo_sad_half_win_px）
  边界不足 / 无合法峰 → kNoRightMatch
  峰贴搜索区间边界 → 放弃（ORB 同款）→ kNoRightMatch

抛物线亚像素修正右 x（δ 超出 ±1 → 弃）→ kNoRightMatch

在同一 best y 上反向一维 SAD，往返误差 > stereo_bidir_px
  → kNoRightMatch
  （不计入 FrameStats.forward_backward_rejected；该字段只表示左目时序 FB）

几何门（顺序与现网一致）
  |y_L - y_R| > max_epipolar_px → kInvalidDisparity
      （row_tol=0 时此项恒过）
  disparity <= min_disparity_px → kInvalidDisparity
  depth ∉ [min_depth_m, max_depth_m] → kDepthOutOfRange
  否则 → kValid，写入 disparity_px
```

要点：

- 每帧独立，无跨帧视差记忆；
- `epipolar_median_px` / `epipolar_p95_px` 仍对进入几何门之前的 `|dy|` 采样；
  `row_tol=0` 时二者应接近 0；
- 实现上可把 SAD 核抽成小函数，便于日后换 NCC，但本片只实现 SAD。

## 5. 错误与诊断

**构造期**（`std::invalid_argument`）：

| 条件 | 要求 |
|---|---|
| `stereo_sad_half_win_px` | ≥ 1 |
| `stereo_row_tol_px` | ≥ 0 |
| `stereo_bidir_px` | > 0 |
| 既有 lk / depth / disparity / epipolar 规则 | 不变 |

**运行时**：四档 `StereoStatus` 语义不变（见上表数据流）。

**可观测性**：

- frontend probe CSV 列不变；主看 `no_right_match_rate` / `valid` / `epipolar_p95_px`；
- 不新增 status 枚举或 CSV 列区分「无峰 vs 反向失败」（避免契约膨胀）；
- `flattenConfig` 追加三个 `tracker.stereo_*`；
- 无新的 per-frame session 日志。

**文档**：更新 `phad/frontend/README.md`（右目匹配算法、删除 `last_disp_px`、新选项）。

## 6. 测试与验收

### 单元测试（`tests/frontend/`）

| 用例 | 断言 |
|---|---|
| 水平平移网格 | 多数 `kValid`，视差 ≈ `fx·b/z`（容差 ~0.75 px） |
| 右点缺失 | `kNoRightMatch`，track 保留 |
| `right_v_offset` 超门且 `row_tol=0` | 失败可观测（`kNoRightMatch` 或 `kInvalidDisparity`） |
| `row_tol` 覆盖小偏移 | 容差内可变为 `kValid` |
| 深度 / 视差门外 | 对应 status |
| 反向一致性失败 | `kNoRightMatch` |
| 非法选项 | 构造抛 `invalid_argument` |
| 既有时序 ID / FB 用例 | 不回归 |

### 真序列（对照 `0b0cd34` / `default_030a0197`）

| 项 | 门控 |
|---|---|
| MH_01 | ATE ≤ 0.150155 m；`segments=1`、`reanchors=0`；**不**要求 `est.tum` 逐字节相同 |
| 主观察 | 全序列 `reanchors` 不增（目标下降）；`no_right_match_rate` 下降、每帧 `valid` 上升 |
| 同等 coverage 健康序列 | ATE 不劣化（如 MH_03/04/05、V1_01） |
| V1_03 / V2_02 / V2_03 | 只记录 `reanchors` / completion |
| 产物 | `docs/research/m3.3-slice2-baseline.md` + 回填 roadmap |

测量：`phad_stereo_frontend_probe` + `phad_vo_bench` + `bench_table.py`。

## 7. 与父设计 / 开源对照的关系

- 父设计第 8 节 Slice ② 边界中的三个「已知洞」经开源对照修订：`last_disp_px`
  种子中毒与「新 track 零种子」在现行代码里**尚未生效**（未置
  `OPTFLOW_USE_INITIAL_FLOW`）；真正主因是无约束 2D 搜索。本片删除该字段而非
  「修好写回顺序」。
- R2 / R3 明确不做；若 Slice ② 出口后 `no_right_match` 仍高，再评估是否开独立
  切片做 Basalt 式右目 track。
