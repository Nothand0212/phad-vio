## 1. 重要前提（对比公平性）

| 维度 | phad-vio ⑤c(30px) | 论文各系统 |
|---|---|---|
| 传感器 | 纯双目 VO（无 IMU） | Stereo 行纯视觉；SI 行有 IMU |
| 回环 | 无 | ORB-SLAM2/3 有回环；VINS-Fusion/OKVIS 等纯里程计 |
| 目标 | 学习型 VIO 实现 | 生产级系统（多年迭代） |
| 数据来源 | 自跑 EuRoC ASL native | 论文作者报告（各系统自报） |

**结论**：phad-vio 是纯视觉里程计（无 IMU、无回环、无地图复用），与
ORB-SLAM2/3（带回环）不在同一能力层级。对比用于**定位当前基线**，不构成
公平竞赛。

## 3. 判读

1. **MH 系列（前 5 条）**：phad-vio 0.063-0.343 m，与 SVO（0.040-0.270）同量级，
   落后 ORB-SLAM2/3 约 5-10 倍。考虑到无回环 + 无 IMU，这是合理的**纯 VO 基线**。
2. **V 系列**：V1_02/V1_03/V2_03 显著差（2.6-8.8 m）——已归因为前端跟踪极限
   + 关键帧债（V1_01 0.514）与走廊低纹理（V2_03 8.8）。
3. **与 Stereo-Inertial 对比**：所有 SI 系统都远优于纯视觉——印证 roadmap 的
   M4 方向（接入 IMU 是精度跃升的主路径）。
4. **差距主要来自**：无 IMU（旋转段位姿退化）、无回环（长时漂移）、前端
   跟踪能力（V 系列快速运动）、无地图复用（V2_03 低纹理）。

## 4. 用途

- 作为 M3.3 收尾的**公开基线定位**（phad-vio 处于纯 VO 学习的合理位置）
- M4 接入 IMU 后，预期 MH/V1 系列向 SI 系统靠拢（如 VINS-Fusion SI 0.138 avg）
- 不用于直接对标（公平性前提见 §1）
