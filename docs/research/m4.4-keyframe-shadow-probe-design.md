## 1. 目标与判读边界

B0 已证明 `KeyframeEpochGate` 在 live pipeline 中逐字节复现 control。下一 probe
回答一个更窄的问题：

> 在 **production accepted-KF epoch 固定不变** 时，last-KF→current IMU rotation
> evidence 与当前 `pose_lag` evidence 每帧如何分叉；分叉是孤立 threshold jitter、
> 连续 motion region，还是 interval 密度问题？

probe 必须同时满足：

- production `decision.selected` 仍只来自 B0 `pose_lag`；
- estimator 收到的 `is_kf`、window、trajectory 和 accepted schedule 不变；
- IMU segment 只在 production `selected && kOk` 后 reset；
- 当前帧使用 estimator 返回前最新 causal gyro bias；
- sidecar 明确记录 evidence、candidate 与真实 outcome 的区别。

probe 不能证明某个 shadow candidate 被 estimator 当 KF 时仍会 `kOk`，也不能计算
首次 shadow 分叉后的真实反事实 window。因此输出只称为 **frozen-epoch first-order
counterfactual**，不称为 candidate accepted schedule。

## 2. 模块边界

```text
phad::estimator::integrateImuRotation
  raw gyro samples + causal bias -> R_Bi_Bj / validity
                  |
                  v
apps::KeyframeShadowProbe (CLI-only)
  accumulate production last-KF segment
  body delta + T_B_C -> R_Ccur_Clkf
                  |
                  v
apps::KeyframeEpochGate::evaluateRotation(ticket, tracks, R)
  reuse committed pixel epoch + intrinsics -> alternative parallax
                  |
                  v
keyframe_shadow.csv -> scripts/keyframe_shadow_probe.py -> Markdown
```

依赖方向保持：GTSAM 只出现在 estimator implementation；apps 只看到 Eigen/POD。
不新增 virtual interface、runtime selector source switch 或 BA fallback。shadow probe
不是 gate 的第二套 production policy。

### 2.1 estimator helper

新增窄 helper：

```cpp
enum class ImuRotationError : std::uint8_t
{
  kNone,
  kInsufficientSamples,
  kNonMonotonicTimestamp,
  kNonFiniteGyro,
  kNonFiniteBias,
  kNonFiniteResult
};

struct ImuRotationResult
{
  bool              valid;
  ImuRotationError  error;
  common::Timestamp t_i;
  common::Timestamp t_j;
  double            dt_s;
  double            angle_rad;
  Eigen::Matrix3d   R_Bi_Bj;
};

[[nodiscard]] ImuRotationResult integrateImuRotation(
    std::span<const sensor::ImuMeasurement> samples,
    const Eigen::Vector3d& bias_gyr );
```

实现使用 GTSAM `PreintegratedAhrsMeasurements`；absolute `bias_gyr` 在构造时作为
`biasHat`，直接读取 `deltaRij()`。样本 `i` 覆盖 `[t_i,t_{i+1}]`，右端样本不再
积分。public header 不出现 GTSAM 类型。

### 2.2 gate alternative-measurement seam

B0 gate 新增只读方法：

```cpp
struct KeyframeRotationEvidence
{
  std::size_t common_count;
  std::size_t parallax_count;
  double      raw_parallax_px;
  double      compensated_parallax_px;
};

[[nodiscard]] KeyframeRotationEvidence evaluateRotation(
    std::uint64_t ticket,
    const frontend::FrameTracks& tracks,
    const Eigen::Matrix3d& R_kf_to_cur ) const;
```

它只允许在同一 frame 的 `decide()` 与 `resolve()` 之间调用；ticket 或 timestamp 不
匹配抛 `std::logic_error`。它读取当前 committed epoch，不改变 pending decision、
trigger、selected rule 或 state。production evidence 与 alternative evidence 复用同一
projection helper，避免 probe 复制 pixel baseline 和相机投影。

## 3. IMU segment 与坐标语义

### 3.1 生命周期

`KeyframeShadowProbe` 保存：

- production last-KF→current raw IMU samples；
- sticky `imu_gap`；
- 最近一次 `kOk` 后的 causal `bias_gyr`；
- last committed KF frame index；
- 单个 pending shadow row。

每帧顺序：

```text
gate.decide(tracks)                  # production decision 已固定
shadow.observe(packet, decision)     # append segment, compute IMU evidence
estimator.update(..., selected)
event = gate.resolve(ticket, feedback)
shadow.resolve(event, bias_gyr)      # write row; commit/reset iff epoch committed
```

相邻 packet 的共享 boundary sample 去重。production epoch commit 后保留当前右端
sample 作为下一段左端，并清除 sticky gap。reject/failed 不 reset segment、不更新
bias；non-KF `kOk` 更新 causal bias但保留 segment。

首个 production accepted KF 前写 `no_accepted_kf`；IMU-off 写 `imu_disabled`；sticky
gap 写 `imu_gap`。这些业务 reason 在 helper 数值错误之前判定。

### 3.2 坐标变换

helper 输出：

```text
DeltaR_ij = R_Bkf_Bcur = R_W_Bkf^T * R_W_Bcur
```

旧 rectified-left ray forward-warp 到当前 rectified-left：

```text
R_Ccur_Clkf = R_B_Crect^T * DeltaR_ij^T * R_B_Crect
```

其中 `R_B_Crect = T_B_left_rectified.rotation()`。shadow 必须使用 non-identity
extrinsic test 锁定 transpose 与共轭；不得复用 B0 当前省略共轭的 `pose_lag` 数学。

## 4. CLI 与 sidecar schema

新增 CLI-only：

```text
--keyframe-shadow-probe <path>
```

对应 `OfflineVoSessionOptions::keyframe_shadow_probe_path`。默认空，不构造 probe；
不进入 `flattenConfig`、`config_hash` 或 `meta.json.config`，行为与现有 `--probe-b`
一致。打开/写入失败返回明确 `SessionError`；不静默禁用 probe。

sidecar 为固定 schema CSV，一帧一行，至少包含：

```text
frame,ts_ns,epoch_before,frames_since_kf,
prod_selected,prod_rule,prod_empty,prod_bootstrap,prod_low_tracks,
prod_timeout,prod_low_survival,prod_parallax,
obs,common,survival,raw_px,pose_comp_px,pose_parallax_n,since_kf_ns,
imu_valid,imu_reason,imu_sample_n,imu_gap,imu_t_i_ns,imu_t_j_ns,
imu_dt_s,imu_angle_rad,bias_gyr_x,bias_gyr_y,bias_gyr_z,
imu_comp_px,imu_parallax_n,imu_gt_10,imu_gt_15,imu_gt_30,
status,epoch_committed,epoch_after
```

浮点用 `max_digits10`，不可用数值写 `0`，由 `imu_valid/reason` 消歧；不写 NaN。
rule、status、reason 使用稳定小写 token。CSV header、列数和严格 timestamp 单调性由
测试锁定。

## 5. 离线 analyzer

新增标准库 Python：

```text
scripts/keyframe_shadow_probe.py
scripts/keyframe_shadow_probe_test.py
```

输入一个 sidecar，输出 Markdown。必须先校验：

- header 完全匹配；
- frame 从 0 连续，timestamp 严格递增；
- `epoch_before/epoch_after/epoch_committed` 自洽；
- `prod_selected`、status 与 commit 关系自洽；
- valid IMU 区间端点、sample count、有限数值自洽。

报告：

1. IMU valid/reason 分布，首个 valid frame；
2. `pose_comp_px`、`imu_comp_px` 与差值的 p50/p90/p95/p99；
3. 10/15/30px frozen-epoch candidate 与 production candidate 的 first difference、
   add/remove 数和按 production rule 分解；
4. IMU threshold hit 的连续 run-length 分布，用来判断 two-hit 是否针对真实孤立抖动；
5. 按 `frames_since_kf` 的 hit 分布，以及 hard gap `1..6` 会 veto 的 first-order 数；
6. 明确免责声明：veto 后 baseline 未重算，不能把计数当 live schedule。

analyzer 不自动推荐 guard；它只把支持/反对某个 mechanism 的证据显式化。

## 6. 错误与事务

- unresolved shadow frame 时再次 `observe()`、ticket mismatch 或 double `resolve()`
  抛 `std::logic_error`；
- gate transaction 先 resolve，再让 shadow 根据返回 event commit，避免 shadow 自己从
  `selected/status` 猜 epoch；
- writer I/O error 转成 session failure，并保留具体 path/reason；
- invalid IMU evidence 是可记录的数据，不是 session failure；
- helper 对非单调/非有限输入返回结构化 invalid，不跳过坏样本后伪装 valid。

## 7. 测试与验收

### 7.1 unit

- estimator helper：identity、constant rotation、absolute bias cancel、direction、
  insufficient/duplicate/reverse/nonfinite；
- gate：alternative identity 与 production evidence 相同、ticket/timestamp mismatch、
  alternative 调用不改变 resolve；
- shadow：shared-boundary 去重、accepted reset、reject retain、non-KF bias update、
  gap reason、non-identity extrinsic、CSV schema/I/O error；
- CLI：usage、path 不改变 config hash；
- Python analyzer synthetic golden 与 malformed input。

## 8. 非目标

- 不改变 production schedule、threshold、rotation source 或 estimator；
- 不在本片实现 cooldown、two-hit、hysteresis 或 adjacent-frame baseline；
- 不用 shadow status 推测“若作为 KF 会被接受”；
- 不扩 sentinel/full-suite；先让 MH_01 evidence 合同成立；
- 不把 probe 路径加入产品 config identity或长期保留双 selector。

## 9. 执行收口

2026-08-09，sidecar 在完整 MH_01 上产出 3682 个 frame row、518 个 committed
epoch；production 三主文件相对 B0 逐字节相同。10/15px IMU hit 主要为连续 run，
而 hard gap / agreement veto 会影响数百个事件，未出现支持 two-hit、hysteresis、
cooldown 或 dual-evidence guard 的局部机制证据。因此本 probe 计划完成，但不实现
production guard；事实、推断与 live-counterfactual 缺口见结果文档。
