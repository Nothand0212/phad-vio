## 1. 目标与非目标

**唯一目标**：在 `StereoVoEstimator` 的正常路径上，用窗口活点集 `landmarks_W`
（最近 `window_size` 帧内被观测、每帧 BA 后写回的世界点；`pruneLandmarksNotInWindow`
保证其寿命 ≤ 窗口） + 当前左目观测做 `cv::solvePnPRansac`，成功则以其位姿作为
窗口新帧初值，并在优化前丢掉本帧 RANSAC 外点观测；失败则回退现有恒速 / 上一帧
初值且不 cull。

不做：

- 永久删除 `landmarks_W` 或同步删 frontend track（Slice ④）；
- 在首段 seed / re-anchor 路径上跑 PnP（`num_shared == 0` 无 3D–2D 对应）；
- 优化后 chi2 外点、关键帧策略、IMU、边缘化；
- frontend 侧 2D–2D F-RANSAC（开源常见，但本片不解决「差初值」，且会改
  frontend）；
- 改 `phad::eval`；不要求 MH_01 `est.tum` 与 Slice ② 逐字节相同。

## 2. 已对齐的决策

| 决策点 | 结论 | 依据 |
|---|---|---|
| 主交付 | **`solvePnPRansac` 初值 + 优化前本帧 inlier 掩码** | roadmap 字面；开源对照：只求位姿不掩码则未完成「剔时序外点」 |
| 求解器 | estimator PIMPL 内调 OpenCV `solvePnPRansac`；`PRIVATE opencv_calib3d`；公开头无 OpenCV | 与 GTSAM PRIVATE / PIMPL 同型；对齐 roadmap |
| 数据流 | 窗口活点集 `landmarks_W` + 当前 `left_pixel`（VINS 型 3D–2D） | 不是 Kimera 默认的 3D–3D Arun；注意 `landmarks_W` **非全局地图**——`pruneLandmarksNotInWindow` 保证寿命 ≤ 窗口，对应点上限 = `num_shared`（当前帧观测 ∩ `landmarks_W`） |
| guess | 现有 `poseInitialValue()`（恒速或上一帧）作 `useExtrinsicGuess` | 对齐 VINS「上一帧外参初值」 |
| 失败回退 | 位姿 = guess；**不** cull；**不**拒帧（含 RANSAC 收敛但 inliers < `min_pnp_inliers` 的弱模型帧） | VINS 失败沿用上一帧；避免 Slice ① 已消掉的吸收态；弱 inlier 集不可靠、掩码可能误删，窗口 BA 的 Huber（k=3 px）兜底 |
| 外点作用域 | 只从本帧 `WindowFrame.observations` 去掉 shared 外点；`landmarks_W` / frontend 不动 | Slice ④ 再做永久生命周期 |
| 新观测 | 不在 `landmarks_W` 的 id 不参与 PnP；成功时仍按最终 `T_W_B` backproject 入图 | 保持现有「本帧新 id 建点」语义 |
| 配置 | 新增 `enable_pnp_init`（默认 true）；`use_constant_velocity_init` 语义不变（guess + fallback） | A/B：关 PnP 复现 Slice ② |
| 默认阈值 | `pnp_reproj_px=2.0`、`pnp_confidence=0.99`、`min_pnp_inliers=10` | 夹在 Kimera PnP 1 px 与 VINS 事后 3 px 之间；min 与 `min_shared_landmarks` 同量级 |
| 诊断 | `diag.csv` +2 列；`summary.json` 加 `pnp_successes` / `pnp_fallbacks` | 与 `segment_id` 同思路：看不见则无法验收 |
| PnP↔guess 一致性 | **不加门限**（YAGNI）：PnP 位姿直接作初值，窗口 BA + 最老帧 prior（1e-4）拉回；异常由既有 `max_window_pose_shift_m` 与 MH_01 ATE 门控观察 | 初值定位；ORB 式 pose-only BA 复核属 Slice ④ 形态 |
| 掩码语义 | 被掩码观测**仍计入** `track_times` / `observationTimestamps`；`num_observations` 保持测量原值 | 诊断完整性；避免「诊断计数 ≠ 入图观测数」引起困惑 |
| 出口门控 | MH_01 ATE ≤ 0.1073 m 且 `segments=1` / `reanchors=0`；全序列 `reanchors` 不增；其余只记录 | 对齐 Slice ② 放宽后口径；不把 MH_04 债绑死本片 |

## 3. 模块边界

不新增库。改动集中在：

```text
phad::estimator   StereoVoEstimator::update  ← 正常路径：PnP 初值 + 本帧 inlier 掩码
                  EstimatorOptions           ← enable_pnp_init / pnp_* / min_pnp_inliers
                  UpdateDiagnostics          ← pnp_success / pnp_inliers
                  CMakeLists.txt             ← PRIVATE opencv_calib3d
        ↓
apps/offline_vo_session                      ← diag.csv 14 → 16 列；结束 summary 日志
apps/phad_vo_bench                           ← flattenConfig 新字段；summary 计数
phad::bench   RunSummary                     ← robustness.pnp_successes / pnp_fallbacks
tests/estimator|apps|bench                   ← 合成场景 + 契约
docs                                         ← estimator README + 本设计 + 出口基线
```

`phad::frontend` / `phad::eval` **不动**。公开 `types.hpp` / `stereo_vo_estimator.hpp`
仍只暴露 Eigen / POD（OpenCV 仅 `.cpp`）。

### 新选项与诊断字段

```cpp
struct EstimatorOptions
{
  // …既有字段…
  bool   enable_pnp_init = true;   // false → 复现 Slice ②（仅恒速/上一帧）
  double pnp_reproj_px   = 2.0;    // solvePnPRansac reprojectionError（像素）
  double pnp_confidence  = 0.99;
  int    min_pnp_inliers = 10;     // 对应点或 inliers 不足 → fallback
};

struct UpdateDiagnostics
{
  // …既有字段…
  bool          pnp_success = false;  // 本帧是否采用了 PnP 位姿
  std::uint32_t pnp_inliers = 0;      // 成功时为 inlier 数；否则 0
};
```

构造校验（`std::invalid_argument`）：

| 条件 | 要求 |
|---|---|
| `pnp_reproj_px` | > 0 |
| `pnp_confidence` | ∈ (0, 1) |
| `min_pnp_inliers` | ≥ 4（PnP 最小集） |
| 既有 window / seed / prior 规则 | 不变 |

四个新字段全部进 `flattenConfig()`，产生新 `config_hash`。

## 4. 数据流

首段 seed 与 re-anchor **不改**：仍 `Identity` / `poseInitialValue()` →
`seedSegment`，`pnp_success=false`、`pnp_inliers=0`（不计入
`pnp_fallbacks`）。

正常路径（`initialized && num_shared > 0`）在现有 `candidate.T_W_B =
poseInitialValue()` 处扩展：

```text
guess = poseInitialValue()

若 !enable_pnp_init:
  T_W_B = guess；不 cull；pnp_success=false
否则若 num_shared < min_pnp_inliers:
  T_W_B = guess；不 cull；pnp_success=false；++pnp_fallbacks
否则:
  收集 (landmarks_W[id], left_pixel) 对 shared 观测
  将 guess 转为左目相机位姿作 useExtrinsicGuess
  cv::solvePnPRansac(P_W, uv, K_rect, dist=[], …,
                     reprojectionError=pnp_reproj_px,
                     confidence=pnp_confidence)
  成功且 inliers.size() >= min_pnp_inliers ?
    是 → T_W_B = T_W_left · T_B_left⁻¹
         从 candidate.observations 去掉 shared 外点
         （新 id 观测保留）；pnp_success=true；pnp_inliers=|
    否 → T_W_B = guess；不 cull；pnp_success=false；++pnp_fallbacks

track_times：按 measurement 全量写入（含被掩码的 shared 外点；见 §5）
对新 id（尚不在 landmarks_W）：用最终 T_W_B 对掩码后的
  candidate.observations backproject（现逻辑）

push window → prune → buildGraph → LM（不变）
```

要点：

- OpenCV 解的是 **rectified left** 相机位姿；用已有
  `body_P_sensor`（`T_B_left_rectified`）变回估计器状态 `T_W_B`；
- 对应点全部来自**最近窗口**：`landmarks_W` 由 `pruneLandmarksNotInWindow` 约束为
  窗口活点集（非 VINS 全局 feature 表），每帧 BA 后写回坐标；对应点上限 =
  `num_shared`；场景切换 / 急转弯后 `num_shared` 骤降属预期，此时走 fallback；
- 实现时勿把 `track_times` 循环改成扫掩码后的 `candidate.observations`，否则会
  静默丢掉被掩码 id 的诊断时间戳；
- `K` 用标定 `fx, fy, cx, cy`，畸变为空（输入已是 rectified 像素）；
- RANSAC 迭代次数**显式传 100**（对齐 Kimera `ransac_max_iterations_=100`，避免
  OpenCV 版本间默认差异），不另开配置旋钮，除非 bench 证明需要；`useExtrinsicGuess`
  隐含 `SOLVEPNP_ITERATIVE`，若合成测试 / MH_01 不稳定可备选 EPNP（放弃 guess）；
- 事务回滚语义不变：任何后续 `kRejected` / `kFailed` 仍整帧还原。

```mermaid
flowchart TD
  A[正常路径 num_shared > 0] --> B[guess = poseInitialValue]
  B --> C{enable_pnp_init?}
  C -- 否 --> G[T = guess 不 cull]
  C -- 是 --> D{|shared| >= min_pnp_inliers?}
  D -- 否 --> F[fallback: T = guess 不 cull]
  D -- 是 --> E[solvePnPRansac]
  E --> H{成功且 inliers 够?}
  H -- 是 --> I[T = PnP 位姿<br/>掩码本帧 shared 外点]
  H -- 否 --> F
  I --> J[新 id backproject → 入窗 → BA]
  F --> J
  G --> J
```

## 5. 错误与诊断

**运行时**：PnP 失败**不是**新的 `UpdateStatus`；只改变初值来源与是否掩码。
非有限位姿仍走既有 `kFailed`。

**掩码语义**：被掩码的 shared 外点观测仍写入 `track_times` 并出现在
`observationTimestamps()`（诊断完整性）；`num_observations` 保持测量原值，
不代表入图观测数。RANSAC 收敛但 inliers ∈ [4, `min_pnp_inliers`) 时模型弱，
仍**不掩码**（取舍 A）：弱 inlier 集不可靠、掩码可能误删；窗口 BA 的 Huber
（k=3 px）兜底；与「失败不 cull」哲学一致。

**`diag.csv`**：14 → 16 列，尾部追加 `pnp_success,pnp_inliers`（整数；
`pnp_success` 为 0/1）。有意契约变更，同步 `phad/estimator/README.md`、
`apps/AGENTS.md`、`tests/apps`。

**`summary.json`**（`schema_version` 保持 1）：

```json
{
  "robustness": {
    "rejected": 0, "failed": 0, "low_connectivity": 0,
    "cheirality": 0, "reanchors": 0,
    "pnp_successes": 0, "pnp_fallbacks": 0
  }
}
```

`pnp_fallbacks` 仅统计**正常路径**上本可尝试 PnP 但未采用的帧（含对应点不足 /
RANSAC 失败 / inliers 不足）。首段与 re-anchor 不计。

**日志**：结束一条 summary（successes / fallbacks；可选平均 inliers）；
首次 fallback 可 warning 一次。不每帧刷屏。

## 6. 测试与验收

### 单元测试（`tests/estimator/`）

| 用例 | 断言 |
|---|---|
| 合成场景 PnP 成功 | 已知运动 + 干净对应 → `pnp_success=true`，位姿≈真值（容差内） |
| RANSAC 剔外点 | shared 中混入明显外点 → 外点不进本帧观测；`landmarks_W` 仍保留该 id |
| 对应点不足 fallback | `num_shared < min_pnp_inliers` → `pnp_success=false`，位姿=guess，不 cull |
| RANSAC 失败 / inliers 不足 | 同上 fallback |
| `enable_pnp_init=false` | 行为对齐仅恒速 / 上一帧路径 |
| re-anchor / 首段 | 不跑 PnP；`pnp_success=false`、`pnp_inliers=0` |
| 掩码 × `min_landmark_observations` 边界 | 窗口内恰 2 帧观测的 landmark，本帧被掩码 → 本帧不进图但坐标保留；下一帧恢复观测后正常入图（无崩溃、无状态污染） |
| 非法选项 | 构造抛 `invalid_argument` |
| 既有 re-anchor / diagnostics | 不回归 |

- `tests/bench/`：`summary.json` 的 `pnp_successes` / `pnp_fallbacks`。

## 7. 与父设计 / 开源对照的关系

- 父设计第 8 节 Slice ③ 原写「参考 VINS `F_THRESHOLD=1.0`、Kimera
  `ransac_threshold_stereo_=1.0`」。开源对照澄清：二者**不是**
  `solvePnPRansac` 的像素阈值；同型参考为 Kimera `ransac_threshold_pnp_=1.0 px`
  与 VINS 事后 ≈3 px。本片默认取 **2.0 px**。
- VINS 热路径是无 RANSAC 的 `solvePnP`；本片有意把其注释掉的 RANSAC 加回，
  并用 inlier 掩码补上「剔时序外点」，避免与 Slice ④ 边界糊掉。
- ORB-SLAM3 / lk-vio 热路径是恒速 + pose-only BA；每帧 PnP-RANSAC 是相对它们的
  **有意偏离**，对齐的是 VINS 纯双目后端。
- Slice ④ 仍负责优化后 chi2 与 landmark / track 永久生命周期；本片外点只影响
  当前帧入图观测。
