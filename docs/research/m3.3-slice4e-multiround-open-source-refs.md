## 1. 要回答的问题

④d 出口：`outlier_avg_reproj_px=4.0` 收口 MH_01（ATE ≈ 0.0988），但 MH_05
仍 ≈ 4.565 m；发散债（MH_02 / V1_02 / V1_03 等）只记录。④b 已证明**单次**
LM₂ 有效（大剔后 RMS 60–337 → 0.18/0.26 px）但对 MH_05 ATE 不够。

④e 要决定：如何把 ORB 式「多轮」接到本仓库已有的 **VINS 型永久 mean-cull +
④b 单次 rebuild LM** 上——是扩展永久删点循环，还是改观测级可翻转外点，
以及是否去 Huber。

## 2. 本仓库现状（④d 热路径）

```text
LM₁（Huber k=3）→ 写回
→ cheirality 永久删 + mean-cull 永久删（n_factors≥4，mean px > T）
→ if culled≥4 且 enable_outlier_reopt: rebuild → LM₂ → 写回
→ 不再 cull；LM₂ 失败则回滚到「LM₁ 写回 + cull」
```

要点：

- 判据与生命周期是 **landmark 级永久删**（+ ④c `block_culled_rebirth` /
  session `dropTracks`），不是观测级 flag；
- 重优最多 **1** 次，且 **不再** mean-cull；
- Huber 全程保留（`huber_k_px=3`；`≤0` 可关）；
- ④d 下 MH_05：`outliers_culled=28`、`outlier_reopts=1`（重优触发极稀）。

## 3. ORB-SLAM3：两种不同形态（勿混为一谈）

本地树：`/home/lin/Projects/lin_ws/slam_ws/ORB_SLAM3`（`src/Optimizer.cc`）。

### 3.1 `PoseOptimization`（跟踪，pose-only）——真正的「4 轮可翻转」

注释原文（约 L999–1000）：

> We perform 4 optimizations, after each optimization we classify observation
> as inlier/outlier. At the next optimization, outliers are not included, but
> at the end they can be classified as inliers again.

机制摘要：

| 项 | 行为 |
|---|---|
| 优化对象 | **仅当前帧位姿**；地图点 `Xw` 固定 |
| 轮次 | 4 × `optimize(10)` |
| 外点单位 | **观测**（`mvbOutlier[i]`） |
| 轮间 | `setLevel(1)` 排除出下一轮；可再翻回 inlier |
| Huber | 第 3 轮后（`it==2`）`setRobustKernel(0)` |
| χ² | mono 5.991 / stereo 7.815 |
| 地图点 | **本函数不永久删 MapPoint** |

### 3.2 `LocalBundleAdjustment`（局部 BA）——与窗口 BA 更同型

机制摘要：

| 项 | 行为 |
|---|---|
| 优化对象 | 局部 KF 位姿 + MapPoint（更接近本仓库窗口 BA） |
| 轮次 | **单次** `optimize(10)`（非 4 轮翻转） |
| 外点动作 | 优化**后**按 χ² / 深度把 **KF↔MP 观测边** `EraseObservation` |
| 点生命周期 | 观测可被拆；点是否 `bad` 另有逻辑，不是「mean px → 整点删」 |

结论：**不能把 PoseOptimization 的 4 轮原样贴到窗口 BA**；ORB 自己在 Local BA
上用的是「一次优化 + 事后拆观测」，多轮可翻转专属于跟踪 pose-only。

## 6. 对本片的工程取舍（调研倾向，非定案）

1. **主路径优先「永久 mean-cull ↔ rebuild+LM」多轮扩展 ④b**  
   保持 VINS/④/④c 生命周期合同；改动面最小；直接针对「LM₂ 后再坏的点 /
   只重优一次不够」。ORB PoseOpt 的可翻转是 pose-only 专用，硬抄到窗口 BA
   需新建观测级 mask 状态机，与 `landmarks_W.erase` + `block_culled_rebirth`
   语义冲突风险高。

2. **观测级可翻转外点** 作为备选 / 不够后再开  
   更贴 ORB PoseOpt，但本仓库无 per-observation outlier 存储；且与 ④c
   「永久身份」已投入成本叠床架屋。除非多轮永久 cull 证明无效。

3. **去 Huber** 宜作可选后段，勿与「多轮 cull」绑死为同一开关  
   ORB 在 pose-only 第 3 轮后去核；窗口 BA 上过早去核可能放大坏点拉动。
   建议：先多轮 cull↔LM；验收不够再试「末轮 / 末两轮 `huber_k_px=0` 重建图」。

4. **阈值**  
   保持 ④d 默认 `outlier_avg_reproj_px=4.0`；本片不为过门乱改 T。χ² 7.815
   仍不作主判据（④ 已否决：绑 σ、比 mean-px 更激进）。

5. **出口证据链**  
   ④b 已证单次 LM₂ 降 RMS；④e 要证多轮能否压 MH_05 ATE（目标方向 &lt;1 m
   或至少明显优于 4.565 / 回到 ≤④b 的 3.449），并观察发散序列是否减债——
   编码后先 MH_01 不回归，再 MH_05 诊断，够再条件全序列。
