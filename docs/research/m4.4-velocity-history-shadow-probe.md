## 1. 问题与边界

rolling PIM 反事实显示，B6 在 0.05/0.5 s 的 displacement excess 中，velocity 分别
解释 `99.40%/71.61%`，而 bias 均不足 `1%`。本探针只回答一个更窄的问题：

> 在固定 candidate pose、gravity、gyro bias、accelerometer bias 与 raw IMU 时，
> 把 velocity information 跨窗口传递，能否降低当前 body-frame velocity error？

探针不改 estimator graph、trajectory、factor covariance、KF schedule 或 run artifact。
EuRoC reference velocity 只用于离线评分，不进入任何 shadow equation。

## 2. 方程与 arms

对相邻 full state `i→j`，使用 candidate 自身 bias 重建 PIM，并固定 candidate pose 与
gravity：

```text
dt * v_i       = p_j - p_i - R_i Δp_ij - 0.5 g_i dt²
-v_i + v_j     = R_i Δv_ij + g_i dt
```

三轴的 normal matrix 同构为标量三对角矩阵；脚本用 Thomas elimination 做 O(N)
求解。dense least-squares 对拍误差小于 `1e-12`。固定五臂：

| arm | 时间合同 | 含义 |
|---|---|---|
| `actual` | causal | candidate posterior velocity |
| `one_interval` | causal | 每条 interval 从 visual displacement 重置 `v_i` 后传播到 `v_j` |
| `causal_marginal` | causal | 精确 Schur 消元旧速度，把全部 past information 传给当前状态 |
| `fixed_window` | causal | 只解当前 10-state fixed-pose window，不带 incoming prior |
| `full_batch` | **non-causal** | 全序列 batch；读取 future，只是诊断上界 |

`fixed_window` 不是 production stereo/IMU 联合图的复刻；它只隔离 fixed-pose velocity
子问题。`full_batch` 即使改善也不能晋级生产。

## 4. MH_01 结果

### 4.1 calibrated B6

| arm | velocity RMS | 对 actual 比率 | 逐帧改善比例 |
|---|---:|---:|---:|
| `actual` | `0.0248283 m/s` | `1.0000` | — |
| `fixed_window` | `0.0270511 m/s` | `1.0895` | `40.09%` |
| `causal_marginal` | `0.0548363 m/s` | `2.2086` | `12.09%` |
| `one_interval` | `0.0402413 m/s` | `1.6208` | `19.83%` |
| `full_batch` | `0.0242514 m/s` | `0.9768` | `49.05%` |

唯一改善 RMS 的 `full_batch` 读取未来，改善仅 `2.32%`，且不足半数帧改善。它在
末段 bucket 7/8 也分别劣于 actual（`0.03427 vs 0.02763`、`0.02250 vs
0.01255 m/s`）。精确 causal marginal 从 bucket 4 起持续累积 model mismatch，末段
达到 `0.08957 m/s`。

## 5. 判定

**否决把 fixed-lag / window-boundary velocity prior 作为下一把 production 修改。**

事实支持的解释是：当前 10-frame joint graph 已优于“全 past prior”和“只看新鲜
interval”两个极端；固定 pose 的 IMU 方程含持续 model mismatch，精确传递 history
会积累而不是修复误差。GTSAM fixed-lag 能正确边缘化信息，但不能自动消除错误模型；
直接接入还会新增 pose measurement noise、bias lifecycle 与 factor ownership 三组
自由度。

因此不实现 C++ `IncrementalFixedLagSmoother` shadow，不扫 lag/noise/bias。下一轮回到
距离门最近的 gyro-only B3（MH_01 ATE 仅比 VO 差 `2.36 mm`、RPE 已好
`0.88 mm`），先检验可观测 visual↔gyro disagreement 是否能支持 factor admission。
