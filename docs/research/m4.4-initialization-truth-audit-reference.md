# M4.4 initialization truth audit 一手资料对照

日期：2026-08-10

状态：**一手资料调研完成；给出只读 t0 truth audit 合同；未修改 production**

本文档描述当前约定，不是绝对约束，会随项目开发修订。

## 1. 结论先行

1. **当前 GTSAM 符号方向是自洽的。** `MakeSharedU(g)` 在 navigation/world frame
   中设置 `g_W=(0,0,-g)`；accelerometer 输入是 sensor frame 的 specific force，bias
   在 sensor frame 先相减。静止时
   `a_meas=-R_W_S^T g_W+b_a+n_a`，所以 bias-corrected specific force 的方向应是
   body/sensor 的“上”，把该方向映到内部世界 `+Z` 与 GTSAM Z-up 合同一致。
2. **EuRoC MH_01 的 reference state 可以直接按 IMU/body state 读取。** 官方约定中
   `q_RS` 是 Hamilton、scalar-first 的 active quaternion，`R_RS` 把向量从 S 变到 R；
   `v_RS_R` 在 R 表达，`b_w_RS_S/b_a_RS_S` 在 S 表达。MH_01 的 `imu0` 与
   `state_groundtruth_estimate0` 均有 `T_BS=I`，所以这里的 `S=B`、`R=W_ref`：
   CSV 可直接解释为 `R_W_B / v_W / bg_B / ba_B`，无需求逆、共轭或再旋转 bias。
3. **必须把 internal world 与 EuRoC reference world 分开。** phad-vio 静止初始化只由
   gravity 决定 roll/pitch，yaw 与位置是 gauge。不能直接逐元素比较
   `R_West_B` 与 `R_Wref_B`；首要姿态指标应是 yaw-invariant 的 body-frame gravity/
   up-vector angle。reference gravity axis 必须显式记录，不能从列名默认为 Z-up。
   后续 pose/velocity 如需同图比较，只允许用一个在 t0 冻结的 yaw+translation gauge，
   不允许 Sim(3) 或逐窗重新对齐。
4. **0.5 s 低方差窗口不能单独证明“静止”。** 它能直接报告时间完整性、raw
   acc/gyr mean/std/covariance；只有在“零角速度、零线加速度”假设成立时，mean gyro
   才是 `bg`。同一个 mean acc 同时用于 tilt 与 `ba` 时仍不可观：已知 `g` 也只有
   3 个观测去约束 2-DoF gravity direction 与 3-DoF acc bias。yaw、绝对位置、绝对
   速度与 scale 更不能由静止 IMU 得出。
5. **当前初始化选择的是一个特定而非可辨识的分解。** 令
   `m=mean_acc, u=m/||m||`，当前实现取 `R*u=e_z`、`ba=m-g*u`。因此 `ba` 被强制与
   `m` 平行，gravity-tangent bias 恒为零；真实 tangent acc bias 会被吸收到 tilt。
   `v0=0` 同样是 prior/假设，不是测量推导。
6. **最小只读 probe 应审计“采用的窗口”和“采用的 state”两种时间语义。** 当前状态
   标在窗口起点 t0，但 `R/bg/ba` 使用整个 `[t0,t1]` 的样本。probe 必须同时对比
   GT(t0) 与同窗口 GT support，并记录 t0、window midpoint/end、第一条 seed state
   timestamp；否则残余运动会被误报成坐标错误。
7. **成熟实现可迁移的是质量门与日志模式，不是某组初始化数值。** OpenVINS 把旧静止
   半窗与新运动半窗分开，并结合视觉 disparity；Kimera 同时打印 expected/actual
   acc/gyr 与 gravity；VINS/ORB-SLAM3 使用多帧视觉-惯性窗口显式求 gyro bias、
   velocity、gravity，mono 再求 scale。它们都没有证明 0.5 s raw IMU 能独立恢复
   `R/v/bg/ba/g/scale`。
8. **EuRoC 的“truth”不是所有维度都独立。** MH ground-truth 是 Leica position 与
   IMU 的离线 batch solution，数据自身注明 orientation 只由 IMU 观测；官方论文也说
   smoother 联合估计 attitude、velocity 与 biases。因此 `R/bg/ba` 是高价值 reference，
   但与被审计 raw IMU 有相关性，结论必须写作“与 EuRoC reference 一致/不一致”，
   不能写成独立标定真值证明。

因此下一片建议只增加一次性、CLI-only 的 initialization sidecar 与离线 analyzer：
先把 `R/v/bg/ba/g/time/frame` 错误定位清楚，不改变 static gate、initializer、prior、
noise、factor 或 keyframe schedule。

## 3. GTSAM measurement 与 gravity 合同

### 3.1 navigation frame 与 gravity

`PreintegrationCombinedParams::MakeSharedU(g)` 明确用于 Z-up/ENU-like navigation
frame，并设置：

```text
g_W = n_gravity = [0, 0, -g]^T
```

见
[`PreintegrationCombinedParams.h:35-77`](https://github.com/borglab/gtsam/blob/2f3e56c0ddbd3a1aa54ed043643b553d26a069f6/gtsam/navigation/PreintegrationCombinedParams.h#L35-L77)。
`predict()` 经 `NavState::correctPIM()` 把初速度与上述 world gravity 加入 position/
velocity prediction，见
[`PreintegrationBase.cpp:117-138`](https://github.com/borglab/gtsam/blob/2f3e56c0ddbd3a1aa54ed043643b553d26a069f6/gtsam/navigation/PreintegrationBase.cpp#L117-L138)
与
[`NavState.cpp:484-499`](https://github.com/borglab/gtsam/blob/2f3e56c0ddbd3a1aa54ed043643b553d26a069f6/gtsam/navigation/NavState.cpp#L484-L499)。

**本仓库事实：** 当前构造 PIM 使用 `MakeSharedU(options.imu_gravity)`；因此真正被
preintegration/predict 消费的是 configured `imu_gravity=9.81007`。静止检测另存的
`init_g=||mean_acc||` 在当前源码中没有后续 consumer。truth sidecar 必须把两者分别
命名为 `gravity_model_mps2` 与 `acc_mean_norm_mps2`，不能都叫 `gravity`。

OKVIS 固定 EuRoC 配置也使用 `g: 9.81007`、IMU 200 Hz 与 identity `T_BS`，见
[`config_fpga_p2_euroc.yaml:34-52`](https://github.com/ethz-asl/okvis/blob/f0c9ba472b89f85030cd58dfbae03ceec7817679/config/config_fpga_p2_euroc.yaml#L34-L52)。
这是成熟工程配置证据，不是 ground-truth CSV 中独立提供的 gravity measurement。

### 3.2 accelerometer 是 specific force，不是 world linear acceleration

GTSAM 的官方 scenario 写出的无噪声模型是：

```text
omega_meas_S = omega_WS^S + bg_S + n_g
acc_meas_S   = R_SW * (a_WS^W - g_W) + ba_S + n_a
```

其中 rotation/translation lever arm 为 identity 时 `S=B`。源码把 accelerometer
称为 specific force，并用 `R^T(a_W-g_W)` 生成 measurement，再叠加 bias/noise，见
[`ScenarioRunner.h:67-91`](https://github.com/borglab/gtsam/blob/2f3e56c0ddbd3a1aa54ed043643b553d26a069f6/gtsam/navigation/ScenarioRunner.h#L67-L91)。

静止时 `a_WS^W=0`、`omega_WS^S=0`，所以：

```text
mean_gyro ~= bg_S
mean_acc  ~= -R_SW * g_W + ba_S
```

在 Z-up 且无 bias 时，upright sensor 读到 `+[0,0,g]`，不是负值。当前把
`mean_acc.normalized()` 映到内部 `+Z` 与这个符号一致。

### 3.3 measurement、bias 与 `body_P_sensor` 所在 frame

`PreintegratedCombinedMeasurements::integrateMeasurement()` 明确接收 sensor-frame
acc/gyro，`body_P_sensor` 负责 sensor→body，见
[`CombinedImuFactor.h:151-163`](https://github.com/borglab/gtsam/blob/2f3e56c0ddbd3a1aa54ed043643b553d26a069f6/gtsam/navigation/CombinedImuFactor.h#L151-L163)。
`body_P_sensor` 是“sensor 在 body 中的 pose”，即 `T_B_S`，见
[`PreintegratedRotation.h:55-84`](https://github.com/borglab/gtsam/blob/2f3e56c0ddbd3a1aa54ed043643b553d26a069f6/gtsam/navigation/PreintegratedRotation.h#L55-L84)。

处理顺序不能交换：

1. `measurement - bias`，仍在 sensor frame；
2. 若存在 `T_B_S`，用 `R_B_S` 旋到 body；
3. 非零 lever arm 再扣除 centripetal acceleration。

证据见
[`ImuBias.h:75-90`](https://github.com/borglab/gtsam/blob/2f3e56c0ddbd3a1aa54ed043643b553d26a069f6/gtsam/navigation/ImuBias.h#L75-L90)、
[`ManifoldPreintegration.cpp:60-74`](https://github.com/borglab/gtsam/blob/2f3e56c0ddbd3a1aa54ed043643b553d26a069f6/gtsam/navigation/ManifoldPreintegration.cpp#L60-L74)
与
[`PreintegrationBase.cpp:61-103`](https://github.com/borglab/gtsam/blob/2f3e56c0ddbd3a1aa54ed043643b553d26a069f6/gtsam/navigation/PreintegrationBase.cpp#L61-L103)。

**本仓库事实：**

- EuRoC loader 已拒绝 non-identity IMU `T_BS`，所以进入 estimator 的 measurement
  已满足 body=IMU 合同；
- ground-truth loader 同样只接受 identity GT `T_BS`；
- estimator 中名为 `body_P_sensor` 的现有 member 是 `T_B_left_rectified`，服务视觉
  factor；它不是 GTSAM IMU params 的 `body_P_sensor`。当前 `imu_params` 没有设置
  IMU extrinsic。

因此 MH_01 bias 应与 CSV sensor-frame bias 直接比较。未来若 loader 放开 non-identity
IMU 外参，必须重新审计 measurement/bias/extrinsic，不能沿用本结论。

## 4. EuRoC frame、CSV 与本地数据快照

### 4.1 官方 notation

EuRoC 论文 Section 4 规定：raw measurement 在各 sensor frame `S` 表达，sensor
相对 sensor-system/body `B` 的 extrinsic 写在 `sensor.yaml`；外部 reference frame
为 `R`，每个数据集另有 quasi-inertial world `W`。quaternion 使用 Hamilton、
`[qw,qx,qy,qz]`；`C_WB(q_WB)` 是把 vector `B→W` 的 active rotation。

据此，CSV 字段的无歧义解释是：

| CSV 字段 | 含义 | MH_01 identity `T_BS` 后 |
|---|---|---|
| `p_RS_R` | S 相对 R 的位置，在 R 表达 | `p_WB_W` |
| `q_RS` | active `R_RS`，把 S vector 变到 R | `R_WB` |
| `v_RS_R` | S 相对 R 的速度，在 R 表达 | `v_WB_W` |
| `b_w_RS_S` | gyroscope bias，在 S 表达 | `bg_B` |
| `b_a_RS_S` | accelerometer bias，在 S 表达 | `ba_B` |

官方 `dataset_tools` 也按这个顺序读取 visual-inertial row，并把 bias 保留为 S-frame
三向量，见
[`dataset_load_sensor_data.m:49-62`](https://github.com/ethz-asl/dataset_tools/blob/851302080465781a35ce548dfceac8adb76bb101/matlab/dataset_load_sensor_data.m#L49-L62)。
raw IMU 则按 timestamp、omega、specific force 读取，见
[`dataset_load_sensor_data.m:17-23`](https://github.com/ethz-asl/dataset_tools/blob/851302080465781a35ce548dfceac8adb76bb101/matlab/dataset_load_sensor_data.m#L17-L23)。
其 body plot 直接把 `T_BS` 的 translation/rotation 解释为 `p_BS_B/C_BS`，见
[`dataset_plot_body.m:20-27`](https://github.com/ethz-asl/dataset_tools/blob/851302080465781a35ce548dfceac8adb76bb101/matlab/dataset_plot_body.m#L20-L27)。

若一般 pose sensor 的 `T_BS` 非 identity：

```text
T_R_S = T_R_B * T_B_S
T_R_B = T_R_S * inverse(T_B_S)
```

而 `v_RS_R` 也不能只旋转；nonzero lever arm 还含 angular-velocity cross-arm 项。
本次 MH_01 两个 `T_BS` 都是 identity，故不进入这条一般路径。

### 4.3 reference 的独立性限制

MH_01 ground-truth `sensor.yaml` 说明：reference 是 Leica position 与 IMU 的离线
nonlinear least-squares batch solution，且 orientation 只有 IMU observation。EuRoC
论文 Section 5.2 同样列出 smoother 联合估计 attitude、position、velocity、gyro/
acc bias 与 alignment/time offset。

所以：

- position 对 static/motion gate 是较强的外部证据；
- `R/v/bg/ba` 是官方 reference，适合回归与误差分解；
- 但 `R/bg/ba` 与 raw IMU 不独立，不能用于声称独立传感器验证了 bias；
- GT bias 是随时间的 batch estimate，不应只取文件第一行或整段常量。

## 5. 成熟实现怎样初始化与验证

### 5.1 Kimera-VIO：static seed 与 truth-style 日志

Kimera static initializer：

- 对 acc/gyr 求 mean；
- 用 `-mean_acc` 对齐 global gravity，translation 置零；
- velocity 置零；
- `bg=mean_gyro`；
- `ba=mean_acc+gravity_local`。

见
[`InitializationFromImu.cpp:21-76`](https://github.com/MIT-SPARK/Kimera-VIO/blob/ce8c59b7b273ab5ac29db7e5572e1623760e19c7/src/initial/InitializationFromImu.cpp#L21-L76)。
这与 phad-vio 属于同一类“stationary assumption + 特定 tilt/ba 分解”，不是 acc bias
独立可观证明。

Kimera 的 online gravity alignment 则使用 visual body poses、camera interval 与 PIM：

- 先验证 camera/PIM interval 一致；
- 用 visual relative rotation 与 PIM rotation 求 gyro bias；
- bias correction 后检查 rotation residual；
- 再求 initial velocity 与 gravity，并检查 gravity norm/refinement。

见
[`OnlineGravityAlignment.cpp:103-158`](https://github.com/MIT-SPARK/Kimera-VIO/blob/ce8c59b7b273ab5ac29db7e5572e1623760e19c7/src/initial/OnlineGravityAlignment.cpp#L103-L158)、
[`OnlineGravityAlignment.cpp:167-206`](https://github.com/MIT-SPARK/Kimera-VIO/blob/ce8c59b7b273ab5ac29db7e5572e1623760e19c7/src/initial/OnlineGravityAlignment.cpp#L167-L206)
与
[`OnlineGravityAlignment.cpp:214-289`](https://github.com/MIT-SPARK/Kimera-VIO/blob/ce8c59b7b273ab5ac29db7e5572e1623760e19c7/src/initial/OnlineGravityAlignment.cpp#L214-L289)。

对本 probe 最可迁移的是其日志：同时打印 global/local gravity、带/不带 bias 的
expected acc、actual acc、expected/actual gyro 与 initial state error，见
[`Logger.cpp:104-140`](https://github.com/MIT-SPARK/Kimera-VIO/blob/ce8c59b7b273ab5ac29db7e5572e1623760e19c7/src/logging/Logger.cpp#L104-L140)。

### 5.2 OpenVINS：分开静止段与 jerk，并输出 covariance

OpenVINS static initializer 把 `init_window_time` 分成两个半窗：旧半窗用于 mean
acc/gyr 与 state，较新半窗用于判定 jerk；wait-for-jerk 时要求旧半窗低 excitation、
新半窗高 excitation，不等待 jerk 时要求两者都低。它以旧半窗末尾为初始化 timestamp，
再设置 gravity-aligned orientation、`v=p=0`、mean gyro bias、acc residual bias 与显式
covariance，见
[`StaticInitializer.cpp:37-164`](https://github.com/rpng/open_vins/blob/69488123ed9362dd44b6f28e7f4680abbff1442b/ov_init/src/static/StaticInitializer.cpp#L37-L164)。

dispatcher 还用两个视觉半窗的 feature disparity 区分 still/jerk/moving，再选择 static
或 dynamic initializer，见
[`InertialInitializer.cpp:104-158`](https://github.com/rpng/open_vins/blob/69488123ed9362dd44b6f28e7f4680abbff1442b/ov_init/src/init/InertialInitializer.cpp#L104-L158)。

其 dynamic path 不把“低 IMU variance”当充分条件：它先要求 visual feature/window
数量与最小 rotation excitation，随后由多帧视觉+IMU 求 velocity/gravity，再在 MLE
中纳入 orientation、position、velocity、gyro/acc bias，并恢复 covariance：

- [初值与 rotation excitation `DynamicInitializer.cpp:166-194`](https://github.com/rpng/open_vins/blob/69488123ed9362dd44b6f28e7f4680abbff1442b/ov_init/src/dynamic/DynamicInitializer.cpp#L166-L194)
- [linear velocity/gravity `DynamicInitializer.cpp:224-480`](https://github.com/rpng/open_vins/blob/69488123ed9362dd44b6f28e7f4680abbff1442b/ov_init/src/dynamic/DynamicInitializer.cpp#L224-L480)
- [joint MLE variables `DynamicInitializer.cpp:551-744`](https://github.com/rpng/open_vins/blob/69488123ed9362dd44b6f28e7f4680abbff1442b/ov_init/src/dynamic/DynamicInitializer.cpp#L551-L744)

**可迁移模式：** adopted static window 与 detected motion window 分开记；state timestamp
必须对应实际使用的旧窗末端/起点；输出 covariance/quality，而不是只输出 state。
本片不建议立刻照搬两半窗策略，只把它作为 probe 字段与后继设计参考。

### 5.3 VINS-Fusion：gyro bias 后求 velocity/gravity/scale

VINS-Fusion 的 monocular visual-inertial initialization 先用 visual relative rotation 与
preintegration rotation Jacobian 解 gyro bias并 repropagate，见
[`initial_aligment.cpp:14-47`](https://github.com/HKUST-Aerial-Robotics/VINS-Fusion/blob/be55a937a57436548ddfb1bd324bc1e9a9e828e0/vins_estimator/src/initial/initial_aligment.cpp#L14-L47)。
随后一个多帧 linear system 求各帧 velocity、gravity、scale，按已知 gravity norm 在
tangent space refine，并拒绝 gravity norm 偏差或负 scale，见
[`initial_aligment.cpp:65-207`](https://github.com/HKUST-Aerial-Robotics/VINS-Fusion/blob/be55a937a57436548ddfb1bd324bc1e9a9e828e0/vins_estimator/src/initial/initial_aligment.cpp#L65-L207)。

实现虽计算 IMU excitation，但低 excitation 的 return 被注释，仅记录日志；不能把它
描述为 hard gate，见
[`estimator.cpp:580-609`](https://github.com/HKUST-Aerial-Robotics/VINS-Fusion/blob/be55a937a57436548ddfb1bd324bc1e9a9e828e0/vins_estimator/src/estimator/estimator.cpp#L580-L609)。
mono alignment 后 acc bias 仍以 zero repropagate；该固定 revision 没有在线性初始化中
求 `ba`，见
[`estimator.cpp:726-784`](https://github.com/HKUST-Aerial-Robotics/VINS-Fusion/blob/be55a937a57436548ddfb1bd324bc1e9a9e828e0/vins_estimator/src/estimator/estimator.cpp#L726-L784)。
stereo+IMU 因视觉已有 metric scale，初始化只做 PnP/triangulation、gyro bias 与随后
optimization，见
[`estimator.cpp:480-505`](https://github.com/HKUST-Aerial-Robotics/VINS-Fusion/blob/be55a937a57436548ddfb1bd324bc1e9a9e828e0/vins_estimator/src/estimator/estimator.cpp#L480-L505)。

**工程结论：** VINS 的 scale/gravity/velocity 结果来自多帧视觉-惯性 excitation，
不是 0.5 s static IMU；其做法不能作为从 static window 直接估 scale 的依据。

### 5.4 ORB-SLAM3：多 KF joint inertial optimization

ORB-SLAM3 等待至少 10 个 KF；stereo/RGB-D 至少 1 s，mono 至少 2 s。它先用
preintegrated delta velocity 得到 gravity direction、用相邻视觉位置差初始化 velocity，
随后 joint optimize per-KF velocities、shared gyro/acc bias、gravity direction 与
scale；stereo 中 scale vertex 固定，mono 才优化。初始化还拒绝过小 scale，见
[`LocalMapping.cc:1173-1301`](https://github.com/UZ-SLAMLab/ORB_SLAM3/blob/4452a3c4ab75b1cde34e5505a36ec3f9edcdc4c4/src/LocalMapping.cc#L1173-L1301)
与
[`Optimizer.cc:3042-3224`](https://github.com/UZ-SLAMLab/ORB_SLAM3/blob/4452a3c4ab75b1cde34e5505a36ec3f9edcdc4c4/src/Optimizer.cc#L3042-L3224)。

**工程结论：** ORB 的 `ba/gravity/v` 可辨识性来自跨 KF motion 与 visual positions；
这进一步反证“单个静止 mean acc 可独立恢复 tilt+full ba”。

### 5.5 OKVIS 补充：mean acc 只 seed pose

OKVIS 首帧对 IMU measurements 求 mean acc，仅用方向对齐 `+Z`；随后 speed/bias
state 从 zero 与 configured `a0` 开始，见
[`Estimator.cpp:109-128`](https://github.com/ethz-asl/okvis/blob/f0c9ba472b89f85030cd58dfbae03ceec7817679/okvis_ceres/src/Estimator.cpp#L109-L128)
与
[`Estimator.cpp:810-839`](https://github.com/ethz-asl/okvis/blob/f0c9ba472b89f85030cd58dfbae03ceec7817679/okvis_ceres/src/Estimator.cpp#L810-L839)。
它没有把同一 mean acc 同时宣称为独立 orientation 与 acc-bias observation。

## 6. 0.5 s 窗口能判定什么

### 6.1 只看 raw IMU

| 量 | 能否直接判定 | 边界 |
|---|---|---|
| timestamp order、span、count、dt/gap | **能** | 使用 int64 ns，不以 nominal rate 代替实测 |
| acc/gyr mean、population std、sample covariance、norm | **能** | 只是样本统计 |
| “读数近似常量” | **能** | 阈值是工程定义 |
| 平台真正静止 | **不能** | constant velocity、constant acceleration/rotation 也可低方差 |
| `bg` | **条件能** | 只有真实 angular rate 为零时 `mean_gyro≈bg` |
| gravity/roll-pitch | **条件能** | 必须假设 linear acceleration 与 acc bias 可忽略/已知 |
| full `ba` 与 roll-pitch 同时 | **不能** | `mean_acc=-R^Tg+ba` 欠约束 |
| yaw | **不能** | gravity 对 yaw 不敏感 |
| `v0`、absolute position | **不能** | `v0=0,p0=0` 是 gauge/prior |
| metric scale | **不能** | static IMU 无视觉 displacement/scale excitation |
| gravity magnitude与 parallel `ba` | **不能分开** | 两者都改变 `||mean_acc||` |
| bias RW / temperature drift | **不能** | 0.5 s 只给局部平均 |

低 std 因而最多是 necessary quality signal，不是 sufficient stationarity proof。

### 6.2 加 EuRoC reference 后，offline 能审计什么

reference 不会让 production 变得可观，但能离线检查采用的假设：

- `max ||p(t)-p(t0)||`、`max angle(R(t0)^T R(t))`、speed/velocity change：窗口是否
  真正静止；
- GT(t0) 与 support-mean `bg/ba`：state timestamp 与 estimator support 两个 bias
  reference；
- body-frame up-vector angle：初始 tilt；
- `||v_GT(t0)||`：`v0=0` 假设误差；
- measurement-model residual：axis、sign、specific-force、bias convention 是否一致；
- start/mid/end 的 GT variation：整窗 mean 是否被 residual motion/time-smearing 污染。

不能直接强结论的量：

- 从 GT quaternion/velocity 数值微分得到的 instantaneous omega/acceleration：微分会放大
  noise，应作为 secondary diagnostic；
- gravity magnitude truth：CSV 没有独立 gravity 字段；
- bias 的独立物理真值：MH reference 与同一 IMU 相关；
- yaw error：internal yaw 是 gauge；
- position at t0：internal origin 是 gauge；
- scale：要在 post-t0 visual displacement 上审计，不能从 static row 得出。

## 7. t0 truth audit 的时间与坐标对齐

### 7.1 三个时间不能混用

probe 至少命名并记录：

```text
t0_ns                adopted IMU window first sample / init state timestamp
t_mid_ns             integer midpoint, audit only
t1_ns                adopted IMU window last sample / detector IMU end
t_seed_ns            first seeded estimator state/camera timestamp
```

当前 `R_W_I0/bg0/ba0` 使用 `[t0,t1]` 全窗，却标到 t0。若 reference 在窗口内并非
常量，必须同时给两组 error：

- **state-contract error**：estimate vs GT(t0)；
- **support error**：estimate vs 同一 adopted window 的 reference statistics。

不得拿 `t_seed` GT 与 `bg0/ba0` 比较后仍称其为 t0 error。

### 7.2 timestamp association

EuRoC 论文说明 camera exposure midpoint 与 IMU 由硬件同步，post-processed GT 又由
offline estimator 做 spatial/temporal alignment；因此第一版 audit 以数据集提供的
timestamp 为合同，不另拟合自由 time offset。即便 IMU/GT nominal rate 同为 200 Hz，
本地 exact ns 仍不应按 row index 对齐。

1. 保留 POSIX timestamp 为 signed int64 ns；不要先把约 `1.4e18` ns 转 double。
2. probe 记录 estimator 实际采用的 first/last/count 与 exact mean/std；analyzer 再从
   dataset reload 同 timestamp range，验证 inclusivity 与统计逐值一致。
3. 对每个 audit timestamp，以 GT 左右两个 row bracket；exact match 直接用。
4. quaternion 用 shortest-path SLERP，dot<0 时先翻 quaternion sign；position、velocity、
   `bg/ba` 线性插值。
5. 禁止 component-wise quaternion lerp、row-index join、nearest-only 后不报 offset、
   endpoint clamp 或 extrapolation。
6. 记录 `gt_left_ns/gt_right_ns/alpha/bracket_span_ns` 与 max gap。MH_01 GT observed
   period 约 5 ms；推荐预注册 `7.5 ms` max bracket span，超限 row 标 invalid，不静默用值。
7. 不在本 probe 通过搜索时间偏移最小化 error。先报告 IMU↔GT timestamp residual；
   若发现系统相位，再独立设计 time-offset probe。

### 7.3 frame/gauge alignment

先验证/记录：

```text
q_RS convention  = Hamilton [w,x,y,z], active S->R
T_BS(imu)         = identity
T_BS(gt)          = identity
GTSAM gravity     = [0,0,-9.81007] in W_est
reference gravity = fixed direction in W_ref + evidence/assumption tag
```

令 `R_e=R_West_B(t0)`、`R_r=R_Wref_B(t0)`，`g_e/g_r` 分别是两个 world
中的 gravity vector。首要 tilt metric：

```text
u_e_B = -R_e^T * normalize(g_e)
u_r_B = -R_r^T * normalize(g_r)
tilt_error = acos(clamp(u_e_B dot u_r_B, -1, 1))
```

当前 `g_e=[0,0,-g]`，故 `u_e_B=R_e^T e_z`。仅在 `W_ref` 的 Z-up 已由数据合同/
固定配置确认时，才可同样代入 `g_r=[0,0,-g]`；否则该 metric 标 invalid。该量对
left-multiplied world yaw 不变，不会把 tilt 吸收到 alignment。

如需比较 t0 后的 pose/velocity：从 t0 horizontal heading 求一个固定 yaw `Rz(psi)`，
并设 `p_align=p_ref(t0)-Rz(psi)*p_est(t0)`；同一个 `Rz/p_align` 应用于整个 prefix，
translation/velocity 不缩放。若水平投影退化，full orientation/yaw metric 标 invalid，
仍保留 up-vector metric。禁止用 `R_r*R_e^T` 的 full SO(3) 对齐，因为它会消掉正要测的
initial tilt。

Bias 已在同一 IMU/S frame，直接做三轴差与 norm；不要随 world yaw 旋转 bias。

### 7.4 general measurement consistency residual

对 identity lever arm：

```text
r_gyr(t) = gyr_meas_S(t) - omega_RS^S(t) - bg_ref_S(t)
r_acc(t) = acc_meas_S(t)
           - R_RS(t)^T * (a_RS^R(t) - g_R)
           - ba_ref_S(t)
```

primary static check 应先用 integrated motion gate：relative rotation、position/velocity
change。只有该 gate 通过，才把 `omega=0,a=0` 代入得到 stable mean residual。由
quaternion/velocity difference 得到的 `omega/a` 版本单列 secondary，并记录 finite-
difference stencil/span，不能与 raw noise 混成一个 headline。

## 8. 最小只读 probe 合同

### 8.1 C++ sidecar 必须记录的原始事实

只在 static initialization 最终采用窗口时写一次；sidecar off 时零行为变化。

| 组 | 字段 |
|---|---|
| run identity | git HEAD/dirty、config hash/canonical、dataset path、上述文件 SHA-256 |
| model contract | gravity model vector/magnitude、MakeSharedU/D、IMU `T_BS`、GT `T_BS`、bias order/frame |
| adopted support | t0/t1/span、sample count、first/last sample ns、dt min/median/max/max-gap、attempt count |
| exact production stats | acc/gyr mean xyz、population std xyz、norm、threshold 与 strict comparator |
| optional audit stats | 3x3 sample covariance、time-weighted mean；必须与 production stats 分栏 |
| state output | `R_West_B0` matrix/quaternion、`v0`、`bg0`、`ba0`、internal origin |
| formula provenance | `u=normalize(mean_acc)`、`ba=mean_acc-g_model*u`、`bg=mean_gyr`、`v0=0` |
| lifecycle | t_mid、t_seed、seed PIM first/last/count/dt、first accepted state key/timestamp |
| consumption | `acc_mean_norm` 是否只 diagnostic、实际 PIM `gravity_model`、IMU extrinsic applied flag |

建议写原始值，不只写派生 error；offline analyzer 才读取 GT。CLI-only path 不进
config/hash，writer 失败必须明确令该 probe run 失败，不能静默少记录。

### 8.2 Offline analyzer 输出

1. 校验 sidecar schema、finite、rotation orthonormal/determinant、timestamp order、
   window span/count 与 dataset reload statistics；
2. 输出 GT bracket/gap/outside-support；
3. 输出 GT start/mid/end 与 per-sample support statistics；
4. 输出 reference stationarity：translation range、rotation range、speed max/RMS、
   velocity delta；
5. 输出 `tilt_error`、`v0_error`、`bg0/ba0` xyz/norm；
6. 把 `ba_error` 分解到 GT body up-vector的 parallel/tangent 分量；
7. 输出 static/general measurement residual 与适用性 flag；
8. 对 t0→t_seed 用 frozen yaw+translation、no-scale 比较 pose/velocity displacement；
9. 所有结论标记 `FACT / DERIVED / ASSUMPTION / INVALID`。

### 8.3 行为隔离与验收

- probe off/on 的 production `est.tum`、`kf.tum`、`diag.csv`、summary metrics 与
  config hash/canonical text 逐字节相同（timing/path metadata 除外）；
- adopted samples reload 后 count/timestamps/mean/std 与 sidecar 一致；
- synthetic orientation test 覆盖 identity、90° tilt、quaternion sign flip 与 yaw gauge；
- synthetic specific-force test 覆盖 upright/static、nonzero bg/ba、符号翻转；
- GT interpolation 覆盖 exact、SLERP、最大 gap、out-of-range；
- MH_01 两个 `T_BS=I` 与 SHA mismatch 都是 hard diagnostic failure；
- analyzer 不产生任何 estimator input，不修改 dataset 或 run artifacts。

## 9. 用 probe 选择下一刀

| 观测 | 支持的机制 | 下一步边界 |
|---|---|---|
| GT window 有明显 rotation/translation/speed | static gate false accept / state timestamp 不匹配 | 先修 gate/窗口语义；不先调 bias prior |
| GT 静止，tilt 大且 tangent `ba` error 大 | tilt/ba coupling | 设计有独立信息的 initialization；不从同一 mean acc 再造公式 |
| tilt 小、`ba` parallel error 大、`||mean_acc||-g` 同号 | gravity magnitude / parallel bias coupling | 独立 gravity/bias prior probe |
| GT 零 rotation，`bg0-bg_ref` 大 | gyro bias/axis/time support | 查 raw mean、timestamp、frame；再决定 bias init |
| `||v_ref(t0)||` 不小但 raw std 低 | zero-velocity 假设 false accept | gate 需视觉/外部 motion evidence |
| state error 小但 measurement residual 大 | sign/axis/specific-force/extrinsic/time convention | 先修合同；不扫 noise |
| t0 state 与 first seed 都接近 reference，随后 PIM prediction 漂 | post-init IMU model/noise/bias evolution | 回到 PIM residual/noise probe |
| t0/PIM 接近，posterior correction 恶化 | visual/optimizer/window | 查 factor cost 与 prior/window，不再改 init |

单一 ATE、单一 bias norm、单一 raw std 都不足以定案。至少需要“reference stationarity +
tilt/v/bg/ba + measurement residual”共同支持。

## 10. 证据缺口与最终建议

### 10.1 已确认事实

- GTSAM Z-up、specific force、sensor-frame bias 与 `T_BS` 方向已由固定源码确认；
- EuRoC `q_RS/v/bg/ba` 方向、单位与 MH_01 identity extrinsics 已确认；
- 当前 `init_g` 与 actual PIM gravity consumer 不同，必须分栏；
- mature static initializers同样依赖 stationary/zero-velocity/bias decomposition 假设；
- mature joint initializers依赖多帧 visual-inertial excitation，不来自静止窗口。

### 10.2 仍有缺口

- EuRoC CSV 不给独立 gravity vector/magnitude；`[0,0,-g]` direction 需显式合同，
  `9.81007` magnitude 来自成熟 EuRoC config；
- MH_01 attitude/bias reference 与 raw IMU 相关，不能视为独立传感器 truth；
- 未拿到实际 adopted t0 sidecar，故本文没有声称 MH_01 adopted window 真静止；
- 未实现/运行本 probe，本文没有给出 tilt/v/bg/ba 数值 verdict；
- 未评估 temperature、IMU intrinsic scale/misalignment 或 residual time offset。

### 10.3 建议

下一片只实现上述一次性 read-only sidecar + offline analyzer，先在 MH_01 回答：

```text
adopted window 是否真静止？
R tilt / v0 / bg0 / ba0 哪个先错？
GTSAM measurement residual 是否满足同一 frame/sign/time 合同？
```

在这三问有数据前，不改 initializer、gravity、noise/prior、factor 或 window policy。
