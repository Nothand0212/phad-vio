## 2. 关键发现

### 2.1 原始轨迹：前 422 帧位姿逐字节相同

`est.tum` 在 diag **i≤426** 与 ④b **完全一致**（含 i=425 大剔 24 + LM₂）。
首个位姿差在 **i=427**（Δxyz ≈ 2.7 mm，`lm_iterations` 8→7）；
至 i=428 已 Δ≈1.86 m，i=429 Δ≈4.76 m。

因此：对齐后「从首帧 ATE 就差 1.6 m」是 **全局 SE3 对齐被后半段带偏**
的假象，不是初始化分叉。

### 2.2 分叉窗口 i=425–436：丢掉 ④b 的第二次大剔+reopt

| i | ④b culled / lm / reproj_after→cull | ④e culled / lm / reproj_after→cull |
|---:|---|---|
| 425 | **24** / 21 / 297→**0.18** | **24** / 21 / 297→**0.18**（相同） |
| 426 | 0 / 14 / 257→0.18；shared=13 | 0 / 14 / 257→0.18；shared=13，obs 68→**66** |
| 427 | 0 / 8 / 0.21；shared=**32** | 0 / 7 / 0.18；shared=**29**（首分叉） |
| 430 | 0 / 4 / **0.27**；pnp ok | 0 / 95 / **9.61**；**pnp fallback**；**不剔** |
| 436 | **44** / 16 / 204→**0.26**（第 2 次 reopt） | **0** / 2 / **5.83**（无第二次自救） |

④e（与 ④c）在 i=430–438 图 RMS 持续 **5–9 px** 且 `outliers_culled=0`，
直到 i=439 才回到 ~0.3 px——mean-cull **未**在这段触发。④b 则在健康
~0.27 px 后于 i=436 再次爆到 204 并一次剔 44 点压回。

全 run cull 帧：④b **6** 帧共 72 点（2 次 ≥4 触发 reopt）；④e **5** 帧共
28 点（仅 i=425 一次 reopt）。与 summary `outlier_reopts` 1 vs 2 一致。

### 2.3 高 ATE ≠ 高重投影（后期）

④e 上 `err_trans>3` 且 `culled==0` 的帧 **1227 / 2216**；多数高误差帧
`reproj_after≈0.3 px`。说明慢性误差是 **自洽但偏了的轨迹**，不是「满图
外点残差」形态——单独末轮去 Huber 缺乏直接证据。

## 3. 假说检验

| 假说 | 判定 | 证据 |
|---|---|---|
| ④e 多轮预算不够 | **反对** | 仅 1 次成功 reopt；无 `rounds>1`；与 ④d bit-identical metrics |
| 末轮去 Huber 为第一刀 | **反对（作首选）** | 分叉后问题是丢第二次大剔；高 ATE 帧 reproj 往往已很低 |
| 观测级外点为第一刀 | **不足 / 次选** | i=430–438 高 RMS 不剔支持「mean 判据盲区」，但是 **④c 之后的继发**；应先修分叉再考虑 |
| ④d 阈值 3→4 为主因 | **反对** | ④c（仍为 3.0）ATE 已是 **4.565**，时间线同型 |
| **④c `block_culled_rebirth` + `dropTracks` 破坏大剔后自救** | **支持（主因）** | 位姿至 i=426 相同；i=426 obs 已少 2；i=427+ shared/lm/位姿分叉；④b 独有 i=436 cull44+reopt；④c/④e 同病 |
| 再拧 `max_outlier_reopts` | **否决** | 机制未触发第二轮的前提（无第二次 `culled≥4`） |

## 4. 机制解读（简）

1. i=425 两侧同样大剔 24 + reopt，图 RMS 压到 0.18。  
2. ④c 起：session `dropTracks` + estimator 拒绝复生 → 前端轨道与窗口
   landmark 集合相对 ④b 变稀（i=426 obs、i=427 shared）。  
3. 随后 ④b 在数帧内恢复低 reproj，并在 i=436 再次炸掉后二次大剔自救；
   ④c/④e 滑入 **高 RMS 但不 mean-cull** 的平台（5–9 px），再靠别的方式
   「熬」回 ~0.3 px，轨迹已偏数米。  
4. ④d/④e 未触及该分叉，故 MH_05 持平 4.565。

## 5. 结论（出口）

### 唯一推荐下一刀

**复盘并修复 ④c 大剔后路径**（`block_culled_rebirth` / session
`dropTracks` 与窗口观测的耦合）：在 **保留 MH_01 反复生 / 不回归锚**
（ATE ≤ 0.098784，`seg/re=1/0`）的前提下，恢复 MH_05 上 ④b 式
**i=425 后二次大剔+reopt 自救**（或等价的稳定恢复）。

建议 ④f 对齐前先做 **最小配置 A/B**（仍属诊断/归因，改默认前要有数字）：

1. 当前默认（对照）  
2. `--allow-culled-rebirth`（isolates reject-set；注意现行 session 仍 drop）  
3. 若 2 不足：再开「大剔后是否 dropTracks」的显式对照（可能需小开关；YAGNI
   到证据要求时再加）

验收方向（MH_05）：软改善相对 4.565；硬方向仍 &lt;1 m 或至少回到 ④b
≈3.45 并再现 i≈436 类二次自救（或证明被更稳机制替代）。

### 否决项（本轮不打）

| 项 | 原因 |
|---|---|
| 再增大 `max_outlier_reopts` / 继续拧 ④e | 预算未用上；无第二次 `culled≥4` |
| 单独「末轮去 Huber」作 ④f | 无遮罩证据；不解释 i=427 分叉 |
| 单独观测级外点作 ④f 首选 | 可能是继发补丁；先修 ④c 路径再评估 |
| 直接开 Slice ⑤ | 与 M4 耦合；MH_05 债未对准 |
| 无 A/B 就改默认阈值蒙混 | ④c 已在 T=3 上回归 |

### 升级探针 B 的缺口（若 A/B 仍不够）

- 在 i=430–438 打 **per-landmark mean vs max** / 单因子残差直方图（解释
  RMS=5–9 却 `culled=0`）；  
- 若 ④c 修复后仍平台高 RMS，再立项观测级或「图 RMS 门触发 cull」续片。
