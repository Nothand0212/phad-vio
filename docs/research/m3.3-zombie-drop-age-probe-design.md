## 行为

| 项 | 约定 |
|---|---|
| CLI | `--zombie-drop-age <n>`，`n≥0`，默认 **0** |
| 状态 | `OfflineVoSession`：`id → 连续存活帧龄`；frontend 无龄语义 |
| 入表 | 仅 **skip** 当帧的 `culled_landmark_ids`；已在表则保留原龄（`try_emplace` 龄=1） |
| 计龄 | 每帧 `tracker.process` 后、`update` 前：仍在 `FrameTracks` 则 +1，否则删项 |
| drop | `update` / skip 入表之后：龄 `≥n` 的 id 精确 `dropTracks`，并从表删除 |
| hash | **不**进 `flattenConfig` |
| 计数 | `zombie_age_drops`（冲刷次数）、`zombie_age_drop_ids`（累计 id 数） |
| n=0 | ④f（不维护表、不 drop） |

## 验收（计划）
