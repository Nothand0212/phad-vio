## 行为

| 项 | 约定 |
|---|---|
| CLI | `--zombie-drop-age <n>`，`n≥0`，默认 **0** |
| 状态 | `OfflineVoSession`：`id → 连续存活帧龄`；frontend 无龄语义 |
| 入表 | 仅 **skip** 当帧的 `culled_landmark_ids`；已在表则保留原龄（`try_emplace` 龄=1） |
| 计龄 | 每帧 `tracker.process` 后、`update` 前：仍在 `FrameTracks` 则 +1，否则删项 |
| drop | `update` / skip 入表之后：龄 `≥n` 的 id 精确 `dropTracks`，并从表删除 |
| hash | **不**进 `flattenConfig` |
| 计数 | `zombie_age_drops`（冲刷次数）、`zombie_age_drop_ids`（累计 id 数） |
| n=0 | ④f（不维护表、不 drop） |

## 验收

| 臂 | 期望 / 实测 |
|---|---|
| MH_05 `n=0` | ATE ≡④f ≈ **3.056878**；两计数 =0 ✅ |
| MH_05 `n∈{5,8,10}` | 均不毁 3.057；n=5 最优 ✅ |
| MH_01 | 未跑（升默认前必跑） |

## 矩阵结果（scratch `/tmp/mh05_zombie_age`，hash `a5e90dc7`，commit `10b2e50`；n=0 tum≡④f）

| n | ATE | RPE | drops / ids | skip | cheir | 备注 |
|---:|---:|---:|---:|---:|---:|---|
| 0 | **3.056878** | 0.772423 | 0 / 0 | 1 | 29 | ≡④f `est.tum` |
| 5 | **2.455726** | 0.711862 | 2 / 91 | 2 | 65 | 最优；二次 skip；非 ≡④e |
| 8 | 3.051629 | 0.772162 | 1 / 32 | 1 | 29 | 略优于 ④f |
| 10 | 3.052424 | 0.772334 | 1 / 32 | 1 | 29 | 略优于 ④f |

probe-b `zombie_track_n`（节选）：

| i | n=0 | n=5 | n=8 | n=10 |
|---:|---:|---:|---:|---:|
| 426 | 32 | 32 | 32 | 32 |
| 429 | 32 | 32 | 32 | 32 |
| 430 | 32 | **0** | 32 | 32 |
| 435 | 32 | 0 | **0** | **0** |
| 440 | 26 | 59 | 0 | 0 |
| 450 | 7 | 0 | 0 | 0 |

**解读**：延后 N 帧再清存活 zombie，可逃出「i+1 整批 drop ≡④e」。n=5 在 i=430 清光首批 32，并触发第二次 skip（累计 drop 91 ids），ATE 从 ~3.06 降到 ~2.46。n=8/10 在 i=435 清 32、轨迹接近 ④f。  
**不**自动升默认：先 MH_01 硬门 + 确认是否以 n=5 产品化（进 `flattenConfig`）或保持 CLI 探针。
