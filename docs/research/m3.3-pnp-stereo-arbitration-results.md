## 3. TDD 与采用边界

### 3.1 缺失行为的 RED

新增 public `StereoVoEstimator::update()` 场景：主体 shared 点的左目像素支持错误
z-translation，disparity 支持恒速 guess；另一个已有一次历史观测的 probe id 被做成
左目 RANSAC outlier。

修改生产代码前，`FallsBackWhenPnpStereoRmsIsWorseThanGuess` 连续运行 3 次均稳定
RED：

- `pnp_success` 实际为 `true`，期望为 `false`；
- `pnp_inliers` 实际为 `10`，期望为 `0`；
- PnP mask 使 graph 中只有 `10` 个 landmark，期望 fallback 保留 probe 后为 `11`。

这证明失败来自“左目 PnP 成功后缺少 stereo 仲裁”，不是测试偶然未触发 PnP。

### 3.2 最小实现

生产改动只在 `StereoVoEstimator::Impl`：

1. `tryPnpInit()` 保留与 OpenCV 2D/3D 输入平行的 shared observation 引用；
2. RANSAC pose 与 inlier 数通过后仍只生成 proposal；
3. 私有 `stereoRmsAtPose()` 在同一 PnP inlier 集上计算未白化
   `(uL,uR,v)` RMS；非法 index、non-finite 或 cheirality 令候选无效；
4. proposal 有效，且 guess 无效或
   `proposal_rms <= guess_rms + stereo_sigma_px` 时才采用；
5. 采用后才移动 inlier indices 并应用既有 mask；否则复用 guess + full
   measurement fallback，诊断保持 `pnp_success=false`、`pnp_inliers=0`。

没有新增 public API、配置键、hash 输入、CSV/summary 字段或错误状态。

### 3.3 `stereo_sigma_px` 的证据

准备期先试过 `1e-4 px` 纯数值同分带。它能修复 MH_02 prefix，但使 MH_01 ATE
从 `0.098783939` 回归到 `0.102761916 m`。诊断定位到三个健康 proposal 仅比 guess
差 `0.000551 / 0.000711 / 0.009798 px`，却被误拒；状态差异随后累积。

最终采用既有 `stereo_sigma_px=1`：

- 合成坏例 proposal 比 guess 差 `1.437 px`，仍稳定拒绝；
- MH_02 i=364 proposal 因 cheirality 无有效 score，仍稳定拒绝；
- 健康 proposal 保留，MH_01 恢复为逐字节相同；
- `AcceptsPnpWithinStereoNoise` 为该统计边界提供独立 RED→GREEN 回归。

该值来自既有观测噪声合同，不是按全序列 ATE 新增的调参旋钮。

## 8. 风险与后续约束

### 8.1 MH_03 回归的短诊断

新旧 `diag.csv` 首次 PnP 采用决策不同在 i=1388：旧路径采用 58-inlier proposal，
LM 后 `reproj_rms_after_px=132.709`；新路径回退，LM 后仅 `4.082 px`。因此首个
差异点的局部诊断支持仲裁，并非明显健康误拒。两条状态路径随后分叉，i=1405、
1628、2172 的 PnP 决策不再是相同状态上的单变量对照。

修复前 MH_03 有 `cheirality=200`、`culled=57`、`reopts=2`；当前分别为
`0/1/0`，但全局 ATE 反而增加 `0.215484 m`。现有证据说明仲裁消除了高残差/删点
路径，却改变了后续漂移形态；它不能证明应放宽当前边界。若下一片选择消化 MH_03，
应从 i=1388 后的 drift 与 i=2172 大窗口位移做独立诊断，不能直接按 ATE 调大
`stereo_sigma_px`。

### 8.2 仍未解决的全序列债

- V1_03、V2_02、V2_03 仍为 `completed_with_failures`；
- V1_03 仍有 15 段/14 re-anchor/72 failed；
- V2_03 completion 仍仅 `0.452889`，ATE 仍为 `7.671 m`；
- 本片没有修复 post-cull 零度 pose 安全债，也没有证明该债已不可达；
- 全表有明显改善不等于 M3.3 全序列质量已达标，Slice ⑤仍须重新对齐后再开。
