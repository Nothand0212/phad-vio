## 1. 目标与非目标

**唯一目标**：在保留 `skip_drop_min_culled=4` 与 `block_culled_rebirth=true`
的前提下，对 skip 当帧未 drop 的完整 `culled_landmark_ids`（mean-cull ∪
cheirality）在**下一帧** `tracker.process` **之前**执行精确 `dropTracks`，
消除长期 zombie×block，收窄 MH_05 i=427–429 shared 缺口；MH_01 不回归。

不做：

- 关整个 skip-drop / 关整个 `block_culled_rebirth`；
- 同帧末立即 drop（≈取消 skip 对 track 的效果，有回归 ④e 风险）；
- 新 CLI / `config_hash` 旋钮；扩 `diag.csv`（仍 18 列）；
- 末轮去 Huber、观测级 cull、再拧 `max_outlier_reopts`；
- Slice ⑤、IMU、TrackId≠LandmarkId 拆分、改 `phad::eval`；
- 改 frontend / estimator 默认策略（本片只动 apps session 编排）。

## 2. 已对齐的决策

| 决策点 | 结论 |
|---|---|
| 做法 | Session 内 `pending_drop`（composition root） |
| 时机 | **下一帧**；在 `tracker.process` **之前**冲刷 |
| 集合 | skip 时并入完整 `culled_landmark_ids`（非仅 `outliers_culled`） |
| 配置 | **无新旋钮**；行为即新默认 |
| 可观测 | `FrameCounts` + `summary.robustness.deferred_drops` / `deferred_drop_ids`；不进 diag / hash |
| skip 判据 | 不变：`outliers_culled ≥ skip_drop_min_culled`（默认 4） |
| 立即路径 | 非 skip 的 cull 仍当帧 `dropTracks`（④c） |
| 门控 | MH_01 硬 → MH_05 软 + `--probe-b` 归因；不够停全序列 |
| Slice ⑤ | 不开 |
| 票务 | 续 [#24](https://github.com/Nothand0212/phad-vio/issues/24)；称 **Slice ④g** |

基数（Probe B）：i=425 `outliers_culled=24`（skip 门）vs
`len(culled_landmark_ids)=32`（pending / zombie 目标集）。

## 4. 数据流

```text
每帧:
  if pending_drop 非空:
      tracker.dropTracks(pending_drop)
      ++deferred_drops
      deferred_drop_ids += |pending|
      pending_drop.clear()

  tracks = tracker.process(...)
  update = estimator.update(...)

  if drop_culled_tracks && !culled_landmark_ids.empty():
      if outliers_culled >= skip_drop_min_culled:   # 且 N>0
          ++drops_skipped
          pending_drop ∪= culled_landmark_ids     # 全集
      else:
          tracker.dropTracks(culled_landmark_ids) # 立即

  写 diag / tum（18 列不变）

session 结束 / 提前退出:
  if pending 非空 → 再冲刷一次（计入同一计数）
```

不变量：

| 项 | 规则 |
|---|---|
| skip 当帧 | 不调用立即 `dropTracks`；只记 pending |
| 连续 skip | 下一帧帧首先冲刷再 process；不会跨过冲刷点无限堆积 |
| block | 默认 true；本片不改 |
| `config_hash` | 无新键；与 ④f 默认可相同，产物靠 **commit** 区分 |

## 5. 错误与诊断

| 项 | 约定 |
|---|---|
| `dropTracks` 失败语义 | 与现有立即路径一致 |
| 提前退出 | 冲刷 pending 再收尾 |
| `diag.csv` | 仍 18 列 |
| `summary.json` | `robustness.deferred_drops`、`robustness.deferred_drop_ids`（缺省 0） |
| `warnings` | deferred drop **不**进 warnings |
| Probe B | 合同不变；门控可开 `--probe-b` |
| 日志 | 可选汇总；不刷每 id |

## 6. 测试与验收

### 单测

- skip → 本帧不立即 drop；下帧 process 前 pending 清空且 tracks 不再含那些 id
- 无 skip 的 cull → 仍立即 drop
- diag 18 列；`FrameCounts` / summary 含 deferred 计数
- `max_frames` / 提前结束 → pending 被冲刷

### 门控顺序

1. **MH_01 硬门**：ATE ≤ **0.098784**；`reanchors=0`；期望
   `drops_skipped=0`、`deferred_drops=0`
2. **MH_05 软门**（对照 ④f ≈3.057 / `a5e90dc7`）：
   - ATE 改善或不回到 ④e≈4.565 灾难平台
   - `--probe-b`：i=425 skip 后，i=426+ 对 425 cull 集 `zombie_track_n`
     迅速归零；427–429 shared 相对 ④f 收窄
   - 期望 `drops_skipped≥1` 且 `deferred_drops≥1`
3. 不够 → **停全序列**
