## 1. 目标与事实

当前 default runtime 会从 `gyro_visual` 自动进入 B5 `full_visual_inertial`。这一 stage
已经被真实 MH_01 证据否决：

| run | ATE / 1 s RPE translation RMSE | paired VO | 结论 |
|---|---:|---:|---|
| raw B5 | `0.249563 / 0.0186294 m` | `0.0809641 / 0.0177812 m` | 双 FAIL |
| calibrated B6 | `0.0963460 / 0.0181547 m` | 同上 | 双 FAIL |
| frozen-`ba` | `0.691356 / 0.0334161 m` | 同上 | 双 FAIL |

B6 的 causal velocity-history shadow 也没有 production 候选。继续让已否决 B5 作为
default，不是“保留未来能力”，而是让当前可运行层主动进入已知更差状态，并把
gyro-only objective support 截断为 20 帧。

本片唯一目标是：**删除 B5 runtime implementation，恢复已验证健康、行为明确的
`vision_only → gyro_visual` 两阶段 estimator，并取得完整 B3 objective 证据。**

这不宣称 B3 已完成 M4.4。B3 在 MH_01 仍是 ATE FAIL/RPE PASS；恢复它只是回到最近的
可工作层，为下一把真正的 VIO 改动提供无混叠基线。

## 2. 模块与 interface

### 2.1 保持的 seam

外部 seam 仍是：

```text
StereoVoEstimator::addImuMeasurement(...)
StereoVoEstimator::update(KeyframeMeasurement, is_keyframe)
```

caller 不新增 mode flag、adapter、factory 或 fallback。`enable_imu=false` 仍完整走 VO；
`enable_imu=true` 在 static audit 与 visual/gyro bias alignment 成功后进入
`gyro_visual`，此后保持该 mode，直到既有 gap/re-anchor 合同处理状态。

### 2.2 删除的 implementation

删除而非隐藏：

- runtime `ImuAlignmentFrame` history、10 s train/1 s held-out activation transaction；
- `full_inertial_active`、gravity/velocity/shared accelerometer-bias optimizer state；
- `ImuFactor`、`V/B` keys、full prediction、full graph cost decomposition；
- full-only estimator options 与 config snapshot keys；
- production-only C++ `imu_alignment` module 及其 tests；
- `FusionMode::kFullVisualInertial` 与 full-only state-sidecar columns。

历史 research 文档、raw benchmark artifacts、以及读取既有 artifacts 的 Python probes
保留；它们是负结果证据，不是 runtime compatibility path。

### 2.3 保持的诊断合同

- static init snapshot 继续报告 audit-only gravity direction、zero initial velocity 与
  accelerometer-bias estimate；这些不进入 production graph；
- `diag.csv` 已有 `bias_acc_*` 列是既有 benchmark 格式，继续为零，避免未经确认破坏
  数据格式；注释明确它不是 gyro-only posterior state；
- `vio_state.csv` 保留 gyro prediction/graph-initial/posterior 与新增 gyro objective；
  full-only alignment、velocity/gravity、factor-cost columns 删除。

## 3. 数据流与事务

```text
raw IMU ──► non-blocking static audit ──► initial bg seed
   │
   └──────► accepted visual rotations ──► one shared bg alignment
                                            │
stereo frames ──► pure VO warm-up ──────────┴─► stereo + AHRS graph
                                                       │
                                                       └─► gyro_visual forever
```

事务规则保持：

1. static collecting 不阻塞视觉；timeout/gap 仍显式失败或重置；
2. gyro activation update 本身仍是 vision-only，下一次 update 才建 AHRS factors；
3. failed/rejected update 不提交 window、bias evidence、pending IMU 或 objective；
4. normal-frame pose initial ownership 仍属于 visual CV/PnP；gyro prediction只作诊断；
5. accelerometer measurement 在 static audit 完成后不得影响 trajectory、factor count、
   fusion mode 或 accepted schedule。

## 4. 错误与诊断

- 删除 full stage 后不存在“alignment pending/rejected”静默状态；相关字段也不输出零值
  冒充一次未发生的估计；
- `vio_state.csv` 的 gyro row 缺 objective、factor count 不一致或 nonfinite 时仍失败；
- IMU interval gap 继续沿既有 gyro contract 显式处理，不降级成 hidden full/VO switch；
- benchmark `meta.json` 必须不再出现 full-only config keys，运行时 snapshot 与 config
  hash 同源。

## 5. 测试与验收

### 5.1 TDD seam

测试只穿过既有 `StereoVoEstimator::update()` seam：构造超过 11 s 的两条相同 gyro/
visual、不同 accelerometer 轨迹；旧代码应进入 full 或改变结果而红，新代码必须：

- 所有 activation 后 accepted rows 都为 `gyro_visual`；
- `imu_factor_count`/full mode interface 已删除；
- 两条 trajectory、gyro factor count、bias 与 status sequence 一致；
- state probe 每条 gyro row 都有 objective。

再更新 state writer/CLI/config schema tests；不测试 private flag 或内部函数。

### 5.2 MH_01 行为门

恢复后的主三产物应与已存 B3 `m44_gyro_visual_init_b3` 逐字节相同。若不相同，先定位
差异，不解释 objective。随后生成完整 state sidecar：

- expected vision-only=`2001`、gyro-only=`1680`、full=`0`；
- sidecar on/off 主三产物逐字节相同；
- 运行 `gyro_graph_objective_probe.py`，取得长期 boundary/interior/newest 分布与时间桶
  所需 support。

若完整 objective 仍不支持 boundary robustification，则正式关闭该方向，下一设计转向
标准 joint state/marginalization；不能凭 20 帧或单序列阈值实现 factor gate。

### 5.3 最终门不变

本片不会让 B3 自动晋级。M4.4 只有在 MH_01、MH_05 及要求的 EuRoC 11 序列 paired
exact-common ATE 与 1 s RPE 都严格 `VIO < VO`、且健康门不退化时才完成。
