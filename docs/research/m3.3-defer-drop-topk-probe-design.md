# M3.3 子集延后 drop 探针（`--defer-drop-topk`）

日期：2026-08-02  
状态：**已编码（探针）** — 默认 k=0（④f）；不进 `config_hash`。  
相关：

## 行为

| 项 | 约定 |
|---|---|
| CLI | `--defer-drop-topk <k>`，`k≥0`，默认 **0** |
| 选取 | skip 当帧：`culled_landmark_ids` 按 id **升序**取前 k |
| 时机 | 下帧 `tracker.process` 前 flush（同 ④g） |
| hash | **不**进 `flattenConfig` |
| 计数 | flush 累加 `deferred_drops` / `deferred_drop_ids` |
| k=0 | ④f（skip 且不排队） |
| k≥\|culled\| | 等价完整延后 drop（MH_05 上期望 ≈④e） |

## 矩阵验收

MH_05：k∈{0,4,8,16,32}；k=0 ≡④f；k=32 ≡④e 自检。
