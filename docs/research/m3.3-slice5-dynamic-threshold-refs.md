## 2. DKB-SLAM 运动加权自适应阈值（首选方案，公式已验证）

**文献**：Sun et al., "DKB-SLAM: Dynamic RGB-D Visual SLAM with Efficient Keyframe
Selection and Local Bundle Adjustment", *Robotics* (MDPI) 2025, 14(10):134。
**RGB-D 系统（无 IMU）——与我们的纯双目 VO 约束相同，机制可直接迁移**（双目
也有度量尺度）。

### 公式（论文 §3.2）

```text
# 滑动窗口平均（Eq. 17-18）：最近 N=10 帧
Δθ̄ = 平均每帧旋转角变化（deg）
Δt̄ = 平均每帧平移变化（m）

# 运动状态权重（Eq. 19-20），ε = 1e-5
w_θ = Δθ̄ / (Δθ̄ + Δt̄ + ε)     # 纯旋转 → w_θ→1
w_t = Δt̄ / (Δθ̄ + Δt̄ + ε)     # 直线 → w_t→1

# 对数缩放（Eq. 21-22）
M_θ = log(1 + w_θ·Δθ̄)
M_t = log(1 + w_t·Δt̄)

# 归一化（Eq. 23-24），Θ_max=45°（VINS 验证的旋转重叠上限），t_max=10m
F = (M_θ + M_t) / [log(1 + w_θ·Θ_max) + log(1 + w_t·t_max)]

# 自适应阈值（Eq. 25）
T = T_max − F·(T_max − T_min)    # T_min=10, T_max=30 px
```

**判定**：当前帧视差 < T → 非关键帧；大运动 → F→1 → T→10（密集 KF）；
低运动 → F→0 → T→30（稀疏 KF）。

### 迁移到 phad-vio 的关键点

1. **决策度量保持**：继续用平均视差（px）做判定，只用 F 滑动 T∈[10,30]
2. **关键微妙点**：DKB 的决策度量是**未补偿**的 Δθ+Δt。纯旋转时 Δθ 大 →
   密集触发关键帧——这与我们 V1_01 的证据一致（需要旋转时密集 KF）。
   如果用旋转补偿视差（VINS 式），纯旋转视差≈0 永不触发——V1_01 会退化。
   **所以保持未补偿视差作为决策度量**，用 F 调节 T
3. 无公开代码（需自实现，公式已足够）

## 3. 旋转信号来源（无 IMU 排名）

| 方案 | 排名 | 依据 |
|---|---|---|
| **(a) 位姿链旋转（恒速外推）** | 首选，免费 | GTSAM 图里 last-KF→prev 旋转已精确；外推最新帧 R_cur ≈ R_prev·ΔR。DSO 实质如此 |
| (b) 本质矩阵分解（5pt RANSAC） | 精修用 | 快速旋转时条件良好；但纯旋转/平面场景退化（EuRoC MH 走廊正是平面主导）|
| (c) 单应分解 | 仅 fallback | 平面/纯旋转鲁棒，深度变化场景退化；标准选择器 H/E inlier 比 >0.45 |
| (d) 光流方向一致性 | 分类器辅助 | 最便宜但最弱，不作旋转估计 |

**推荐**：(a) 为基础 + (b) 在 RANSAC inlier 充足时精修。

## 4. 旋转帧策略（三选一）

| 策略 | 做法 | 适配 |
|---|---|---|
| (i) DKB 式 | 未补偿视差让旋转帧密集触发 KF | **与 V1_01 证据一致，首选** |
| (ii) RD-VIO 式 | θ_max ≤ θ_rot 检测 R-frame，作轻量子帧 | 复杂，θ_rot 未公开需标定 |
| (iii) DSO 式 | 抑制纯旋转关键帧 | V1_01 证据显示有害 |

**推荐 (i)** + 旋转累积超过 Θ_max=45° 时即使视差小也强制插关键帧。

## 6. 其他方案（备选）

- **Kim 2020**（自适应阈值 vs 平均特征跟踪长度）：多项式拟合，系数未公开；
  概念可复制（阈值依赖可测的跟踪统计量）

  W=5 窗口，k=1.5，γ=0.95 decay

## 9. 动态阈值实施结论（2026-08-06 深挖）

### 三个根因（由数据确认）

1. **量纲不匹配**（V2_02/V2_03）：DKB `w_θ=Δθ/(Δθ+Δt)` 度米直接相加，慢速走廊
   `dt~0.01m` 被 `dR~1°` 碾压（wR=0.96）→ T 被压 → 关键帧过密。已修：归一化
   权重（Δθ/5°, Δt/0.1m）。
2. **临界带相位敏感**（MH_03/MH_05）：帧间视差 27-30px 恰在阈值边界。T 微降
   （30→28.5）即改变 KF 触发帧——滞回后 kf 率恢复（31.8%→27.7%≈固定 25.8%）
   但 ATE 不变（0.611→0.595 vs 固定 0.310）。**KF 位置交错**（滞回独有
   70,72,74 vs 固定独有 71,73,75）：同密度不同相位，BA 窗口内容不同。
3. **checkpoint 数据错误**：⑤c V1_02 实际 2.617（非记录的 0.617），动态 1.800
   是改善——修正后动态为 7 改善 / 4 退化。

### 结论

MH_03 类序列（视差恰在阈值附近）对任何 T 变化**相位高度敏感**——继续调阈值
（Θ_max、归一化、滞回）都无法稳定。要根本解决需：
- 换 KF 判据（DSO rotation-compensated flow / ORB track-ratio / Kimera disparity）
- 或回到固定 30px（⑤c 状态，MH_03 0.310 最优）
