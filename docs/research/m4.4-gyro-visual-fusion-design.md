## 1. 目标、非目标与决策

### 1.1 目标

在不消费 accelerometer、gravity 或 velocity state 的前提下，把相邻接受帧之间的
gyro 预积分旋转与一个共享 gyro bias 接入既有 stereo BA。该 vertical slice 必须：

1. 保持 `enable_imu=false` 的 VO 行为与主产物不变；
2. 消除当前 static initializer 的 gravity/acc-bias tangent 混淆对生产轨迹的影响；
3. 在 MH_01 同 timestamp support 上使 ATE 与 1 s RPE translation RMSE 都严格优于
   VO，否则不晋级；
4. 保留将来“gyro-first → full inertial”演进所需的原始 IMU segment 与事务边界，
   但本片不预留空接口或未消费配置。

### 1.2 已否决方案

**事实：** MH_01 static truth audit 测得初始 gravity tilt `0.8435°`、acc-bias
tangent error `0.1496 m/s²`；PIM prediction 在 optimizer 前已经劣于 VO。现有
noise/prior/window 矩阵均无收益。

**新增诊断事实：** 用同一 MH_01 的 metric stereo VO poses 与 raw IMU 做线性原型：

| 窗口 | unknown | 条件数 / 结果 |
|---|---|---|
| `0.95 s` | `v_i + g + ba` | `4.9e5`，得到百量级假 bias |
| `3.95 s` | `v_i + g + ba` | `8.6e4`，仍为十量级假 bias |
| `9.95 s` | `v_i + g + ba` | `5.1e4`，仍为十量级假 bias |
| `19.95 s` | `v_i + g + ba` | `1.15e4`，gravity tilt 仍约 `44.5°` |

这些解的 measurement RMS 仍只有 `2.6e-4..4.7e-4`，说明“低残差”不能区分
真实解与退化解。固定 static bias、只求定模 gravity 时条件数降至约 `40`，但 tilt
仍为 `0.80..0.83°`，没有消除根因。

因此否决：

- 静止通过后立即联合求 `gravity + full ba + velocities`；
- 只做 gravity norm refinement；
- 继续调整 Combined factor 的 acc noise、bias prior 或 static window；
- 用 EuRoC ground truth bias 反馈 production。

### 1.3 选择 B：gyro-first

采用可分层演进的 B：

```text
raw stereo + raw gyro
        │
        ├─ static low-variance window → gyro bias seed
        │
        └─ visual X/L graph + relative gyro factors + shared bg
                                │
                                └─ pose-only VIO output
```

accelerometer 仍被同步和保存在原始 segment 中，但本片 production graph 不读取它。
这不是静默降级：diagnostics 明确标识 rotation-only fusion，且旧的
`CombinedImuFactor` 路径从 production 删除，不保留双实现开关。

一手模式依据：

- GTSAM `PreintegratedAhrsMeasurements` 对 gyro 做 bias correction、body-frame
  conversion 与 covariance propagation：
  [AHRSFactor.cpp](https://github.com/borglab/gtsam/blob/2f3e56c0ddbd3a1aa54ed043643b553d26a069f6/gtsam/navigation/AHRSFactor.cpp)；
- Kimera online alignment 先用视觉相对旋转与 PIM rotation 求 gyro bias，并在进入
  gravity/velocity alignment 前检查 rotation residual：
  [OnlineGravityAlignment.cpp](https://github.com/MIT-SPARK/Kimera-VIO/blob/ce8c59b7b273ab5ac29db7e5572e1623760e19c7/src/initial/OnlineGravityAlignment.cpp#L167-L206)；
- VINS-Fusion 同样先解 gyro bias、repropagate，再做 gravity/velocity：
  [initial_aligment.cpp](https://github.com/HKUST-Aerial-Robotics/VINS-Fusion/blob/be55a937a57436548ddfb1bd324bc1e9a9e828e0/vins_estimator/src/initial/initial_aligment.cpp#L14-L47)。

本设计只迁移“先旋转、后平移惯性”的阶段边界，不复制上游 mono scale 初始化。

## 2. 模块边界

### 2.1 `phad::estimator`

`StereoVoEstimator` 继续是唯一 factor-graph owner。GTSAM 类型留在 PIMPL：

- private `PoseAhrsFactor`：变量为 `Pose3 X_i / Pose3 X_j / Vector3 bg`，内部只取
  pose rotation，再调用 GTSAM PIM 的 `computeError`；translation Jacobian 恒为零；
- private `rebuildAhrsPreintegration`：从 `WindowFrame::imu_samples` 即时重建，
  `biasHat=上一轮共享 bg`；
- 每个窗口只有一个 shared `bg` variable，不创建 `V_i` 或 full `B_i`；
- stereo factors、landmark 生命周期与 cull/reopt 事务不搬层。

`imu_rotation.hpp/.cpp` 仍服务 keyframe evidence 的只读积分，不承担 graph ownership；
graph PIM 不通过 Eigen result 反向拼装 GTSAM 对象。

### 2.2 `apps/`

composition root 不新增 fusion policy。现有 `--no-imu` 仍是唯一产品开关：

- `enable_imu=false`：纯 VO；
- `enable_imu=true`：gyro-first VIO。

不新增 `--gyro-only` / `--legacy-combined` 兼容开关。probe sidecar 只消费 estimator
read-only diagnostics，不控制 estimator。

### 2.3 公共类型

公共 header 继续只暴露 Eigen/POD。新增一个枚举值或布尔诊断，明确当前接受状态是
`gyro_visual`，并把以下事实分开：

- `bias_gyro`：本帧 graph posterior shared bg；
- `bias_acc`：本模式无 posterior，主 diag 输出零；
- `imu_init.acc_*`：只读 static-window audit candidate，不是 graph-consumed bias；
- velocity state：本模式不存在，不得用零值冒充有效估计；predicted pose 的
  translation 仍来自视觉恒速 guess，不称 inertial translation prediction。

## 3. 数据流与状态事务

### 3.1 静止阶段

保留连续 IMU 拼接、gap reset、0.5 s low-variance gate 与 30 s sticky timeout，但
static detection 必须与纯视觉估计并行，不能以 `kRejected` 丢弃视觉帧。检测通过前：

1. `enable_imu=true` 与 `enable_imu=false` 使用相同视觉 seed、窗口更新和 keyframe
   feedback 时间轴；
2. 当前帧仍可发布 `kOk` 视觉估计，同时以 `init_pending=true` 明示 gyro 尚未 ready；
3. raw IMU interval 随接受帧保存为后续 visual/gyro alignment evidence，但 graph 不建
   gyro factor；
4. 30 s 内仍无合格低方差窗时返回 sticky `kFailed`，不得静默宣称 VIO ready。

检测通过时：

1. `bg_seed = mean_gyro`；
2. `acc_mean / acc_std / gravity candidate / ba candidate` 只进入一次性 init audit；
3. 不重播、不重锚、不改变既有视觉窗口；`bg_seed` 只作为 gyro alignment 初值；
4. 不创建虚拟 `t0` NavState，不从 accelerometer `Predict` pose/velocity；
5. gyro activation 还必须独立满足 visual/gyro alignment support 门，且只影响下一次
   update。

首个视觉 seed 保持既有 VO identity gauge。static gravity-aligned rotation只写入 init
audit，不得回写生产 pose；否则即使 graph 不消费 accelerometer，也会让 IMU-on 与
IMU-off 在 gyro factor 激活前产生不同 estimator/keyframe schedule。

### 3.2 正常帧

对上一接受帧 `i` 到当前候选 `j`：

1. update 入口先把被拒帧以来的 IMU 段拼进 `pending_imu`；
2. 用当前 shared `bg` 预积分得到 `R_Bi_Bj`，作为只读 prediction diagnostics；
3. 正常有 overlap 的 frame 仍以既有视觉恒速 pose 驱动 PnP/graph initialization，
   不让 gyro prediction 改变 PnP basin 或 inlier schedule；只有视觉断链 re-anchor
   可用 `R_W_Bi * R_Bi_Bj` 替换 anchor rotation；
4. 接受后 `cur.imu_samples = pending_imu`，graph 为每个连续、非 gap 窗口边加
   `PoseAhrsFactor`；
5. optimizer 回写 `X/L/shared bg`；所有窗口 frame 的 gyro bias 同步为该 posterior；
6. 只有 `kOk` 消费 pending；`kRejected/kFailed` 保留并在下一候选继续积分。

factor residual 定义：

```text
R_pred_j = R_W_Bi * ΔR_ij(bg)
e_R      = Log(R_W_Bj⁻¹ * R_pred_j)
```

noise 以 `PreintegratedAhrsMeasurements::preintMeasCov()` 为底，再加
`I * alignment_residual_rms_rad² / 3`。后者来自同一批 visual-vs-gyro alignment
residual，把未由 white-noise PIM 表达的相关 mismatch 纳入权重；不是人工 knob。
gyro density 仍按 `gyr_nd²` 写入 params。shared bg 以 visual alignment 结果为 prior
target，sigma 复用 `imu_prior_bias_gyro_sigma`。

### 3.3 窗口与重建

gyro factor 要求窗口相邻 frame 的 IMU segment 与 pose pair 一一对应，因此 IMU-on
仍只 `pop_front`，不逐出中间 frame。

与 full inertial 不同，gyro-only 无法约束 translation dropout：

- zero overlap keyframe：走既有 re-anchor 质量门，anchor rotation 可用 gyro 外推，
  translation 用视觉恒速；
- zero overlap non-keyframe：拒绝；
- empty observations：拒绝；
- gap：该边不建 gyro factor，视觉路径照常；若视觉也不足，显式拒绝。

不得用“rotation 有约束”把无 translation constraint 的 frame 送进 LM，避免
indeterminant system 或虚假成功。

### 3.4 cull / reopt

LM1 与每轮 outlier reopt 都重建同一 gyro graph。每轮事务 snapshot 必须包含 shared
bg；失败回退 `window/landmarks/bg`，pending IMU 仍遵守入口累计合同。

## 4. 错误与诊断

### 4.1 显式失败

- non-finite/逆序 IMU：沿现有 sync / rotation integration error 返回；
- PIM covariance 非有限、非对称或不能构造 Gaussian：`kFailed`，保留原异常原因；
- optimized pose/bg 缺失或非有限：事务回滚并 `kFailed`；
- static init timeout：sticky `kFailed`；
- 无 translation constraint：`kRejected`，不冒充 gyro propagation pose。

### 4.2 新 diagnostics

每个接受帧至少可观察：

- `fusion_mode = gyro_visual`、gyro factor count 与 alignment residual RMS；
- shared bg posterior；
- 本候选 gyro prediction 是否有效、积分 sample count / interval；
- predicted / posterior pose（probe 离线计算 rotation correction）；
- accel/velocity 不进入该 sidecar schema。

CLI-only sidecar 只记录上述值，不改变 graph；probe-off/on 的 `est.tum/kf.tum/diag.csv`
必须逐字节一致。

## 5. 测试与验收

### 5.1 红测试

1. synthetic constant rotation：视觉 pose 初值带扰动，posterior relative rotation 靠近
   gyro truth，translation 与 VO solution 一致；
2. synthetic known gyro bias：shared bg 从 seed/prior 被多边视觉旋转约束恢复；
3. accelerometer adversarial：同一 gyro、任意巨大 acc 值产生逐字节相同 pose/bg；
4. gap：缺边不建 factor，视觉仍可解；
5. empty/zero-overlap non-keyframe：拒绝而非仅靠 gyro 接受；
6. reopt failure：pose/landmark/bg 回滚，pending interval 不丢；
7. IMU-off 既有 tests 与 byte sentinel 不变。

### 5.2 MH_01 诊断门

先只跑 MH_01，保持 tracker/KF/session 与 static gate 不变。必须记录完整
`meta.json.config_canonical_text`，并与既有 VO run 在 exact common timestamps 比较：

```text
primary:
  ATE_translation_gyro_vio < ATE_translation_vo
  RPE_translation_1s_gyro_vio < RPE_translation_1s_vo

hard health:
  failed = 0
  finite trajectory
  no completion/coverage regression relative current VIO support
  segments/reanchors 有显式解释

diagnostic:
  ATE/RPE rotation
  bg error vs EuRoC reference（相关 reference，不称独立 truth）
  gyro prediction→posterior correction buckets
```

当前 exact-common VO 红门约为 ATE `0.08319 m`、RPE `0.01833 m`；实际命令重跑值
为准，不能把文档常数当运行结果。

### 5.3 停止与晋级

- MH_01 primary 任一不严格改善：停止，不跑 11/11；先按 rotation residual、bg drift、
  pose correction 与 visual reprojection 分解失败；
- MH_01 通过：跑 IMU-off sentinel，再跑 EuRoC 11/11；
- 11/11 的产品门是每序列 exact-common VIO 同时严格优于 VO，且健康门通过；
- gyro-first 未通过前，不重新接入 accelerometer；通过后，full inertial activation 另立
  一片，以 excitation/condition/residual 门为前置条件。

## 6. 证据边界

**已确认：** 当前根因在 static initializer / first PIM 之前；gyro 通道的 initial error
远小于 acc tangent error；成熟实现均先处理 rotation/bg；GTSAM 有直接可复用的 AHRS
PIM 与 covariance。

**推断：** rotation-only constraint 可能降低视觉旋转噪声，并通过 stereo BA 的 pose-
landmark coupling 改善 translation；是否足以严格胜过 VO 必须由 MH_01 日志回答。

**未确认：** gyro-first 能否在全部 11 序列逐序列胜过 VO；shared constant bg 对长序列
温漂是否足够；这些不能从 MH_01 或上游源码外推。

## 7. 实现后证据（2026-08-10）

清理后的 `m44_gyro_align100_clean_b` / `f6808356` 已删除 production
`CombinedImuFactor`、`V/B/ConstantBias` 状态与 5 个无 consumer 配置键。它与清理前
residual-covariance 候选的 `est.tum/kf.tum/diag.csv` 逐字节相同。

MH_01 exact-common 3240 poses 上，gyro-first 的 ATE/RPE translation RMSE 为
`0.0801837 / 0.0169006 m`，配对 VO 为 `0.0831874 / 0.0183341 m`，两项严格
改善；failed=0。IMU-off sentinel 与冻结 VO reference 三份主产物逐字节相同。

因此 §5.2 首门和 IMU-off sentinel 已通过，但它们尚未隔离 blocking init 对 schedule
的影响，不能单独证明 gyro factor 的跨序列收益。

### 7.2 B2 实现结果与 graph-initial 归因

B2 在 MH_01 550 帧、跨 static ready 的真实数据哨兵上使 VIO/VO 的 `est.tum`、
`kf.tum` 以及 status/window/prior/KF schedule 投影逐字节相同。全程复跑也确认
gyro 激活前 2001 poses 的 ATE/RPE 与 VO 完全相等。

但全程 3681 exact-common poses 上，B2 为：

| metric | VIO | VO | VIO − VO | verdict |
|---|---:|---:|---:|---|
| ATE translation RMSE (m) | `0.0835455` | `0.0809641` | `+0.0025814` | FAIL |
| RPE 1 s translation RMSE (m) | `0.0170120` | `0.0177812` | `-0.0007692` | PASS |

active 1680 poses 单独对 VO 的 ATE/RPE 为 `0.0926759/0.0192903` 对
`0.0793033/0.0207739`。新增 graph-initial probe（主产物与 B2 逐字节相同）进一步
测得：

| active path | ATE (m) | RPE (m) |
|---|---:|---:|
| raw gyro prediction | `0.0926101` | `0.0194998` |
| PnP 后、LM 前 graph initial | `0.0926028` | `0.0195770` |
| posterior | `0.0926759` | `0.0192903` |

PnP 成功率为 `1678/1680`，却几乎原样保留 gyro prediction 的全局形状；AHRS graph
相对 graph initial 只增加 `0.0000731 m` ATE，并改善 `0.0002867 m` RPE。故 B3
按 §3.2 恢复正常帧 visual initialization ownership；这是由路径分解选择的单一改动，
不同时调整 factor covariance 或 bias model。

### 7.3 B3 与 covariance 归因结果

B3 `m44_gyro_visual_init_b3/f6808356` 在 MH_01 全程 3681 exact-common poses 上：

| metric | VIO | VO | VIO − VO | verdict |
|---|---:|---:|---:|---|
| ATE translation RMSE (m) | `0.0833210` | `0.0809641` | `+0.0023569` | FAIL |
| RPE 1 s translation RMSE (m) | `0.0168992` | `0.0177812` | `-0.0008820` | PASS |

B3 恢复 visual initial-value ownership 后仍未过 ATE 门。active suffix 的 raw gyro
prediction、graph initial、posterior ATE 分别为
`0.0926003/0.0926168/0.0926643 m`，RPE 分别为
`0.0192969/0.0193894/0.0190702 m`；optimizer 仍主要改善局部 RPE。

随后对 alignment-residual covariance 做 `0..2` 的 9 点 sweep。所有点健康门通过，
但没有一个同时严格优于 VO；最小 ATE 是 `scale=1.2` 的 `0.0825194 m`，仍 FAIL。
临时 scale 接口已删除。reference attitude 对照同时显示固定 bias gyro interval 的
rotation error RMS 为 `3.436e-4 rad`，优于 VO 的 `5.575e-4 rad`；所以结论不是
“gyro 无信息”，而是 pose-only rotation factor 不足以让 translation ATE 晋级。

下一步不恢复旧 Combined 初始化。旧路径已测得 `0.8435°` gravity tilt 与
`0.1496 m/s²` tangent accelerometer-bias error。先以只读 probe 验证成熟实现采用的
staged alignment：已知 gyro bias 后、stereo scale 固定，只解 velocities + gravity，
并以 reference accelerometer bias 仅做离线 oracle 上界。probe 不能过可观性、残差与
预测误差门时，不进入 production graph。
