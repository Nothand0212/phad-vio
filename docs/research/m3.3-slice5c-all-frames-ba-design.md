## 1. 目标

方案 C（VINS/OKVIS/Basalt 设计）：**所有帧都进窗口参与 BA**，非关键帧不再是
PnP-only。消除非关键帧位姿质量差的根本来源。

## 2. 背景

⑤b 验证结果：V1_01 非关键帧位姿质量是根本瓶颈（阈值 30→15→10px 持续改善但
收敛慢；97.9% 关键帧率时 ≈ 基线 0.173）。开源证实：VINS 最新帧永远是窗口 BA
状态，非关键帧（MARGIN_SECOND_NEW）只改变哪个旧帧被边际化；Basalt 所有帧都是
优化变量。

## 3. 设计

### 3.1 窗口语义变化

| | 当前（⑤b） | ⑤c |
|---|---|---|
| 窗口内容 | 仅关键帧（≤10） | **所有帧**（关键帧 + 非关键帧） |
| 非关键帧位姿 | PnP + pose-only 精修 | **窗口 BA 精修**（与关键帧同路径） |
| 非关键帧 seed landmark | 不 | 不（仅关键帧 seed） |
| 非关键帧 reanchor | 不 | 不（仅关键帧可 reanchor） |
| 驱逐 | 满 10 pop 最老 | **优先 pop 非关键帧**，无则 pop 最老 |

### 3.2 实现：非关键帧走完整 BA 路径

删除 `update(keyframe=false)` 的提前返回（当前 `:1258-1388`），让非关键帧继续
走完整流程（backproject → push 窗口 → buildGraph → LM）。只加两处 gate：

```cpp
// 1. 非关键帧不 seed 新 landmark（跳过 backproject 块）
if ( keyframe )
{
  for ( observation : candidate.observations )
  {
    if ( 新 id ) backproject...
  }
}

// 2. 非关键帧不触发 reanchor（overlap_broken 时）
if ( overlap_broken && !keyframe ) → kRejected（现有）
```

### 3.3 驱逐策略：Basalt 式（7 KF + 3 temporal 近似）

窗口上限保持 `window_size = 10`，但驱逐时**优先移除最老的非关键帧**：

```cpp
while ( window.size() > window_size )
{
  // 找最老的非关键帧；没有则 pop 最老帧
  auto it = find_first_nonkeyframe_from_front();
  if ( it != window.end() ) window.erase(it);
  else window.pop_front();
}
```

需要 `WindowFrame` 增加 `bool is_keyframe` 字段（session 传入或 estimator 记录）。

### 3.4 效果

- 非关键帧位姿 = 窗口 BA 精修（VINS 同款）→ V1_01 预期回到 ~0.17
- 关键帧保留更久 → 窗口时间跨度长（Basalt 7KF 结构）
- 非关键帧仍不产生新 landmark → landmark 生命周期不变
- `est.tum` 逐帧、`kf.tum` 关键帧——输出语义不变

### 3.5 复杂度

窗口固定 10 帧（所有帧），每帧 BA 图大小不变（10 pose + 窗口内 landmark）。
非关键帧进 BA 使 LM 变量数不变（都是 10 pose），但 landmark 因子更密集。
RTF 影响预计 <10%（非关键帧占 ~80% 帧，从 PnP-only 变为 BA）。

## 4. 已对齐决策

| 决策点 | 结论 |
|---|---|
| 非关键帧 | 进窗口参与 BA（同路径） |
| 非关键帧 seed | 不（仅关键帧） |
| 非关键帧 reanchor | 不（overlap_broken → kRejected） |
| 窗口结构 | **Basalt 7KF + 3 temporal**（7 关键帧 + 3 最近帧，共 10） |
| pose-only 精修 | **删除**（非关键帧进 BA 后不再需要 solvePnPRefineLM） |
| window_size | 10（7 KF + 3 temporal） |
| 关键帧率 | 由 isKeyframe 决定（当前 10px 阈值） |

### 4.1 窗口驱逐规则（Basalt 式）

```cpp
// 总上限 10 帧
while ( window.size() > 10 )
{
  // 1. 优先 pop 最老的非关键帧（temporal）
  auto nkf = 最老的 is_keyframe == false 帧（非最新帧）;
  if ( nkf 存在 ) { erase(nkf); continue; }
  // 2. 无 temporal：pop 最老关键帧
  window.pop_front();
}
// 3. 关键帧上限 7：超了 pop 最老关键帧
while ( 关键帧数 > 7 ) pop 最老关键帧;
```

效果：非关键帧连续进来时保留最近 3 个（temporal 区），老的被驱逐；关键帧
保留 7 个（长跨度）。等效 Basalt 的 FramePose(7) + FrameState(3)。

## 7. 风险

| 风险 | 缓解 |
|---|---|
| MH_01 硬门回归（非关键帧进 BA 改变数字）| 硬门兜底；MH_01 关键帧率 43%（10px），非关键帧 57% 进 BA 可能改变轨迹 |
| 窗口时间跨度缩短 | 若 MH 系列退化，升级 7KF+3temporal 结构 |
| RTF 上升 | 记录；非关键帧 BA 图小 |
| reanchor 语义变化 | 非关键帧 overlap_broken 仍拒绝（不变） |
