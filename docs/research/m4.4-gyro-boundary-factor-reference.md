# M4.4 gyro factor admission 与窗口边界一手资料核对

日期：2026-08-10

状态：**一手资料、MH_01 correlation 与 boundary objective 审计均已收口；全局 hard
admission 和 boundary robustification 均否决，普通 Gaussian AHRS graph 保持不变**

本文档描述当前约定，不是绝对约束，会随项目开发修订。

## 1. 问题

gyro-only B3 在 MH_01 上已经使 1 s translation RPE 优于 VO，但 ATE 仍差
`2.36 mm`。raw gyro relative rotation 在 active suffix 比 VO 更接近 EuRoC reference，
因此出现一个诱人的规则：仅在 visual↔gyro disagreement 较大时加入 AHRS factor。

本调研核对两个问题：

1. 成熟 VIO 是否按 visual↔IMU disagreement 对相邻 IMU factor 做 hard admission？
2. 若不做，是否有针对固定窗口边界的特殊处理？

## 2. 上游事实

### 2.1 VINS-Fusion：有效 IMU 边全部入图，robust loss 给视觉

VINS 在每个 `sum_dt <= 10 s` 的相邻 slot 上创建 `IMUFactor`，传给 Ceres 的
`loss_function` 是 `NULL`；同一优化里 projection factors 才使用 `HuberLoss(1.0)`：

- [IMU factor 无 loss L1052-L1061](https://github.com/HKUST-Aerial-Robotics/VINS-Fusion/blob/be55a937a57436548ddfb1bd324bc1e9a9e828e0/vins_estimator/src/estimator/estimator.cpp#L1052-L1061)
- [视觉 Huber 与 projection factor L1009-L1014、L1081-L1102](https://github.com/HKUST-Aerial-Robotics/VINS-Fusion/blob/be55a937a57436548ddfb1bd324bc1e9a9e828e0/vins_estimator/src/estimator/estimator.cpp#L1009-L1014)

`sum_dt > 10 s` 是 interval 有效性保护，不是 visual↔IMU innovation admission。

### 2.2 Kimera-VIO：每个 KF PIM 入图，视觉侧做 outlier rejection

Kimera 的 `addImuFactor()` 直接按配置创建 `CombinedImuFactor` 或普通
`ImuFactor + bias BetweenFactor`，没有 residual-based skip 或 robust wrapper：

- [addImuFactor L910-L950](https://github.com/MIT-SPARK/Kimera-VIO/blob/ce8c59b7b273ab5ac29db7e5572e1623760e19c7/src/backend/VioBackend.cpp#L910-L950)

前端 separately 对 mono/stereo/PnP 做几何 outlier rejection；这不能反向证明应 gate
IMU factor。

### 2.3 OpenVINS：IMU 负责 propagation，χ² gate 视觉 update

OpenVINS 的 MSCKF feature update 用 state covariance 与 pixel noise 构造 innovation
covariance `S`，再按 χ² gate 删除坏 feature：

- [visual innovation χ² L202-L229](https://github.com/rpng/open_vins/blob/69488123ed9362dd44b6f28e7f4680abbff1442b/ov_msckf/src/update/UpdaterMSCKF.cpp#L202-L229)

该模式是“IMU propagation + gate visual measurement”，不是比较两套 rotation 后只在
disagreement 大时消费 IMU。

### 2.4 Basalt：所有 IMU measurement 构成 blocks，Huber 在 landmark residual

Basalt 的线性化构造器遍历全部 `imu_meas` 创建 `ImuBlock`：

- [IMU blocks L163-L167](https://github.com/VladyslavUsenko/basalt/blob/0f3b2b52c807f70ff4e2973ce253c73329eea7bc/src/linearization/linearization_abs_qr.cpp#L163-L167)

Huber weight 位于 landmark block 的 visual residual 路径：

- [landmark Huber L474-L489](https://github.com/VladyslavUsenko/basalt/blob/0f3b2b52c807f70ff4e2973ce253c73329eea7bc/include/basalt/linearization/landmark_block_abs_dynamic.hpp#L474-L489)

### 2.5 ORB-SLAM3：不做全局 admission，但特殊处理固定窗口边界

ORB-SLAM3 local inertial BA 把所有有效 inertial edges 加入 optimizer；interior edges
保持普通 quadratic。只有连接 local window 与 fixed outside keyframe 的 boundary edge
使用 Huber，并把 information 乘 `1e-2`，源码注释明确是为避免 fixing variables
导致误差累积：

- [boundary inertial edge L2623-L2644](https://github.com/UZ-SLAMLab/ORB_SLAM3/blob/4452a3c4ab75b1cde34e5505a36ec3f9edcdc4c4/src/Optimizer.cc#L2623-L2644)

ORB 的 9D inertial Huber delta 为 `sqrt(16.92)`。这个数不能直接移植到本仓库 3D
rotation residual；可迁移的是“boundary 与 interior 分开观测/处理”的结构。

### 2.6 GTSAM robust 参数在 whitened units

GTSAM `noiseModel::Robust` 先用 base Gaussian whiten residual，再把 whitened norm 送入
M-estimator；因此 Huber `k` 的单位是 sigma 数，不是 rad：

- [Robust whitening 合同 L661-L696](https://github.com/borglab/gtsam/blob/2f3e56c0ddbd3a1aa54ed043643b553d26a069f6/gtsam/linear/NoiseModel.h#L661-L696)
- [Huber 定义](https://gtsam.org/doxygen/a04439.html)

任何 robust candidate 都必须先记录 whitened boundary residual，不能把 raw rad 与
χ² threshold 混用。

## 3. MH_01 read-only correlation

对 B3 active suffix 的 `1657` 个 GT-supported interval，以 candidate fixed aligned bias
重建 gyro delta，并比较 IMU-off VO relative rotation、gyro rotation 与 EuRoC reference：

| metric | value |
|---|---:|
| gyro rotation RMS | `0.3436 mrad` |
| VO rotation RMS | `0.5577 mrad` |
| gyro better fraction | `65.12%` |
| visual↔gyro disagreement median / p90 | `0.489 / 0.933 mrad` |
| disagreement 与 `(gyro error - visual error)` Pearson | `-0.6523` |

最高 disagreement decile 中 gyro 在 `89.76%` intervals 更准；最低 decile 为
`57.23%`。这是有价值的离线归因，但不构成 production hard admission：

1. winner 标签消费了 GT；运行时只有 disagreement，无法辨别“视觉坏”还是“IMU坏”；
2. 五个成熟实现都没有采用“disagreement 越大越应加入 IMU、越小越跳过”的链路；
3. 一致 measurement 即使 point estimate correction 小，仍提供 Hessian information；
4. 只在 MH_01 选 threshold 会把 sequence-specific reference correlation 写进产品。

因此不实现 high-disagreement-only factor gate，也不扫 threshold quantile。

## 4. 对本仓库的最小可迁移结论

当前 B3 每次从 10-frame window 重建 stereo + AHRS graph，oldest pose 用强 prior
近似固定；第一条 AHRS edge 正好跨 `anchored oldest → free next`。它与 ORB 的 fixed
boundary failure surface 相似，但并不等价：本仓库没有真正 outside fixed keyframe，
也没有 marginalization prior。

所以下一步不是直接乘 `1e-2`，而是先加 read-only gyro factor objective probe：

- boundary / interior / newest AHRS factor 的 initial/posterior whitened norm 与 cost；
- oldest pose prior correction/cost；
- 10 s buckets 与 window slide 后 boundary residual persistence；
- sidecar on/off 的 `est.tum/kf.tum/diag.csv` byte gate。

只有 boundary 持续显著高于 interior、并与 B3 ATE 坏桶同相，才设计 boundary robust
candidate；否则 ORB 模式不适用，继续保留普通 Gaussian AHRS graph。

## 5. 证据缺口

- 没有上游 revision 使用 3D gyro-only factor + stereo BA 的同一结构；
- ORB 的 `1e-2` 与 `sqrt(16.92)` 针对 9D full inertial edge，不可直接证明本仓库数值；
- EuRoC GT attitude 与 IMU 同源，只能作 reference correlation；
- B5/B6 历史 runtime 的 full stage 会在 gyro activation 后约 1 s 接管，因此第 6 节
  初次 probe 只能提供 20 个与 B3 合同相同的 gyro-only 窗口；第 7 节在删除该失败
  runtime 后补足 1680 rows，但仍只覆盖 MH_01 单序列。

### 6.2 结果

full alignment history 在 gyro activation 前已经累计支持，故 full stage 在 1 s
validation delay 后接管。可审计 support 为 state key `2001..2020`、20 个 gyro-only
window；AHRS factor 数从 4 增到 9。

| posterior metric | boundary | newest |
|---|---:|---:|
| whitened norm median / p90 / max | `0.309 / 0.654 / 0.672` | `0.414 / 0.639 / 0.828` |
| raw rotation median / p90 / max | `0.157 / 0.332 / 0.341 mrad` | `0.210 / 0.324 / 0.421 mrad` |
| cost median / p90 / max | `0.0476 / 0.2140 / 0.2256` | `0.0859 / 0.2043 / 0.3429` |

boundary 相对每窗 interior 单因子平均 cost：

- ratio median=`0.3605`、p90=`1.7735`、max=`1.8703`；
- boundary 仅 `25%` 窗口高于 interior 单因子均值，仅 `30%` 高于 newest；
- boundary 占全部 AHRS posterior cost 的 median=`6.28%`、p90=`18.15%`；
- pose/bias prior posterior cost 最大仅 `6.80e-22 / 6.15e-8`；
- cost identity 最大绝对误差 `4.44e-16`。

### 6.3 决策

结果与“固定窗头造成 boundary outlier”相反：boundary 的典型 cost 低于 interior，且
20 个窗口中最大 whitened norm 也不到 `0.7σ`。ORB-SLAM3 的 9D boundary Huber delta
`sqrt(16.92)≈4.11` 在这里不会触发；直接移植 `information * 1e-2` 则会在没有异常
residual 的情况下人为删除边界信息。

因此按第 4 节判定：

1. 不实现 boundary Huber、information scale 或 threshold sweep；
2. 不跑 MH_05；
3. 保持全部有效 AHRS edge 的普通 Gaussian 合同；
4. 20-row support 只否决“当前窗口边界明显异常”，不外推为所有序列的边界均永远
   健康，也不把短 support 冒充 10 s persistence 证据。

### 7.4 最终决策

完整 support 强化而非推翻第 6 节结论：boundary 的典型 normalized residual 低于
`1σ`，八个完整 10 s 桶的最大值均 `<1.11σ`；尾桶单个 `2.678σ` 也低于 ORB 9D
参考 Huber `4.11σ`。因此：

1. boundary Huber、information scale 与 threshold sweep 正式关闭；
2. ordinary Gaussian AHRS factor 保持不变；
3. 不因单序列健康而宣称所有数据集 boundary 永远健康；
4. 按已确认的 A→B 路线转入 persistent joint-state/fixed-lag 设计，仍从 MH_01 首门
   重新验收，不直接扩 MH_05。
