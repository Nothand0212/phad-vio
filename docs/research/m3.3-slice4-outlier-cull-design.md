## 1. 目标与非目标

**唯一目标**：在窗口 BA（LM）写回位姿与点之后，按 landmark 聚合的平均
重投影误差剔除外点，并**永久**从 `landmarks_W` 回收该 id（同时清除窗口内该 id
的观测），使毒点不再进入后续帧的图。优先消化 Slice ③ 留下的 **MH_05 发散**
（ATE≈3.3e4、`cheirality=2055`）与健康序列上的坏点拖拽。

不做：

- 剔点后本帧二次 LM（编码结束后先跑 MH_05 诊断「不重优是否够」；不够再单独立项）；
- ORB 式多轮优化 / 去 Huber / 观测级可翻转外点；
- 同步删除 frontend track（保持 `estimator` ↛ `frontend`）与 estimator 内部拒绝名单
  （伪永久语义见 §2；重复删除率由 `outliers_culled_unique` 诊断，偏高再单独立项）；
- 关键帧策略（Slice ⑤）、IMU、边缘化；
- 改 `phad::eval`；不要求 MH_01 `est.tum` 与 Slice ③ 逐字节相同。

## 2. 已对齐的决策

| 决策点 | 结论 | 依据 |
|---|---|---|
| 主模板 | BA 后按 landmark **平均像素**误差永久删点；**不重优** | VINS `outliersRejection`；开源对照 §3 |
| 作用域 | 永久 `landmarks_W.erase` + 清窗口各帧该 id 观测；不回传删 track | 父设计分叉 A；单向依赖 |
| 永久性语义 | **伪永久**：无拒绝名单；frontend 存活 track 再喂同 id → 按新点 backproject；以 `culled_ids_` 去重统计诊断重复删除率 | VINS `MULTIPLE_THREAD=1` 时前端同样不删 track；对照 §2.1 |
| 单帧残差 | `GenericStereoFactor::unwhitenedError` 的 ‖·‖₂（3 维像素） | 与现有 `stereoReprojRms` 同源 |
| 聚合 | 窗口内该 id 各因子残差的**算术平均**（每帧一个 3 维因子） | VINS `ave_err`（归一化残差；本片直接用像素） |
| 默认阈值 | `outlier_avg_reproj_px = 3.0`（像素，不乘焦距） | VINS `ave_err * 460 > 3` 中 460 是**硬编码常量**（`parameters.h:23`）而非标定；本片直接像素更干净 |
| 最少观测 | 窗口观测（因子）数 `< 4` **跳过**（硬编码，非选项） | VINS `used_num < 4` 同为**帧数**计数（每帧一次 push_back，左右目不分别 +1），语义一致 |
| 开关 | `enable_outlier_cull` 默认 `true`；`false` **只关** mean-reproj 剔点（cheirality 清窗口观测 helper 仍生效；不承诺与 Slice ③ 逐字节/`est.tum` 相同） | 与 re-anchor / PnP 同型功能 A/B；helper 是删点路径正确性修复，不挂在 cull 开关上 |
| 与 cheirality | 先 `dropCheiralityLandmarks`，再外点剔除；两条删点路径**共用清窗口观测 helper** | behind-camera 已有专用路径；避免哨兵残差搅进 3 px 统计；`countObservations()` 无幽灵 id |
| `reproj_after` | 仍为剔除**前** graph 上的 RMS；新增 `reproj_after_cull_px`（剔后，遍历跳过被删 id，不重建图） | 前者反映本帧 BA 质量；后者量化「剔点清掉了多少残余」，供 MH_05 诊断 |
| `track_times` | **不删** | 诊断时间线；对齐 Slice ③ 掩码哲学 |
| 诊断 | `diag.csv` +2 列；`summary.json` 累计 `outliers_culled` 与 `outliers_culled_unique` | MH_05 诊断需要看得见「在砍」；次数 ÷ 去重数 = 重复删除率 |
| 出口顺序 | **编码结束后先跑 MH_05**，再全序列 | 用户指定；判断不重优是否足够 |
| 硬门控 | MH_01 ATE ≤ 0.099263 m 且 seg/re；**健康序列**（MH_01–04、V1_01/02、V2_01/02）reanchors 不增；MH_05 reanchors **豁免**并记录 | 剔点恢复路径可能触发 re-anchor；MH_05 从 0 变 >0 是治疗生效而非退化 |

## 3. 模块边界

不新增库。改动集中在：

```text
phad::estimator   StereoVoEstimator::update
                  ← BA 写回后：mean ||e|| 外点 → 永久删 landmarks_W
                    + 清窗口观测（与 cheirality 共用 helper；不重优）
                  EstimatorOptions
                  ← enable_outlier_cull / outlier_avg_reproj_px
                  UpdateDiagnostics
                  ← outliers_culled / outliers_culled_unique / reproj_rms_after_cull_px
        ↓
apps/offline_vo_session     ← diag.csv 16→18 列；结束 summary 日志
apps/phad_vo_bench          ← flattenConfig 新字段；summary 累计
phad::bench   RunSummary    ← robustness.outliers_culled / outliers_culled_unique
tests/estimator|apps|bench  ← 合成场景 + 契约
docs                        ← 本设计 + 开源对照 + 基线
```

`phad::frontend` / `phad::eval` **不动**。公开头仍只暴露 Eigen / POD。

Frontend 若继续喂已被删的 id：下一帧按**新点** backproject（无拒绝名单；伪永久）。
Impl 维护 `culled_ids_`（去重集合，跨段保留）只为统计：`outliers_culled / outliers_culled_unique`
即重复删除率，> 1 说明同一 id 在「删 → 重建 → 再删」空转；若 MH_05 诊断显示剔点在空转且
剔后无改善，再单独立项拒绝名单。

### 新选项与诊断字段

```cpp
struct EstimatorOptions
{
  // …既有字段…
  bool   enable_outlier_cull   = true;  // false → 复现 Slice ③
  double outlier_avg_reproj_px = 3.0;   // mean ||unwhitenedError|| 阈值
};

struct UpdateDiagnostics
{
  // …既有字段…
  std::uint32_t outliers_culled        = 0;   // 本帧永久删除的 landmark 数
  std::uint32_t outliers_culled_unique = 0;   // 本帧新增去重 id 数（Impl 持 culled_ids_ 集合）
  double        reproj_rms_after_cull_px = 0.0;  // 剔后 graph RMS（跳过被删 id，不重建图）
};
```

构造校验：`outlier_avg_reproj_px > 0`，否则 `std::invalid_argument`。  
两字段进 `flattenConfig()`，产生新 `config_hash`。

## 4. 数据流

首段 seed / re-anchor / 正常路径在走过 LM 写回后共用下述后缀（观测 `< 4`
的点会被跳过，故单帧 seed 实质上不剔）：

```text
LM optimize → 写回 window.T_W_B / landmarks_W
→ dropCheiralityLandmarks(optimized)          // 既有；顺带清窗口观测（共用 helper）
→ 若 enable_outlier_cull:
     对每个仍在 landmarks_W 且窗口观测数 ≥ 4 的 id:
       在 graph + optimized 上收集该 id 的 GenericStereoFactor
       score = mean_i( ||unwhitenedError_i||₂ )
       若 score > outlier_avg_reproj_px:
         landmarks_W.erase(id)
         从 window 各帧 observations 去掉该 id（共用 helper）
         ++outliers_culled
         若 culled_ids_.insert(id).second: ++outliers_culled_unique
→ 写 diagnostics.reproj_rms_after_px（剔除前 graph）
→ 写 diagnostics.reproj_rms_after_cull_px（剔后 graph：遍历跳过被删 id，不重建图）
→ kOk + estimate（位姿 = 第一轮 LM 结果）
```

要点：

- **不重建图、不二次 LM**；
- 事务回滚语义不变（`landmarks_W` / `window` 仍在快照内）；
- 外点剔除**不是**新的 `UpdateStatus`，不因剔点拒帧。

```mermaid
flowchart TD
  A[LM + 写回] --> B[dropCheiralityLandmarks]
  B --> C{enable_outlier_cull?}
  C -- 否 --> Z[kOk]
  C -- 是 --> D[按 id 聚合 mean ||e||]
  D --> E{obs>=4 且 score>阈值?}
  E -- 是 --> F[erase landmarks_W<br/>清窗口观测（共用 helper）<br/>++outliers_culled]
  E -- 否 --> G[保留]
  F --> Z
  G --> Z
```

## 5. 错误与诊断

**运行时**：剔点失败模式只有「没删 / 删了」；不定系统等仍走既有 `kFailed`。

**`diag.csv`**：16 → 18 列，尾部追加 `outliers_culled`（整数）与
`reproj_rms_after_cull_px`（浮点；剔后 graph RMS，跳过被删 id）。有意契约变更，
同步 `phad/estimator/README.md`、`apps/AGENTS.md`、`tests/apps`。
`enable_outlier_cull=false` 时两列仍有定义：`outliers_culled=0`、
`reproj_rms_after_cull_px == reproj_rms_after_px`（无 mean-reproj 剔点，不产生空洞；
cheirality 清观测仍可能发生，故不承诺与 Slice ③ 逐字节相同）。

**`summary.json`**（`schema_version` 保持 1）：

```json
{
  "robustness": {
    "rejected": 0, "failed": 0, "low_connectivity": 0,
    "cheirality": 0, "reanchors": 0,
    "pnp_successes": 0, "pnp_fallbacks": 0,
    "outliers_culled": 0,
    "outliers_culled_unique": 0
  }
}
```

`outliers_culled` 为全 run **累计删点次数**（按帧累加本帧删点数，非去重 id）；
`outliers_culled_unique` 为全 run **累计去重 id 数**。两者之比即**重复删除率**：
> 1 说明同一 id 在「删 → 前端再喂 → 重建 → 再删」空转，需在 MH_05 诊断中评估是否
单独立项拒绝名单。

**日志**：结束一条 summary（合计剔点数）；不每帧刷屏。

## 6. 测试与验收

### 单元测试（`tests/estimator/`）

| 用例 | 断言 |
|---|---|
| 合成坏点被永久删 | 持续高 reproj 的 id → 离开 `landmarks_W`，窗口观测被清；`outliers_culled ≥ 1`；**下一帧同 id 再喂 → 按新点 backproject 重建**（伪永久语义，见 §2） |
| 观测数 `< 4` 不剔 | 仅 2–3 帧观测的歪点保留 |
| 阈值内保留 | 干净场景无误删 |
| `enable_outlier_cull=false` | `outliers_culled=0`，不跑 mean-reproj 剔点；cheirality helper 仍清窗口观测 |
| 不重优 | 本帧 `estimate.T_W_B` 等于剔点前已写回位姿 |
| 非法选项 | `outlier_avg_reproj_px ≤ 0` → `invalid_argument` |
| 重复删除率 | 同 id 删 → 重建 → 再删：`outliers_culled=2`、`outliers_culled_unique=1` |
| cheirality 清观测 | cheirality 删点同样清窗口观测（helper 共用），`countObservations()` 无幽灵 id |
| 既有 PnP / re-anchor / diagnostics | 不回归 |

### 契约测试

- `tests/apps/`：`diag.csv` 18 列表头与行格式（含 `reproj_rms_after_cull_px`）；
- `tests/bench/`：`summary.json` 的 `outliers_culled` / `outliers_culled_unique`。

### 真序列（对照 `b712c91` / `default_8a9236e0`）

**编码结束后的强制顺序**（实施计划必须单列任务）：

1. **先跑 `MH_05_difficult`**，诊断「剔完不重优」是否足够：
   - 观察 ATE 是否离开 `~1e4` 量级、`cheirality`、`outliers_culled` /
     `outliers_culled_unique`（重复删除率）、`reproj_after` 与
     `reproj_after_cull` 时间线（判据见下）；
   - **够用** → 继续全序列 + 写基线；
   - **不够** → 停止扩 scope，回头讨论本帧二次 LM（设计讨论中的 B/C），
     本片出口标明「部分完成 / 需重优」。
2. 再跑其余 10 条 + `bench_table.py`。

| 项 | 门控 |
|---|---|
| MH_01 | ATE ≤ **0.099263** m；`segments=1`、`reanchors=0` |
| 健康序列（MH_01–04、V1_01/02、V2_01/02）`reanchors` | 相对 Slice ③ **不增** |
| MH_05 `reanchors` | **豁免**：剔点恢复路径可能从 0 变 >0，属治疗生效而非退化；次数记录进基线 |
| MH_05 | **诊断门**（非硬数值）：必须完成步骤 1 并写入基线结论，判据见下 |
| 其余 ATE | 只记录 |
| 产物 | `docs/research/m3.3-slice4-baseline.md` + 回填 roadmap |

**MH_05「够 / 不够」预定义判据**（编码前已定，避免事后解释）：

- **够** = ATE 离开 `~1e4` 量级回到 **< 1 m**（参照 Slice ② 的 0.40）；`cheirality` 显著下降（远离 2055）；`outliers_culled` 时间线集中在序列**前段**（后期不再大量剔）；重复删除率接近 1。
- **不够** = ATE 仍 `~1e4` 量级；或 `reanchors` 暴增（剔点掏空窗口，需本帧二次 LM / 重建图——停止扩 scope，回头讨论设计中的 B/C）。

测量：`ctest` + `phad_vo_bench` + `bench_table.py`。

## 7. 与父设计 / 开源对照的关系

- 父设计第 8 节 Slice ④ 原写「需决定本帧还是永久」——本片定为**永久**（伪永久语义，
  见 §2），且不同步 frontend。
- 主模板是 VINS，不是 ORB 多轮 χ²；阈值 3.0 px 与开源对照一致（VINS 的
  `FOCAL_LENGTH=460` 是硬编码常量，本片直接像素阈值，见对照 §2.1）。
- VINS `MULTIPLE_THREAD=1` 时前端同样不删 track，伪永久有先例；且 VINS 被删点的
  信息残留在 marg 先验中，本仓库无 marg，「永久删除」更彻底。
- Slice ③ 外点只影响当前帧入图观测；本片负责优化后生命周期，边界不糊。
- Slice ⑤（关键帧）仍单独对齐。
