## 1. 目标与非目标

### 目标

在已有双目前端（`FrameTracks`）之上接入 GTSAM 显式 landmark 固定窗口 batch BA，使 `MH_01_easy` 产出完整 `T_W_B` 轨迹（TUM），ATE 有限且米级即可；该数字作为后续里程碑基线。

### 非目标

- 关键帧策略、PnP / 本质矩阵初值（M3）
- IMU、preintegration、`V`/`B` 状态（M4）
- 边缘化 / fixed-lag smoother（M6）
- Smart factor、多线程、回环
- 精度优化或 MH_02–05 门控

## 2. 已锁定决策

| 项 | 决策 |
|---|---|
| 关键帧 | 每帧都进 estimator |
| Seam | App/glue 将 `FrameTracks`（仅 `kValid`）组装为 `KeyframeMeasurement`；类型属 `phad::estimator`；frontend 不引入关键帧 API |
| Pose 初值 | 新帧 = 上一帧优化后的 `T_W_B` |
| Gauge | 单一强 `PriorFactor<Pose3>` 钉在**当前窗口最老帧**；滑窗时迁移（均值取该帧当前估计） |
| 窗口 | 可配置，默认 `10` |
| 状态定义 | `X(k)` = body pose；`GenericStereoFactor` 传 `body_P_sensor = T_B_left` |
| Landmark 初值 | 首次 `kValid` 观测用 `StereoCamera::backproject`，再变到世界系 |
| 图维护 | **每步重建**窗口内 factor graph + Values，再 LM |
| 出口应用 | `phad_stereo_vo_probe`（无窗口验收）+ `phad_euroc_runner`（可视化） |
| Gauge 因子类型 | `PriorFactor`（不用 `NonlinearEquality`，避免强制 QR） |

## 3. 模块边界

### 3.1 `phad::estimator`

CMake target：`phad_estimator`（alias `phad::estimator`）。

| 拥有 | 不拥有 |
|---|---|
| `KeyframeMeasurement` / `StereoObservation` / `VioEstimate` / `VioUpdateResult`（M2 无 `pim`） | 图像、路径、数据集字段名 |
| 固定窗口：pose、landmark、窗口内观测缓存 | 关键帧决策、feature track 生命周期 |
| GTSAM 图重建、`Cal3_S2Stereo`、`body_P_sensor`、LM | 边缘化、smart factor、IMU |
| 诊断：重投影、cheirality、外参合同 | ATE（`phad::eval`） |

**依赖**：`phad::common`、`phad::sensor`、`phad::camera`、GTSAM（本里程碑接入 CMake）。  
**不依赖** `phad::frontend`（由 apps/glue 连接，避免库环依赖）。

### 3.2 公开 API（草）

```cpp
namespace phad::estimator {

using LandmarkId = std::uint64_t;  // 与 frontend 数值合同一致

struct StereoObservation {
  LandmarkId id;
  Eigen::Vector2d left_px;  // rectified left
  double disparity_px;      // must be > 0
};

struct KeyframeMeasurement {
  common::Timestamp timestamp;
  std::vector<StereoObservation> observations;
};

struct EstimatorOptions {
  int window_size = 10;
  // stereo measurement noise, prior sigmas, LM knobs as needed
};

enum class UpdateStatus : std::uint8_t {
  kOk = 0,
  kRejected = 1,
  kFailed = 2
};

struct VioEstimate {
  common::Timestamp timestamp;
  Eigen::Isometry3d T_W_B;
};

struct VioUpdateResult {
  UpdateStatus status;
  std::optional<VioEstimate> estimate;  // only when kOk
  // diagnostic fields: reproj_rms_px, num_cheirality, message, ...
};

class StereoVoEstimator {
 public:
  StereoVoEstimator(camera::RectifiedStereoCalibration calib,
                    sensor::RigidTransform T_B_left,
                    EstimatorOptions options = {});

  [[nodiscard]] VioUpdateResult update(const KeyframeMeasurement& measurement);
};

}  // namespace phad::estimator
```

类名 `StereoVoEstimator` 强调 M2 纯视觉；M4 可演进或改名为更通用的 estimator，不以抽象基类预留。

## 4. 数据流与每步算法

### 4.1 内部状态（私有）

- 有序窗口队列：每帧 `{timestamp, T_W_B, observations}`
- `LandmarkId → Point3`（世界系），仅保留窗口内仍被观测的 id
- 诊断用：`LandmarkId →` 观测过的时间戳列表（不参与优化）

### 4.2 `update` 步骤

1. **校验输入**：时间戳严格递增；观测非空（首帧也要求至少一观测才初始化）；视差 > 0；标定/外参合同已在构造期通过。
2. **首帧**：`T_W_B = I`；对每个观测 `backproject(StereoPoint2)` 得左相机系点，经 `T_W_B * T_B_C` 到世界系，插入 landmark。
3. **后续帧**：pose 初值 = 上一帧优化结果；未见过的 id → `backproject`；已见 id 沿用当前 landmark 估计作初值。
4. **入窗**；若超过 `window_size`：弹出最老帧；删除窗口内已无观测的 landmark。
5. **重建图**：
   - Symbols：`x(k)` / `l(j)`（`j` 由稳定 `LandmarkId` 映射）
   - 每个窗口观测：`GenericStereoFactor<Pose3,Point3>` + 共享 `Cal3_S2Stereo` + `body_P_sensor`
   - 最老帧：`PriorFactor<Pose3>`（强先验，均值 = 该帧当前估计）
6. **`LevenbergMarquardtOptimizer`**；写回窗口内 pose 与 landmark。
7. **返回**最新帧 `VioEstimate` + 诊断；失败不写入成功轨迹点。

### 4.3 标定映射

从 `RectifiedStereoCalibration` 构造 `Cal3_S2Stereo(fx, fy, s, cx, cy, baseline)`。  
`T_B_left` 来自 `StereoImuCalibration::T_B_left_camera()`（或等价合同），转为 GTSAM `Pose3` 作为 `body_P_sensor`。

## 5. 错误与诊断

| `UpdateStatus` | 含义 |
|---|---|
| `kOk` | LM 成功，带 `T_W_B` |
| `kRejected` | 输入/合同非法（空观测、坏视差、时间戳、外参/标定） |
| `kFailed` | 优化异常或不可接受的失败；附原因字符串 |

约束：禁止用 identity / 上一帧冒充 `kOk`。

**Cheirality**：factor 默认不 throw；计数 `num_cheirality`；优化后可丢弃 behind-camera landmark，不中止序列。单测覆盖显式报告。

**Probe 诊断 CSV（建议列）**  
`timestamp_ns, status, num_obs, num_landmarks, window_size, prior_key, reproj_rms_px, num_cheirality, lm_iterations`

**按 id 汇总 track**：诊断结构或测试 helper 能按 `LandmarkId` 列出完整观测时间戳。

## 6. 测试与验收

### 6.1 单元（合成，`-L unit`）

1. 扰动初值后 pose / landmark 误差下降  
2. 优化后重投影 RMS 下降  
3. Behind-camera → cheirality 诊断  
4. 错误外参 → 失败且信息指向 extrinsic/calibration  
5. 按 landmark id 汇总 feature track  
6. 窗口大小与 prior 始终在最老帧；滑出帧不在 Values  

### 6.2 集成出口

- `MH_01_easy`：`phad_stereo_vo_probe` 跑完不崩，写出完整 TUM  
- `phad_traj_eval`：ATE 有限、米级；记录为 M2.3 基线  
- Runner：轨迹形状目视合理（人工）；agent 不擅自弹窗
