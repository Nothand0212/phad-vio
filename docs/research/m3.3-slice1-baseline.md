## 2. 一句话结论

**拒帧吸收态已消除**：M3.2 上 completion ≈ 0.11–0.13 的 MH_02 / V1_03 / V2_02
现均可跑到 ≈ 0.98–1.0；MH_01 健康路径 `est.tum` 相对 `4780660/default_0885385a`
**逐字节相同**，ATE 仍 0.150155 m，`segments=1` / `reanchors=0`。
跨 coverage 的 ATE **只记录不门控**（V1_03 / V2_02 全覆盖后 ATE 上升是口径变化）。

分层（按 Slice ① 后的行为）：

| 档 | 序列 | 特征 |
|---|---|---|
| 健康单段 | MH_01、MH_03、MH_04、MH_05、V1_01 | `segments=1`、`reanchors=0`，数字与 M3.2 对齐 |
| 单段略损 completion | V1_02、V2_01 | `reanchors=0`；V1_02 因首段 seed 门限拒掉前 93 帧（comp 1.000→0.946）；V2_01 ok 数与 M3.2 相同 |
| 恢复多段 | MH_02、V1_03、V2_02 | completion 显著上升；有 re-anchor；ATE 升因 coverage 扩 |
| 仍差但不门控 | V2_03 | completion 0.03→0.49；`reanchors=26`；sync 仍丢 415 右帧 |

## 5. 给 Slice ②–⑤ 的用法

1. 优先盯 **reanchors 次数** 与每段长度：Slice ② 目标是减少 re-anchor、提高每帧观测数，不是再修吸收态。
2. MH_01 继续作字节/统计不回归锚。
3. V1_03 / V2_02 的高 ATE 是「跑完了但仍漂」；低 coverage 旧 ATE 不再作为对比基线。
4. V1_02 的首段 seed 拒帧（93）可在 Slice ② 观测数上来后自然缓解，或再评估 `min_seed_observations`。
5. V2_03 仍不作门控（sync 丢 415 右帧 + 场景退化）。
