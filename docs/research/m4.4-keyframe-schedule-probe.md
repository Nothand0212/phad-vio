## 1. 问题与判读边界

M4.4 的 IMU10 候选已把 accepted KF 总量恢复到 control 附近，但 ATE 仍劣化。
本探针回答三个更窄的问题：

1. 两条 schedule 是否只是相差一两帧；
2. 首次分叉发生在初始化、偶发失败，还是正常 accepted epoch；
3. 总量接近是否掩盖了局部密度和 rule 构成变化。

探针只把 `diag.csv` 中 `status=ok && is_keyframe=1` 计为 accepted KF。比较前
要求 sequence 相同、逐帧 timestamp axis 完全一致且严格递增；否则明确失败。
accepted event 使用动态规划做单调一对一匹配：先最大化匹配数，再最小化总 frame
lag，避免一条 candidate event 被多个 reference event 重复计数。

这个比较能证明 schedule 的差异范围，不能单独证明 ATE 的因果根因。首次分叉后
accepted-KF baseline 和 estimator window 都会变化，因此后续 evidence 已不是固定
baseline 下的反事实。

## 3. 结果

匹配率分别以 reference/candidate 为分母：

| candidate | accepted | Δ | exact | ±1 frame | ±2 frames | first order mismatch | 10-frame rolling max \|Δ\| |
|---|---:|---:|---:|---:|---:|---:|---:|
| IMU30 | 320 | −198 | 16.6% / 26.9% | 33.4% / 54.1% | 43.6% / 70.6% | 44 | 5 |
| IMU15 | 406 | −112 | 23.2% / 29.6% | 44.8% / 57.1% | 59.3% / 75.6% | 44 | 5 |
| IMU10 | 533 | +15 | 25.7% / 25.0% | 55.6% / 54.0% | 67.8% / 65.9% | 45 | 5 |

### 3.1 首处分叉

| candidate | reference event | candidate event | first set departure |
|---|---|---|---|
| IMU30 | #44 / frame 898 | #44 / frame 903 | frame 898：reference accepted，candidate 未选 |
| IMU15 | #44 / frame 898 | #44 / frame 899 | frame 898：reference accepted，candidate 未选 |
| IMU10 | #45 / frame 903 | #45 / frame 901 | frame 901：candidate accepted，reference 未选 |

三条候选此前已有 43–44 个 accepted KF 精确同序；分叉发生在正常运行期，而不是
首帧、静止初始化或 candidate rejection。阈值从 15px 降到 10px 时，同一局部运动
段的第一偏离由“漏选 control”翻成“提前额外选择”，说明 threshold crossing 与
accepted baseline 形成离散状态切换。

### 3.2 interval 分布

| run | mean / median gap (frames) | gap ≤6 | gap=11（timeout cadence） |
|---|---:|---:|---:|
| control | 6.261 / 5 | 296 / 517 | 149 |
| IMU30 | 10.147 / 11 | 29 / 319 | 258 |
| IMU15 | 7.993 / 9 | 138 / 405 | 162 |
| IMU10 | 6.085 / 5 | 341 / 532 | 113 |

IMU10 的均值与中位数接近 control，但 interval histogram 明显不同；局部任意连续
10 帧窗口的 accepted-KF 数差最大为 5。总量/均值相近不足以证明 schedule 受控。

Basalt-family `frames_after_kf > 5` 若直接用于当前路径，会触及 IMU10 已观察到的
341/532 个短间隔，也触及 control 的 296/517 个短间隔。反事实 schedule 会在首次
抑制后重算，所以上述不是最终被抑制数；但它足以证明 `N=5` 不是只修少量离群偏离
的最小刀。

### 3.3 candidate rule 构成

| candidate | Rule 4 total / candidate-only | timeout total / candidate-only | low survival total / candidate-only |
|---|---:|---:|---:|
| IMU30 | 42 / 33 | 258 / 193 | 18 / 8 |
| IMU15 | 231 / 179 | 162 / 105 | 11 / 2 |
| IMU10 | 409 / 335 | 113 / 60 | 9 / 5 |

IMU30 的主要 schedule 已退化为 timeout cadence；IMU10 的 335 个 candidate-only
accepted KF 来自 Rule 4。两者不是同一种“密度偏一点”，不能由一个全局 KF count
目标统一解释。

## 4. 事实、推断与证据缺口

### 4.1 已证事实

- 三条 candidate 与 control 的 image timestamp axis 完全相同；差异不是输入帧
  缺失；
- 首处分叉前存在 43–44 个精确同序 accepted KF；
- IMU10 exact overlap 只有 133 个，±2 frame 最大一对一匹配也只有
  351/518 reference events；
- 三条 candidate 都出现 10-frame 窗口内最多 5 个 accepted-KF 的局部计数差；
- IMU10 与 control 总量、mean/median gap 接近，但 interval histogram 和 rule 构成
  不同。

### 4.2 当前最强推断

Rule 4 不是无状态阈值函数。一次 accepted-KF 差异会同时改变 pixel/rotation
baseline 与 estimator window，随后 evidence 和 schedule 会级联。因此 B 的模块
边界需要把不可变 frame evidence、schedule transition 和 `selected && kOk` commit
分别显式化，不能再用“最终 KF 数相近”作为时序正确性的代理。

### 4.3 尚未证明

- 没有固定 production accepted-KF baseline 下的 IMU shadow evidence，因此不能
  判断两击确认、某个最小 interval 或 hysteresis 哪个能恢复质量；
- 没有反事实 estimator window，不能把后续 ATE 差异唯一归因于第一处分叉；
- frozen control trace 可作离线迁移门，但没有证据证明 95% 或其他 match-rate 是
  正确产品常量；
- 当前结果只来自 MH_01，不能外推其他 EuRoC 序列。

## 5. 对 successor B 的直接约束

1. 第一刀应是行为保持 seam：继续使用现行 evidence 和 schedule，要求
   `est.tum`、`kf.tum`、`diag.csv` 逐字节一致；
2. gate 内部必须产出完整 trigger mask、selected reason、accepted-KF epoch 和 commit
   outcome，使“evidence 变了”与“transition 变了”可区分；
3. schedule guard 先在同一 evidence source 上单变量验证；不要同时换 IMU source；
4. `N=5` cooldown、两击确认和 frozen-trace budget 都只能作为待验证假设，不能从本
   probe 直接晋级为默认；
5. 最终替换 IMU evidence 时删除 BA evidence implementation，不保留双 production
   selector；
6. MH_01 相对 control ATE、completion 与结构门仍是最小晋级门；最终 M4/VIO 出口
   还必须证明精度优于 VO，而不是只恢复当前 IMU-on control。

返回的完整 evidence，但尚缺一个不改变 decision 的 IMU/guard shadow trace。
