## 1. 要回答的问题

Slice ④ 目标：优化后按误差剔除外点，并回收 landmark 生命周期。父设计已点名：

- ORB-SLAM3 stereo χ² 7.815 / mono 5.991，4 轮 × 10 次迭代、第 3 轮后去 Huber；
- lk-vio 前端 5.991 / 后端 5.891；
- 需决定剔除是「本帧」还是「永久」（VINS 永久且同步删前端 track）。

本仓库现状：优化中有 Huber（`huber_k_px=3`）；优化后仅
`dropCheiralityLandmarks` 永久删 behind-camera 点；Slice ③ 只在优化前对本帧
RANSAC 外点做观测掩码，**不**删 `landmarks_W`。

## 2. 逐项目结论

### 2.1 VINS-Fusion —— 与本片目标同型

热路径在 `optimization()` 之后：

```542:551:vins_estimator/src/estimator/estimator.cpp
        outliersRejection(removeIndex);
        f_manager.removeOutlier(removeIndex);
        if (!MULTIPLE_THREAD)
        {
            featureTracker.removeOutliers(removeIndex);
            predictPtsInNextFrame();
        }
        ...
        slideWindow();
```

`outliersRejection`（节选逻辑，`estimator.cpp:1511-1569`）：

- 仅当 `used_num >= 4` 才评估；`used_num = feature_per_frame.size()`
  （`estimator.cpp:1519`），每帧只 `push_back` 一次、左右目不分别计数——**单位是帧**；
- 残差 `reprojectionError`（`estimator.cpp:1499-1509`）：用 `estimated_depth` 反投影
  首帧归一化坐标成 3D 点，重投影到当前帧后取**归一化平面**欧氏距离（左右目各算一份
  并累加）；`ave_err = err / errCnt` 为算术平均；
- 判定 `ave_err * FOCAL_LENGTH > 3`（`estimator.cpp:1564-1566`）——`FOCAL_LENGTH`
  是 **`parameters.h:23` 硬编码常量 460.0**，不是标定焦距；阈值实际是「归一化残差
  按 460 像素假设折算的 3 px」；
- **永久**从 `FeatureManager` 删除（`removeOutlier`，`feature_manager.cpp:433-448`），
  并同步 `featureTracker.removeOutliers`（`feature_tracker.cpp:524-543`）——但仅当
  `MULTIPLE_THREAD=0`；默认单线程模式（`MULTIPLE_THREAD=1`）下**前端不删 track**，
  外点会在后续帧以同 id 重新进入后端（伪永久）。

**不**在同一帧因剔点而重跑非线性优化；剔除在 `optimization()`（含 marginalization）
之后、`slideWindow()` 之前（`estimator.cpp:542-551`），被删点信息仍残留在本帧生成的
marg 先验中。  
本仓库无 frontend←estimator 依赖，不能照抄「同步删 track」；永久删
`landmarks_W` + 清窗口观测是同型落地，frontend 若再喂同 id 则按新点
backproject（伪永久，与 VINS `MULTIPLE_THREAD=1` 同型；且本仓库无 marg，
删除比 VINS 更彻底）。

### 2.2 ORB-SLAM3 —— 观测级、多轮、可翻转

`Optimizer.cc` PoseOptimization：4 轮（每轮 10 次迭代），mono/stereo χ² 阈
5.991 / 7.815；第 3 轮后 `setRobustKernel(0)`。外点是**当前帧观测标志**
（`mvbOutlier`），轮次间可 inlier↔outlier 翻转；不是「平均像素 → 永久删地图点」
的热路径形态。

把 7.815 直接拿来做「任一因子超阈 → 整点永久删」会比 ORB 更激进，且绑定
噪声 σ。本片不采用多轮 / χ² 主判据。

### 2.3 lk-vio

前端 pose-only BA 用 χ²≈5.991 分档跟踪质量；后端另有 ≈5.891。LOST 无恢复。
数量级参考，不是本片主模板。

### 2.4 其他

Kimera / Basalt / SVO 的外点策略更散（前端门限、marg、质量强制关键帧），不如
VINS「BA 后按平均重投影永久删 feature」与本仓库窗口 BA 贴合。

## 3. 对本片的取舍

| 项 | 结论 |
|---|---|
| 主模板 | **VINS**：BA 后平均误差 → 永久删 landmark；不重优 |
| 阈值 | 默认 **3.0 px**，本片直接像素单位（VINS 是 `ave_err × 460 > 3`，460 为硬编码常量，非标定焦距） |
| 最少观测 | **硬编码 4**（`used_num < 4` 跳过；单位是**帧**，与本仓库「窗口因子数」一致） |
| 不采用 | ORB 4 轮去 Huber；χ² 7.815 作主阈值；同步删 frontend track |
| 伪永久 | 无拒绝名单：与 VINS `MULTIPLE_THREAD=1` 同型；以去重计数诊断重复删除率 |
| 重优 | 本片不做；编码后先跑 MH_05 诊断「不重优是否够」，不够再单独立项 |

## 4. 与 Slice ③ 的边界

| | Slice ③ | Slice ④ |
|---|---|---|
| 时机 | 优化前 | 优化后 |
| 作用域 | 本帧 shared 观测掩码 | 永久 `landmarks_W` + 清窗口该 id |
| 判据 | `solvePnPRansac` inliers | 窗口内 mean ‖unwhitenedError‖ |
| frontend | 不动 | 不动 |
