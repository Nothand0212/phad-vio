## 1. 问题与预注册假设

前一片已证明 MH_01 的 PIM prediction 在本帧 optimizer correction 前就劣于同 support
VO。本片只审计 production static initializer 实际提交的 `[t0,t1]` 窗口与
`R_W_B0/v0/bg0/ba0/gravity model`，不改变 estimator 数值。

预注册顺序为：

1. gravity direction 与 accelerometer bias tangent 分量混淆；
2. `v0=0` 与 t0 reference 速度不符；
3. frame / specific-force sign 错误；
4. acc mean norm 与 gravity model / parallel bias 混淆；
5. t0、窗口或首条 IMU interval 错位。

在 reference 近静止条件下：

```text

||mean_acc - (g_model * body_up_ref + ba_ref)|| 0.0188871 m/s²
```

acc residual 小于任一 raw 轴 std（`0.0636..0.0935 m/s²`），且无轴/符号级
`g` 或 `2g` 残差。GTSAM Z-up、specific-force sign 与 EuRoC identity frame 合同
没有被本日志否定。

## 5. 归因

### 已确认事实

- 采用窗口近静止；`v0=0` 误差只有 `1.9 mm/s`；
- raw sidecar 与 dataset reload 完全一致，GT bracket 只有 `256 ns` offset；
- frame/sign 模型 residual 只有 `0.0189 m/s²`；
- acc-bias error 几乎全在 body-up tangent：`0.1496 / 0.1508 m/s²`；
- initial tilt 为 `0.8435°`。

### 高置信推断

假设 1 获得共同证据支持。`0.8435° = 0.01472 rad`，乘 gravity model 得
约 `0.1444 m/s²`，与 tangent bias error `0.1496 m/s²` 同量级。当前公式

```text
u   = normalize(mean_acc)
R*u = +Z
ba  = mean_acc - g*u
```

强制 `ba` 相对 `mean_acc` 的 tangent 分量为零；真实 tangent `ba` 被吸收到 tilt，
二者又在静止 measurement residual 中互相抵消，所以低 residual 不代表两者分别正确。

### 被本轮否定为主因

- 假设 2：reference t0 近零速；
- 假设 3：没有 sign/frame 级 residual；
- 假设 5：raw endpoint 与 GT 时间支持均对齐；
- 假设 4 只剩次要 parallel/magnitude coupling，量级小于 tangent 项。

## 6. 证据边界与下一刀

- EuRoC attitude/bias 是 Leica + 同一 IMU 的 batch reference，不是独立传感器真值；
  结论应写“与 EuRoC reference 不一致”；
- 本片只证明错误在首条 PIM 前存在，尚未用 production A/B 证明修正它足以让
  ATE/RPE 超过 VO；
- 单个 static mean acc 无法同时辨识 2-DoF tilt 与 3-DoF full acc bias。不能再从
  同一均值造另一个公式，也不应继续扫 RW、prior 或 static threshold；
- 下一片必须引入独立信息：stereo metric visual motion + 多帧 IMU 的 joint
  gravity/velocity/bias alignment，或先明确隔离 accelerometer translation fusion。
  不允许用 EuRoC GT 回写 estimator。

按预注册选刀规则，下一步是 **joint gravity/accelerometer-bias initialization 设计**。
