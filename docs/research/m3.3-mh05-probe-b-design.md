## 1. 目标与非目标

**唯一目标**：用**最小 instrumentation**（默认关）在 MH_05 **④f 默认**路径上
采到探针 B 清单 1–3 的证据，写出诊断笔记并给出**唯一推荐下一刀**（或明确
仍不足）；不占 ④g（机制片才编号）。本片称 **MH_05 探针 B**。

不做：

- 改 `diag.csv` 18 列合同；改 skip-drop / block / cull / Huber 默认；
- 为 ④b 复跑探针；滑动窗局部 Umeyama（清单第 4 项，除非 1–3 仍分不出刀）；
- 跑全序列、开 Slice ⑤、改阈值蒙混 &lt;1 m；
- 预定「去 Huber / 观测级」为结论；
- 入库长期 `scripts/` CLI（允许会话内一次性 Python）。

## 2. 已对齐的决策

| 决策点 | 结论 |

| 帧窗 | 重字段限 i∈[420,450] 或触发条件（见 §3） |
| config_hash | `--probe-b <path>` **CLI-only**，**不**进 `flattenConfig` |
| 票务 | 续 #24；不占 ④g |
| 命名 | 设计 `m3.3-mh05-probe-b-design.md`；笔记 `m3.3-mh05-probe-b-diagnosis.md` |

## 4. 数据流

```text
bench/probe --probe-b PATH
    → OfflineVoSession（打开 jsonl；维护 lifetime_culled）
         → tracker.process → FrameTracks
              zombie = |{obs.id ∈ lifetime_culled}|
         → estimator.update（probe 填充 diagnostics 旁路字段）
         → skip-drop / dropTracks（逻辑不变）
         → lifetime_culled ∪= culled_landmark_ids
         → 条件写 probe_b.jsonl 一行
    → 既有 est.tum / diag.csv
    → 一次性 Python → m3.3-mh05-probe-b-diagnosis.md
```

### `probe_b.jsonl` 行（草图）

轻量帧（窗外且无触发）：可跳过或只写 `i,ts_ns,shared,num_obs`。  
重字段帧（i∈[420,450] **或** `culled>0` **或** `lm_iterations≥100` **或**
`shift_m>0.5`）：

```json
{"i":429,"ts_ns":0,"culled_ids":[...],"zombie_track_n":0,"rejected_block_n":0,
 "new_lm":0,"shared":0,"num_obs":0,"lm_iterations":100,"shift_m":2.94,
 "shift_top":[{"key":123,"dt_m":1.2}],
 "res_mean_px":0.2,"res_max_px":1.5,"res_max_id":42,
 "drops_skipped_this_frame":false}
```

## 5. 错误与诊断

| 项 | 约定 |
|---|---|
| 开关关 | 零 I/O；数值路径不变 |
| path 无法创建 / 中途写失败 | session 硬失败（同 tum/diag 写失败级） |
| 探针不得改变 estimator 状态 | 只读采样 / 旁路计数 |
| 字段不足 | 笔记标不足；不得硬选 Huber/观测级 |
| 日志 | 可选一行 enabled；不刷每点残差到 stderr |
