## 1. 目标与非目标

**唯一目标**：在保持 ④c 机制默认开启的前提下，用 mean-cull 像素阈值
A/B 把 MH_01 ATE 拉回 ≤ **0.099263** m（`segments=1` / `reanchors=0`），再
判断 MH_05 相对 ④b/④c 是否可接受。假说：④c 健康已恢复，ATE 超锚主要因
**删点过猛**（默认 `outlier_avg_reproj_px=3.0`）。

不做：

- 多轮 cull↔LM、ORB 式去 Huber、观测级可翻转外点（→ **④e**，本片不够时另开）；
- 改硬编码 `n_factors < 4`（mean-cull 跳过最少观测）；
- 拆 `TrackId ≠ LandmarkId`；
- 关键帧（Slice ⑤）、IMU、边缘化、改 `phad::eval`；
- 扩 `diag.csv`（仍 **18** 列）；
- 为过门放宽阈值却不落 bench 数字。

## 2. 已对齐的决策

| 决策点 | 结论 |
|---|---|
| 顺序 | 先本片阈值（A），后 ④e 多轮 LM（B）；B 不进本片 todos |
| 旋钮 | 仅 `EstimatorOptions::outlier_avg_reproj_px`（已进 `config_hash`） |
| 扫参网格（MH_01） | `{3.0, 3.5, 4.0, 5.0, 6.0}`（3.0 = ④c 对照） |
| 选默认 | 过 MH_01 硬门的候选中取 **最小**（最紧）`T*` |
| 无一过门 | ④d **不够**；默认保持 3.0；不开全序列；开 ④e 设计 |
| MH_05 | 只跑选定 `T*`；软对照 ④c 4.565 / ④b 3.449；不硬门 &lt;1 m |
| MH_05 恶化 | 相对 ④c ATE↑ 或 completion/failed 崩 → 停全序列 → ④e |
| CLI | `phad_vo_bench --outlier-avg-reproj-px <float>` |
| 代码默认 | 仅当 `T* ≠ 3.0` 时改 `EstimatorOptions` 默认 |
| Slice ⑤ | 本片 MH_01 硬门前（或明确不够并开 ④e 前）**暂停** |
| 票务 | 续 [#24](https://github.com/Nothand0212/phad-vio/issues/24)；称 Slice ④d |

### CLI

```text
phad_vo_bench <sequence-root> … --outlier-avg-reproj-px <float>
```

- 覆盖 `session_options.estimator.outlier_avg_reproj_px`
- 须 `> 0`（与构造校验一致）；非法 → 非 0 退出
- 进 `flattenConfig` → 独立 `config_hash` 目录

## 3. 模块边界

不新增库。改动集中在：

```text
apps/phad_vo_bench          ← CLI 解析与注入

tests / README / AGENTS     ← 契约与说明

```

`phad::frontend` / `phad::eval` / cull 算法形态 / ④c 拒复生与 `dropTracks` **不动**。

## 4. 扫参与出口

```text
CLI 就绪
→ 对 T ∈ {3.0, 3.5, 4.0, 5.0, 6.0} 跑 MH_01（完整序列，无 --max-frames）
→ 硬门：ATE ≤ 0.099263；seg/re = 1/0；failed 不构成吸收态
→ 过门集合非空 → T* = min(过门)；改定默认（若需）→ MH_05 诊断
→ 过门集合空 → ④d 不够 → 文档收口 → ④e（不做 ⑤）
```

| 门 | 标准 |
|---|---|
| MH_01 | ATE ≤ **0.099263**；seg/re=1/0 |
| 默认 | 过门中最小 `outlier_avg_reproj_px` |
| MH_05 | 诊断；不硬门 &lt;1 m；相对 ④c 明显恶化则停全序列 |
| 全序列 | 仅 MH_01 过且 MH_05 未停 |

对照：

| 锚 | 值 |
|---|---|
| MH_01 硬锚（③ / no_cull） | ATE **0.099263** m |
| ④c MH_01 | ATE **0.120247**（`9da4ccd2`） |
| ④c MH_05 | ATE **4.565** |
| ④b MH_05 | ATE **3.449** |
