pose initial value 的所有权还给了视觉。MH_01 exact-common 结果仍是：

- VO ATE / RPE：`0.0809641 / 0.0177812`

## 2. 固定资料范围

### 2.1 GTSAM 4.3a1

固定 tag `4.3a1` 指向
[`2f3e56c0ddbd3a1aa54ed043643b553d26a069f6`](https://github.com/borglab/gtsam/tree/2f3e56c0ddbd3a1aa54ed043643b553d26a069f6)。

- `PreintegratedRotationParams::gyroscopeCovariance` 明确是 continuous-time gyro
  measurement covariance，标准差单位为 `rad/s/sqrt(Hz)`：
  [`PreintegratedRotation.h`](https://github.com/borglab/gtsam/blob/2f3e56c0ddbd3a1aa54ed043643b553d26a069f6/gtsam/navigation/PreintegratedRotation.h#L54-L69)。
- `PreintegratedAhrsMeasurements::integrateMeasurement` 按
  `P <- F P F^T + Sigma_g * dt` 传播 measurement covariance：
  [`AHRSFactor.cpp`](https://github.com/borglab/gtsam/blob/2f3e56c0ddbd3a1aa54ed043643b553d26a069f6/gtsam/navigation/AHRSFactor.cpp#L53-L77)。
- 官方 `AHRSFactor` 直接用 `pim.preintMeasCov_` 构造 Gaussian factor；没有把与另一
  个传感器的 disagreement 再写回 gyro covariance：
  [`AHRSFactor.cpp`](https://github.com/borglab/gtsam/blob/2f3e56c0ddbd3a1aa54ed043643b553d26a069f6/gtsam/navigation/AHRSFactor.cpp#L149-L153)。
- 普通 IMU factor 之外，官方 example 用相邻 bias variables 的 zero-mean
  `BetweenFactor<imuBias::ConstantBias>` 表示 bias evolution：
  [`ImuFactorsExample.cpp`](https://github.com/borglab/gtsam/blob/2f3e56c0ddbd3a1aa54ed043643b553d26a069f6/examples/ImuFactorsExample.cpp#L253-L263)。

### 2.2 Kalibr / EuRoC noise contract

Kalibr 官方 IMU noise model 把 gyro bias 写成 Brownian motion：

```text
b[k] = b[k-1] + sigma_bg * sqrt(dt) * w[k]
```

其中 `gyroscope_random_walk` 是 continuous-time `sigma_bg`，单位
`rad/s^2/sqrt(Hz)`；见
[`IMU Noise Model`](https://github.com/ethz-asl/kalibr/wiki/IMU-Noise-Model)。

本仓库 EuRoC loader 已保留该标定量为 `ImuParameters::gyrRw()`；MH_01 的原始
`sensor.yaml` 值为 `1.9393e-05`。当前 B3 estimator 尚未消费它。

## 3. 本仓库现状审计

### 3.1 已确认事实

- 所有 active AHRS edge 都连接同一个 `W(0)`。
- `W(0)` prior center 永久固定在前 100 s visual/gyro alignment 的结果，sigma
  固定为 `1e-6 rad/s`。
- `makeAhrsNoise()` 在 PIM covariance 上额外加
  `alignment_residual_rms_rad^2 / 3 * I`。
- 这份 alignment residual 是 pure-VO relative rotation 与 gyro relative
  rotation 的 disagreement，混合了 visual error、gyro error、bias/model error，
  不是独立测得的 gyro sensor covariance。
- 默认 `imu_prior_pose_sigma` 与原视觉
  `prior_rotation_sigma_rad/prior_translation_sigma_m` 都等于 `1e-4`；因此当前
  MH_01 上 activation 没有偷偷改变 pose anchor 权重。该重复配置仍是后续清理债，
  但不是本次 ATE 回退来源。

### 3.2 推断

把整份 visual/gyro disagreement 写进 gyro factor covariance，会把已由 stereo
reprojection factors 表达的 visual uncertainty 再归给 IMU。它不是 GTSAM 的标准
factor covariance ownership，且会系统性降低 gyro 权重。

这不等于“sensor-only covariance 必然最好”：EuRoC 标定只描述传感器随机噪声，
timestamp、外参、离散积分与 reference truth 自身仍会贡献未建模误差。因此下文用
covariance A/B 检验该推断，而不是直接把 scale 固化为 0。

## 4. bias random-walk：模型正确，但当前窗口不可观

### 4.1 probe 改动

`scripts/gyro_bias_alignment_probe.py` 新增固定长度 rolling-window 模式：

```bash
python3 scripts/gyro_bias_alignment_probe.py \
  <gyro-run> <vo-run> <MH_01-root> \
  --rolling-window-pairs <N> --rolling-stride-pairs <S> --output <csv>
```

每行只包含完整窗口，并用 `pair_count/start_ns/end_ns` 明确 support。测试覆盖完整
窗口、stride 与非法窗口合同。

### 4.2 MH_01 gyro-active suffix

输入：

- accepted timestamps / init seed：`m44_gyro_visual_init_b3`
- relative rotations：paired VO sentinel `m44_gyro_clean_imuoff_sentinel`
- reference bias：EuRoC `state_groundtruth_estimate0/data.csv`
- active start：`1403636679863555584 ns`

| support | rolling bias error median | p90 | estimate step median | fixed 100 s bias error median |
|---:|---:|---:|---:|---:|
| 0.5 s | 3.081e-3 | 6.033e-3 | 4.322e-3 | 4.284e-4 |
| 1.0 s | 2.327e-3 | 4.364e-3 | 2.136e-3 | 4.284e-4 |
| 5.0 s | 1.330e-3 | 1.955e-3 | 7.316e-4 | 4.280e-4 |
| 10.0 s | 1.080e-3 | 1.483e-3 | 3.369e-4 | 4.280e-4 |

同一 stride 上 reference bias step 中位数只有约 `1e-6 rad/s`。短窗估计跳变比
真实变化大三到四个数量级；10 帧 estimator window（约 0.5 s）没有独立估计
per-frame bias 的数值支持。

结论：per-state random-walk 是成熟且正确的最终模型，但现在实施只会增加弱可观
自由度。B4 不走这条刀；待窗口/边缘化合同能保留更长 bias evidence 后再恢复。

## 5. gyro 与 visual rotation 的 reference 对照

对 gyro-active suffix 的 1658 个可对拍 interval，以 EuRoC GT quaternion 做时间
插值，比较 `R_i^T R_j`：

| source | rotation error RMS | median | p90 | max |
|---|---:|---:|---:|---:|
| paired VO | 5.575e-4 rad | 3.719e-4 | 7.851e-4 | 4.551e-3 |
| gyro + fixed aligned bias | 3.436e-4 rad | 2.777e-4 | 5.062e-4 | 1.199e-3 |
| gyro + reference bias | 3.417e-4 rad | 2.766e-4 | 5.115e-4 | 1.221e-3 |

固定 bias 与 reference bias 几乎同档，且 gyro 在 `1079 / 1658` 个 interval 优于
VO。事实支持“gyro measurement 有信息”；不支持“bias drift 是当前主要瓶颈”。

### 6.3 决策

- 否决用 alignment residual scale 调权重收口；不选择 `1.2` 这种未过门的窄点；
- 临时 estimator option、CLI 与对应测试已删除，生产合同恢复固定 B3 行为；
- 不实施当前 0.5 s rolling window 上不可观的 per-frame bias；
- 下一步转向 staged translation/gravity alignment 只读探针。探针先固定 stereo
  metric scale 与 gyro-aligned rotation，按 VINS/Kimera 顺序只解 velocities +
  gravity，不把 full accelerometer bias 与 gravity 同时塞进初始化。

## 7. 尚未解决的风险

- GT attitude/bias 是 EuRoC reference，不是完全独立 truth；本次只用于离线归因，
  绝不能成为运行时输入。
- sweep 只能说明当前 MH_01 上没有 covariance 甜区，不能外推其他序列；由于首门已
  失败，按合同没有运行 MH_05。
- 当前 rolling graph 没有真正 marginalize bias covariance；在解决长支持 evidence
  前，不应仅为“结构像标准 VIO”而加入 per-frame bias。
