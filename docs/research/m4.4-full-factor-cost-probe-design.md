## 3. 模块与数据流

不新增 CLI 或 estimator 行为开关。estimator 在成功的 full optimization 后只读现有
`graph / initial values / optimized values`，生成一个可选
`FullGraphCostDiagnostics`：

```text
buildGraph → LM optimize → summarizeFullGraphCosts(graph, init, post)
                                      │
                                      ├─ newest/all ImuFactor
                                      ├─ all stereo factors
                                      └─ pose/velocity/bias priors
                                                    │
                                                    ▼
                              UpdateDiagnostics → vio_state.csv
```

helper 不写 `window`、landmark、bias、velocity 或 graph。normal run 只多一次只读 factor
evaluation；CSV 仍只在已有 `--vio-state-probe` 路径写出。primary LM 后记录 primary；若
outlier reopt 成功，则用最后一个成功 round 的 init/post 覆盖，以匹配最终提交的 state；
失败并 rollback 的 round 不覆盖。

## 4. 字段合同

`FullGraphCostDiagnostics` 只在本 update 实际使用 full graph 且 summary 完整时存在：

| 组 | 字段 |
|---|---|
| 结构 | `imu_factor_n`、`stereo_factor_n` |
| total | init/post graph cost |
| IMU aggregate | init/post all-IMU cost |
| newest IMU | init/post cost；init/post `|dR| rad`、`|dP| m`、`|dV| m/s` |
| stereo aggregate | init/post stereo robust cost |
| oldest pose prior | post `|dR| rad`、`|dt| m`、cost |
| oldest velocity prior | post residual norm `m/s`、cost |
| shared bias prior | post acc/gyro residual norm、cost |

非 full row 不伪造有效数据：CSV 的 `factor_cost_valid=0`，其他 numeric 字段写 `0`。
full row 缺 summary、count 不匹配、字段非有限或 cost/residual 为负时，sidecar run 明确
失败；normal estimator 不因 probe summary 缺失而改变 update transaction。

## 6. 选刀规则

- newest IMU init 物理 residual 已持续异常：先核对 frame/extrinsic/timestamp/PIM 合同；
- init residual 合理，但 IMU normalized cost 远压 stereo 且 optimizer 强拉视觉 pose：设计
  单一 covariance-consistency probe，不先扫 noise；
- IMU post cost 低，而 velocity/pose prior cost 或 frame-to-frame correction 随滑窗累积：
  优先 persistent prior/marginalization vertical slice；
- bias prior cost 高且放开 bias 明显降低 IMU/total cost：bias 是补偿变量，必须先找到被
  补偿的 measurement/history mismatch，不能再把 bias drift 本身当根因。

该探针只选择下一刀，不替代 MH_01/MH_05 `VIO < VO` 双指标验收。

## 9. 结论与下一刀

事实：

1. optimizer 每帧都把 4 mm 量级的视觉/PnP 与 inertial displacement 分歧压到
   micrometre 级，而不是留下高 IMU posterior residual；
2. oldest pose/velocity prior 没有承担对应量级的 normalized cost；
3. shared `ba` 随时间逐步偏离 prior，且前一轮 frozen-`ba` 已证明阻止该补偿会让
   trajectory 更差；
4. alignment held-out 的 inertial-vs-visual RMS 实际为 `1.901 mm`，与 full
   graph newest `|dP|` 同属 millimetre 量级，但 raw PIM covariance 没有包含这项实测
   model discrepancy。

推断：当前最直接、可证伪的 mismatch 是 full `ImuFactor` 仍按传感器白噪声传播的
covariance 对待整套模型，而 activation gate 实际只证明了 millimetre 级 held-out
一致性。局部 objective 看似很低，是因为 factor 被满足，不等价于全局 trajectory
正确。窗口重建不保留 Schur-complement history 仍是明确架构债，但本探针尚未证明它
比 covariance mismatch 更先致因。

按第 6 节冻结规则随后完成了单臂 **alignment-calibrated covariance consistency
probe**。它把 newest IMU initial cost median 从 `15046.1` 降到 `1.858`，证明
overconfidence 机制确实被解除；但 MH_01 全程候选 ATE/RPE=
`0.0963460/0.0181547 m`，paired VO=`0.0809641/0.0177812 m`，full suffix 亦双门
失败。因此该臂已否决并恢复 raw factor covariance，不运行 MH_05、不做 noise/prior
sweep。

下一步转入 no-write transition/window-history 诊断。先分别计算 frozen prefix 与 full
suffix 的刚体对齐，量化 activation 前后是否出现 gauge/phase mismatch；只有排除相位
问题后，才把窗口重建缺少 Schur-complement history 当作下一项 causal hypothesis。
