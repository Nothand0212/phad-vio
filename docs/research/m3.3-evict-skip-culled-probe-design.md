## 行为

| 项 | 约定 |
|---|---|
| CLI | `--evict-skip-culled`（flag），默认 **关** |
| 时机 | skip 当帧：对完整 `culled_landmark_ids` 调 `StereoTracker::markEvictable` |
| 腾槽 | 下一（及后续）`process` → `detectNewTracks`：占用 = non-evictable；缺槽时按 id **升序**驱逐 evictable，再 GFTT |
| 非 skip | 仍立即 `dropTracks`（与 ④f 一致） |
| hash | **不**进 `flattenConfig` |
| 计数 | `evictable_marked`（skip 标记次数）、`tracks_evicted`（`FrameStats.evicted` 累计） |
| 关 | ≡④f（skip 且不 mark） |
