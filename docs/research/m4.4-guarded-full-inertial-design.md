## 1. 目标与非目标

B5 在现有 `vision_only → gyro_visual` 之上增加第三阶段
`full_visual_inertial`。只有无 GT 的运行时 alignment gate 通过后，才把
accelerometer、velocity、gravity 与 shared `ba` 接入既有 stereo BA。

本片必须：

1. `enable_imu=false` 继续走原 VO 路径；
2. gate pending/rejected 不改变已发布 gyro-visual pose、accepted schedule 或 KF
   feedback；
3. full graph 不重复添加 AHRS factor；
4. 使用真实 raw IMU interval、arbitrary visual-world gravity 与 GTSAM `ImuFactor`；
5. MH_01/MH_05 exact-common ATE、1 s RPE translation 都严格优于 paired VO，否则
   不扩 11/11。

本片不做 per-frame bias RW、marginalization、monocular scale、在线外参/时延标定，
也不把 probe 阈值暴露成一组临时 CLI knobs。

## 2. 模块边界

新增 estimator-private 深模块 `imu_alignment.hpp/.cpp`：

```text
AcceptedAlignmentFrame {timestamp, T_W_B, raw interval, gap}
                    │
                    ▼
GuardedImuAlignment::estimate(train 10 s, stride 10, bg, static ba, |g|)
                    │  candidate {g_W, shared ba, per-train velocity, condition}
                    ▼
GuardedImuAlignment::validate(next 1 s full-rate visual poses + IMU)
                    │
                    ├─ condition >= 12 or ratio >= 0.8 → rejected/pending
                    └─ both pass → accepted state at validation end
```

该模块只依赖 `phad::sensor`/Eigen/POD，不依赖 landmark、GTSAM graph、apps、GT 或
benchmark。它复用与 production PIM 相同的 left-sample interval 语义；合成测试作为
Python oracle 对拍 C++ 输出。

`StereoVoEstimator::Impl` 只负责编排：维护最近 11 s 连续 accepted evidence、1 s
attempt cadence、状态事务，以及把 accepted alignment 映射到当前 window。apps 只写
sidecar，不反向参与 gate。

## 3. 数据流与状态机

### 3.1 evidence 生命周期

- 从视觉 seed 后就保留最近 11 s accepted pose + 已消费 raw IMU interval；
- gap、re-anchor、非连续 `t_prev` 清空 history；
- gyro alignment 未完成时只缓存，不尝试 translation alignment；
- gyro 激活后，最早在 1 s validation 到齐时尝试；失败后每 1 s 滚动重试；
- rejected attempt 是正常 pending，不返回 `kRejected/kFailed`；数值非有限、时间合同
  破坏或 solver 自身失败才是显式 `kFailed`。

### 3.2 activation transaction

一次 attempt 使用 `[t-11,t-1]` train 与 `(t-1,t]` held-out validation：

1. 固定 `bg=gyro_bias_prior` 与 metric scale；
2. static `ba` 下先解 velocity + fixed-norm gravity；
3. 在 gravity tangent 上解 shared constant `ba`；
4. 要求 column-scaled condition `<12`；
5. 从 train-end velocity 开环传播 validation，要求 inertial/visual disagreement RMS
   除以 CV/visual disagreement RMS `<0.8`；
6. 通过时保存 validation end 的 `g_W/ba/v_W` 和 validation 各帧 velocity；该 update
   仍使用 gyro graph；下一 update 才进入 full graph。

这样同一视觉帧不会同时充当 held-out calibration evidence 与 full factor consumer。

### 3.3 full graph

full mode 的 graph variables：

- 每个 window frame：`X(k)`、`V(k)`；
- 整个 window：一个 `B(0)=ConstantBias(ba,bg)`；
- landmarks：既有 `L(id)`。

每条连续非-gap边即时从 raw samples 重建
`PreintegratedImuMeasurements(ba,bg,g_W)`，只建一个
`ImuFactor(X_i,V_i,X_j,V_j,B(0))`。AHRS factor 在 full mode 不再建立，避免同一 gyro
measurement 双计数。stereo factors 与 pose anchor 保持不变。

PIM 参数取已存在的 EuRoC/GTSAM 合同：

- `accel noise density = 2.0e-3 m/s²/sqrt(Hz)`；
- `gyro noise density = 1.6968e-4 rad/s/sqrt(Hz)`；
- `integration covariance = 1e-8 I`；
- `n_gravity = alignment.g_W`，不旋转整个 visual gauge。

oldest velocity prior sigma `0.1 m/s`；shared bias prior 以 alignment 为中心，gyro sigma
沿用 `1e-6 rad/s`，acc sigma `0.1 m/s²`。这些是被 factor 实际消费、进入
`config_hash` 的概率模型，不是 CLI-only sweep。

正常帧 pose initial value 仍归视觉 CV/PnP 所有，避免重现 B3 的 gyro-seeded basin
级联；velocity initial value由上一 posterior 经 IMU 传播。full NavState prediction 只供
velocity initial/re-anchor/diagnostics，不能绕过视觉 translation support 门。

## 4. 错误、dropout 与回滚

- alignment 条件/ratio 未过：继续 `gyro_visual`，不是错误；
- history gap/re-anchor：清 history；若尚未 full，等待 11 s 新 support；
- full mode 遇 gap/re-anchor：事务性退回 `gyro_visual`，清 `V/ba/g`，重新积累，避免
  无 IMU edge 的 velocity variable 冒充可观；
- graph build、PIM covariance 或 LM 非有限：`kFailed`，恢复 window/landmark/
  velocity/shared bias/full-mode 状态，pending IMU 保留；
- cull reopt 必须重建同一 full graph；任一 reopt 失败按既有 round rollback；
- optimizer 必须回写每个 `V(k)` 与 shared `B(0)`；缺 key、非有限或异常不能静默
  沿用初值。

## 5. 诊断

`FusionMode` 新增 `kFullVisualInertial`。accepted IMU-on sidecar 增加：

- alignment attempted/accepted、condition、validation ratio；
- gravity、velocity、shared `ba`；
- full IMU factor count。

主 `diag.csv` 与 IMU-off 三份主产物不加 probe-only列；`bias_acc` 只在 full mode
写真实 posterior，其他模式仍为 0。runtime gate 不读取 sidecar。

## 6. 测试与验收

### 6.1 synthetic / transaction

1. C++ alignment 与 Python oracle：gravity/velocity/shared-ba、Jacobian、condition；
2. poor rotation excitation 得到 rejected attempt，不产生假成功；
3. held-out ratio 的 PASS/FAIL 两支；
4. activation 所在 update 仍是 gyro graph，下一 update 才 full；
5. full graph stationary、constant velocity、constant acceleration/rotation；
6. absolute bias 只扣一次；AHRS/ImuFactor 互斥；
7. gap/re-anchor demotion、pending interval、LM rollback；
8. IMU-off byte sentinel。

### 6.2 真实门

1. MH_01：health + exact-common ATE/RPE translation 严格优于 paired VO；
2. 未通过立即停止，不跑 MH_05；
3. 通过后跑 MH_05，同门严格通过；
4. 两序列都通过后才扩 11/11；每序列分别过门，不能用平均值掩盖失败；
5. baseline 文档记录 `meta.json.config_canonical_text` 与 config hash。

probe 的 one-step PASS 只是进入实现的前置证据，不替代上述 trajectory gate。
