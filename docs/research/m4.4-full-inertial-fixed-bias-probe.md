## 1. 已确认事实

### 1.1 首个 B5 真实运行未过门

MH_01 `m44_full_inertial_b5` 的固定配置 hash 为 `865fa580`。运行健康，
completion=`0.999728`、coverage=`1`，但 paired exact-common 硬门失败：

| support | VIO ATE / RPE translation RMSE (m) | VO ATE / RPE translation RMSE (m) | 结论 |
|---|---:|---:|---|
| 全部 3681 poses | `0.249563 / 0.0186294` | `0.0809641 / 0.0177812` | 两项 FAIL |
| full 激活前 2021 poses | `0.0391611 / 0.0148634` | `0.0392149 / 0.0148534` | ATE 微优，RPE 微劣 |
| full 激活后 1660 poses | `0.279138 / 0.0224558` | `0.0790578 / 0.0208636` | 两项 FAIL |

因此退化已定位到 `full_visual_inertial` suffix；按 B5 停止条件，不跑 MH_05。

### 1.2 runtime alignment 候选是健康的

同一运行在 timestamp `1403636680813555456` 接受唯一一次 runtime alignment：

- column-scaled condition=`6.27452 < 12`；
- held-out ratio=`0.551002 < 0.8`；
- activation update 仍为 `gyro_visual`，下一 update 才进入 full graph。

用现有只读 Python oracle 对同一 10 s train + 1 s held-out 重算，得到：

- estimated `ba=[-0.044698, 0.137106, 0.072149] m/s²`；
- train-end reference `ba=[-0.026302, 0.137400, 0.076259] m/s²`；
- `ba` error=`0.018852 m/s²`；
- gravity tilt error=`0.131528°`；
- held-out inertial prediction RMS=`0.000822 m`；
- held-out constant-velocity prediction RMS=`0.004309 m`。

这说明“候选本身明显错误”与当前证据不符。

### 1.3 短窗 posterior `ba` 明显漂移

首个 full posterior 的 `ba=[-0.010926, 0.069479, 0.050290] m/s²`；末个 full
posterior 为 `[-0.070935, -0.400979, 0.064644] m/s²`。full suffix 内 posterior
`|ba|` 范围为 `0.0114..0.6627 m/s²`，而固定 alignment prior 中心不变。

当前 graph 每次只重建最近 10 帧，并以 `sigma_ba=0.1 m/s²` 让一个 shared `B(0)`
同时与短窗内 pose、velocity、视觉 landmark 竞争；没有把上一窗口的 Schur complement
作为 marginalization prior 带入下一窗口。

## 2. 上游合同与证据边界

### 2.1 GTSAM

固定 revision `2f3e56c` 的 `ImuFactor` 是 `(X_i,V_i,X_j,V_j,B_i)` 五元因子；源码
明确说明它不建模 bias temporal consistency，该生命周期由 caller 决定：

- [`ImuFactor` 合同 L176-L226](https://github.com/borglab/gtsam/blob/2f3e56c0ddbd3a1aa54ed043643b553d26a069f6/gtsam/navigation/ImuFactor.h#L176-L226)
- [bias-corrected residual L136-L148](https://github.com/borglab/gtsam/blob/2f3e56c0ddbd3a1aa54ed043643b553d26a069f6/gtsam/navigation/ImuFactor.cpp#L136-L148)

GTSAM 也提供 `NonlinearEquality<T>` 固定一个变量；其 exact constructor 使用 constrained
noise model。官方 stereo example 提醒 exact equality 会让线性求解改用 QR，因此虽然
语义最干净，却会把 solver backend/performance 一起带入本次因果试验：

- [`NonlinearEquality` exact/inexact constructors L44-L104](https://github.com/borglab/gtsam/blob/2f3e56c0ddbd3a1aa54ed043643b553d26a069f6/gtsam/nonlinear/NonlinearEquality.h#L44-L104)
- [官方 stereo example 的 QR 说明 L100-L111](https://github.com/borglab/gtsam/blob/2f3e56c0ddbd3a1aa54ed043643b553d26a069f6/examples/StereoVOExample_large.cpp#L100-L111)

因此本探针不用 exact equality；沿用同一 Gaussian graph，只把 acc-bias prior sigma 收紧到
现有 gyro-bias 冻结值 `1e-6`。它不是物理 noise 标定，而是“取消该自由度”的数值实现。

### 2.2 ORB-SLAM3 与 VINS-Fusion

ORB-SLAM3 初始化时会在多 keyframe 联合图中优化 shared bias；正常 full inertial BA
则使用 per-keyframe bias 与 RW edges。它在初始化后约 5 s/15 s 继续 refine，不能证明
“10 帧 rebuild-and-reprior shared bias”可观：

- [ORB-SLAM3 inertial initialization L3042-L3224](https://github.com/UZ-SLAMLab/ORB_SLAM3/blob/4452a3c4ab75b1cde34e5505a36ec3f9edcdc4c4/src/Optimizer.cc#L3042-L3224)
- [post-init staged refinement L180-L239](https://github.com/UZ-SLAMLab/ORB_SLAM3/blob/4452a3c4ab75b1cde34e5505a36ec3f9edcdc4c4/src/LocalMapping.cc#L180-L239)

VINS-Fusion 的 fixed window 会回灌上一轮 marginalization factor，并在移除旧状态时生成
下一轮 prior；这也不同于当前每帧重新锚定窗头：

- [旧 marginalization factor 回灌 L1045-L1061](https://github.com/HKUST-Aerial-Robotics/VINS-Fusion/blob/be55a937a57436548ddfb1bd324bc1e9a9e828e0/vins_estimator/src/estimator/estimator.cpp#L1045-L1061)
- [IMU state marginalization L1140-L1171](https://github.com/HKUST-Aerial-Robotics/VINS-Fusion/blob/be55a937a57436548ddfb1bd324bc1e9a9e828e0/vins_estimator/src/estimator/estimator.cpp#L1140-L1171)

**工程推断：** 当前 observed `ba` drift 与 full suffix 退化同步，且 alignment 候选通过
GT/reference 与 held-out 双重检查，所以“短窗重估 `ba` 是主要回归源”值得做一次单因果
消融。但相关性尚不能证明因果，必须由下面的 A/B 决定。

## 3. 单因果 A/B 合同

control 固定为已完成的 `m44_full_inertial_b5`；candidate 只改一项：

```text
estimator.imu_prior_bias_acc_sigma: 0.1 -> 1e-6
```

保持不变：

- 同一个 10 s train、1 s held-out、condition/ratio gate 与 activation timestamp；
- 同一个 alignment `g_W/ba/v_W` 候选；
- 同一个 GTSAM `ImuFactor`、acc/gyro white noise、integration covariance；
- 同一个 pose/velocity prior、visual factors、window、cull/reopt 与 keyframe schedule；
- 不增加 CLI knob，不做 sigma sweep，不读取 GT 参与 runtime decision。

candidate 必须额外满足：

1. synthetic lifecycle 中首个和后续 full posterior `ba` 均与 accepted alignment 候选
   `isApprox(..., 1e-5)`；
2. full graph 仍有 `ImuFactor>0`、AHRS factor=`0`，不能退化成伪 full；
3. MH_01 activation timestamp、condition、ratio 与 control 仅允许浮点末位差异；
4. full suffix `ba` 最大漂移 `<=1e-5 m/s²`；
5. health/completion/coverage 门不退化。

## 4. 判定与停止条件

- 若 MH_01 exact-common ATE 与 RPE translation 都严格优于 paired VO，才跑 MH_05；
- 若仅明显优于 B5 control、但仍未双胜 VO，则确认 `ba` drift 是一项因果源，同时判定
  frozen-`ba` 不足以完成 M4.4；记录结果后转向 persistent prior/marginalization 或 factor
  residual probe，不扫 sigma；
- 若与 control 持平或更差，则否决该假设，恢复 `sigma_ba=0.1`，不得把“freeze”混入
  后续刀；
- 即使双门通过，也只能暂时说明 frozen-`ba` 在 MH_01/MH_05 有效。是否长期采用，仍需
  11/11 每序列门与 runtime bias/reference drift 审计，不能引用 ORB/VINS 作为直接证明。

## 5. 实际结果（否决）

candidate 输出：

```text
run=m44_full_inertial_b5_fixed_ba
config_hash=66ba2e00
completion_rate=0.999728
coverage_rate=1
ATE=0.691356 m
RPE_translation=0.0334161 m
```

因果合同成立：

- activation timestamp 仍为 `1403636680813555456`；
- condition/ratio 逐位保持 `6.27451686540235 / 0.55100234141038329`；
- full rows=`1660`，首个 full `imu_factor_n=9`；
- 首个 posterior `ba=[-0.0450452,0.134154,0.0700711] m/s²`；
- full suffix 最大 `ba` drift=`2.36e-9 m/s²`。

exact-common 结果：

| support | frozen-`ba` VIO ATE / RPE (m) | paired VO ATE / RPE (m) | verdict |
|---|---:|---:|---|
| 全部 3681 poses | `0.691356 / 0.0334161` | `0.0809641 / 0.0177812` | FAIL |
| full suffix 1660 poses | `0.620270 / 0.0471578` | `0.0790578 / 0.0208636` | FAIL |

相对未冻结 B5 control 的全段 `0.249563 / 0.0186294` 也显著恶化。因此：

1. `ba` drift 不是当前 full suffix 退化的主要因果源；它更可能是短窗 graph 用于吸收
   其他模型/约束误差的症状；
2. alignment 候选 1 s held-out 健康，不等于冻结它可支持余下约 83 s；
3. 拒绝继续收紧 bias prior 或做 sigma sweep；已恢复 `sigma_ba=0.1`；
4. 下一步必须直接观测 newest IMU factor、窗头 pose/velocity prior 与视觉 correction 的
   whitened residual/cost，区分 measurement model、概率权重与 rebuild-and-reprior 信息丢失。
