# M3.3 Slice ⑤b 非关键帧位姿精修 + 关键帧选择修复

**Goal:** 修复 Slice ⑤ 全序列恶化（5 改善 / 6 恶化，V2_02 +5400%）。根因：
非关键帧 PnP 位姿质量差（CV 链被污染）+ 关键帧选择对旋转不敏感 + snapshot/空观测
实现漏洞。

**Architecture:** 方案 A（ORB-SLAM3 模板）：非关键帧 PnP 后对 inlier 集跑
pose-only LM 精修（只优化新帧位姿，landmark 固定）。方案 B（VINS/DKB 模板）：
旋转补偿视差 + 低 track 强制关键帧 + snapshot 条件更新 + 空观测修复。保持
关键帧窗口语义不变。

**Tech Stack:** 既有 GTSAM（LM + Huber + GenericStereoFactor）、OpenCV
（solvePnPRansac）、Eigen（旋转投影）。无新依赖。

Issue：[#27](https://github.com/Nothand0212/phad-vio/issues/27)，Part of
[#23](https://github.com/Nothand0212/phad-vio/issues/23)。

## 已对齐的决策

| 决策点 | 结论 |
|---|---|
| 非 KF 位姿 | PnP RANSAC 后 pose-only LM 精修（inlier 集，Huber） |
| 非 KF 门控 | `shared < min_pnp_inliers` → kRejected（不写 est.tum 不更新链） |
| 旋转补偿视差 | 用 `last_accepted_T_W_B` 旋转投影上一 KF 观测到当前帧再测视差 |
| 低 track 强制 | 观测数 < `min_pnp_inliers`（10）→ 强制关键帧 |
| snapshot 条件 | 仅 `update.status == kOk` 时更新 snapshot |
| 空观测 | 0 观测帧不触发虚假关键帧（配合 snapshot 条件更新） |
| 主路径恒速外推 | **不改** dt 归一化（行为变更风险，留给后续片） |
| 窗口语义 | 保持 10 关键帧窗口，非 KF 不进 BA（方案 C 后续再评估） |
| 阈值 | 视差阈值暂保持 30 px（旋转补偿后语义变化，先验证再调） |
| 非目标 | 不改 cull/reopt/reanchor；不实现 IMU；不调 session/cull 阈值 |

## Task 2：非关键帧 pose-only 精修

修改 `phad/estimator/stereo_vo_estimator.cpp`：

在 PnP 成功（`pnp.success`）且仲裁通过后，`candidate.T_W_B` 已设为 proposal。
非关键帧路径在此插入精修：

```cpp
// 非关键帧：PnP proposal 上做 pose-only LM 精修（ORB-SLAM3 PoseOptimization 模板）
if ( !keyframe )
{
  if ( pnp 成功且仲裁通过 )
  {
    // 构建只含新帧 pose 的图：inlier 集 StereoFactor + Huber
    NonlinearFactorGraph refine_graph;
    Values refine_values;
    Symbol pose_key('x', next_frame_index);
    refine_values.insert(pose_key, toPose3(candidate.T_W_B));
    for ( inlier 集中的每个观测 )
      refine_graph.add(GenericStereoFactor(..., huber_noise, pose_key, landmark));
    try {
      auto refined = LevenbergMarquardtOptimizer(refine_graph, refine_values).optimize();
      candidate.T_W_B = toIsometry(refined.at<Pose3>(pose_key));
    } catch (IndeterminantLinearSystemException) {
      // 回退 PnP 原始位姿
    }
  }
  // 后续：更新 last/prev + estimate（现有）
}
```

关键点：

- Huber noise：复用 `stereo_noise` 的 robust 包装（`makeStereoNoise` 已有
  `Huber::WithChiSquared` 逻辑？——检查现有实现；若 `huber_k_px > 0` 已用
  `Huber::WithChiSquared` 或线性阈值，保持一致）
- inlier 集：从 `pnp.inlier_indices` 映射回观测（`shared_ids` 逻辑，与
  关键帧路径 PnP mask 相同）
- landmark 固定：`landmarks_W` 已有值（shared 的 landmark）
- 失败回退：LM 异常 → 用 PnP 原始 proposal

## Task 3：旋转补偿视差 + 低 track 强制关键帧

修改 `apps/offline_vo_session.cpp` `isKeyframeImpl()`：

```cpp
// Rule 0（插入）：观测数 < min_pnp_inliers → 强制关键帧
if ( tracks.observations.size() < 10 ) return true;  // 10 = min_pnp_inliers

// Rule 4（改造）：旋转补偿视差
// 用 last_accepted_T_W_B 的旋转（来自 estimator 上一接受帧）
// R_prev_to_cur = R_cur * R_prev⁻¹  （或恒速外推旋转）
// p_comp = R_prev_to_cur * p_lastkf
// parallax = mean || p_cur - p_comp ||
```

旋转来源：session 维护 `last_accepted_rotation`（每次 estimator kOk 后从
`update.estimate->T_W_B` 提取旋转矩阵）。恒速模型：用 last 与 prev 的旋转差
外推当前帧旋转（与 `poseInitialValue()` 一致）。

简化实现（先验证方向）：用 `last_accepted` 的旋转直接补偿——
`p_comp = R_last_accepted * R_lastkf⁻¹ * p_lastkf`？不对——需要把上一 KF 的
观测旋转到当前帧相机方向：

```
R_lastkf_to_cur = R_cur * R_lastkf⁻¹    （两帧旋转差）
p_comp = R_lastkf_to_cur * p_lastkf
parallax = mean || p_cur - p_comp ||
```

其中 R_cur 是当前帧的估计旋转（恒速外推或 last_accepted）。纯旋转时
`p_cur ≈ p_comp` → 视差 ≈ 0 → 不触发关键帧（正确！）。

## Task 4：snapshot 条件更新 + 空观测修复

修改 `apps/offline_vo_session.cpp` session 循环：

```cpp
// 当前（无条件）：
if ( is_kf ) updateKeyframeSnapshot( tracks, tracks.timestamp );

// 修复：
if ( is_kf && update.status == estimator::UpdateStatus::kOk )

```

`false`（非关键帧 → estimator 拒"empty observations"→ 不更新 snapshot）——
打破级联循环。
