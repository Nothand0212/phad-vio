# M4.4 B5 guarded full-inertial 实施计划

设计：
[`m4.4-guarded-full-inertial-design.md`](../research/m4.4-guarded-full-inertial-design.md)

本文档描述当前约定，不是绝对约束，会随项目开发修订。

## 1. Vertical slice

本片只交付：accepted visual/IMU history → staged `v/g/shared ba` → 1 s held-out
runtime gate → shared-bias GTSAM `ImuFactor` + per-window velocity + stereo BA。

不加入 per-state bias/RW、marginalization、monocular scale、额外 tracker/KF 改动或
probe-only CLI 调参。

## 2. 小步顺序

1. 在独立纯逻辑 module 写 synthetic 红测试并移植 Python 方程；
2. 固定 condition 与 validation ratio，先不接 estimator；
3. 写 estimator history/activation transaction 红测试；
4. 接 history，证明 pending/rejected attempt 不改变 gyro trajectory；
5. 写 full graph factor/absolute-bias/AHRS互斥红测试；
6. 接 `V/B/ImuFactor` 与 arbitrary gravity；
7. 接 sidecar diagnostics；
8. 定向 tests → unit → MH_01 → MH_05 → 11/11。

## 4. 定向验证

```bash
cmake --build build --target phad_estimator_tests phad_apps_tests phad_vo_bench -j2
./build/phad_estimator_tests \
  --gtest_filter='ImuAlignment.*:StereoVoImu.*'
./build/phad_apps_tests \
  --gtest_filter='VioStateProbeTest.*:VoBenchCliTest.*'
.venv/bin/python scripts/imu_translation_alignment_probe_test.py
python3 scripts/vio_state_probe_test.py
ctest --test-dir build -L unit --output-on-failure
git diff --check
```

## 5. 停止条件

- C++/Python oracle 不一致、condition/ratio synthetic 不可复现：不接 production；
- activation 改变其前 gyro trajectory/schedule：修 transaction，不解释 trajectory；
- MH_01 ATE 或 RPE 任一不严格改善：保留日志、停止 MH_05，不扫 prior/noise knob；
- MH_01 通过而 MH_05 失败：按 phase/alignment/full-factor 分解后停，不扩 11/11；
- 只有 11/11 每序列双门和健康门都通过，才可宣称 M4.4 精度目标完成。
