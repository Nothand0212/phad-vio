# M3.3 Slice ④ 优化后外点剔除与 landmark 生命周期

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在窗口 BA 写回后，按 landmark 聚合的平均像素重投影误差永久删除毒点，并清除窗口内该 id 观测，优先消化 Slice ③ 留下的 MH_05 发散债。

**Architecture:** 只改 `phad::estimator` 热路径后缀（PIMPL 内）；`dropCheiralityLandmarks` 与外点剔除共用 `eraseLandmarkFromWindow` helper。不重建图、不二次 LM。诊断经 session → bench 落盘。`phad::frontend` / `phad::eval` 不动。

**Tech Stack:** C++20、GTSAM `GenericStereoFactor::unwhitenedError`、GTest、`phad_vo_bench`。

Issue：[#23](https://github.com/Nothand0212/phad-vio/issues/23)。  
设计见 [M3.3 Slice ④ 设计](../research/m3.3-slice4-outlier-cull-design.md)，  
开源对照见 [Slice ④ 开源对照](../research/m3.3-slice4-outlier-cull-open-source-refs.md)，  
对照基线 [Slice ③](../research/m3.3-slice3-baseline.md)（`b712c91` / `default_8a9236e0`）。

- C++ 命名 / 风格遵循 `docs/agents/cpp-naming.md` 与 `docs/agents/cpp-style.md`（Allman、2 空格、`m_` 成员）。

- 提交 subject 带 `(#23)`；短生命周期分支（建议从 `main` 开 / 续 `m3.3`）。
- MH_01：ATE ≤ **0.099263** m，`segments=1` / `reanchors=0`；**不**要求 `est.tum` 与 Slice ③ 逐字节相同。

- **出口顺序强制**：编码完成后 **先 MH_05 诊断门**（Task 4），判定「够」后再 Task 5 全序列；「不够」则停、标明部分完成，回头讨论二次 LM。

## 已对齐的决策

| 决策点 | 结论 |
|---|---|
| 主模板 | BA 后 landmark **平均像素** ‖unwhitenedError‖₂ → 永久删；**不重优** |
| 作用域 | `landmarks_W.erase` + 清窗口各帧该 id；不回传 frontend |
| 伪永久 | 无拒绝名单；同 id 再喂 → 按新点 backproject；`culled_ids_` 跨段保留只为统计 |
| 阈值 | `outlier_avg_reproj_px = 3.0`；观测（因子）数 `< 4` 跳过（硬编码） |
| 开关 | `enable_outlier_cull` 默认 true；`false` **只关** mean-reproj；**cheirality helper 仍清观测** |
| 顺序 | LM 写回 → cheirality（含清观测）→ outlier cull → 写 `reproj_after` / `reproj_after_cull` |
| `reproj_after` | 仍为剔除**前**（outlier cull 前）全 graph RMS；`reproj_rms_after_cull_px` 跳过已删 id、不重建图 |
| `track_times` | **不删** |
| diag | 16→18：尾追加 `outliers_culled`,`reproj_rms_after_cull_px`（**无** unique 列） |
| summary | `robustness.outliers_culled` + `outliers_culled_unique`（累计） |
| MH_05 门 | 够 = ATE &lt; 1 m 且离开 ~1e4、cheirality 显著降、剔点偏前段、重复删除率≈1；不够则停 |

void eraseLandmarkFromWindow( LandmarkId id )

- [ ] **Step 1: 实现聚合与剔除（插在现有 cheirality 与写 `reproj_rms_after_px` 之间）**

现有尾部（约 `stereo_vo_estimator.cpp:1011–1019`）改为：

```text
cheirality_after / dropCheiralityLandmarks(optimized)   // 已含清观测
diagnostics.num_cheirality = max(...)

outliers_culled = 0; outliers_culled_unique = 0
if enable_outlier_cull:
  对每个仍在 landmarks_W 的 id:
    在 graph 上收集 key2()==L(id) 的 GenericStereoFactor
    n = 因子数
    if n < 4: continue
    score = mean_i( ||unwhitenedError_i(optimized)||₂ )
    if score > outlier_avg_reproj_px:
      landmarks_W.erase(id)
      eraseLandmarkFromWindow(id)
      ++outliers_culled
      if culled_ids_.insert(id).second: ++outliers_culled_unique

diagnostics.outliers_culled = ...
diagnostics.outliers_culled_unique = ...
diagnostics.reproj_rms_after_px = stereoReprojRms(graph, optimized)  // 全因子；语义= cull 前
diagnostics.reproj_rms_after_cull_px =
    stereoReprojRmsSkippingMissingLandmarks(graph, optimized)
    // 遍历 GenericStereoFactor；若 L(id) 已不在 landmarks_W 则跳过；不重建图
```

辅助实现要点：

```cpp
// 从 factor 取 landmark id：
const gtsam::Key lkey = stereo->key2();  // 与 emplace 时 L(id) 一致
const LandmarkId id = static_cast<LandmarkId>( gtsam::Symbol( lkey ).index() );

// enable_outlier_cull==false:
//   outliers_culled=0, outliers_culled_unique=0
//   reproj_rms_after_cull_px == reproj_rms_after_px
```

**不**因剔点改 `UpdateStatus`；**不**二次 `LevenbergMarquardtOptimizer`；
事务 `restore()` 范围不变（`landmarks_W` / `window` 仍在快照内——确认
`culled_ids_` **不要**放进可回滚快照，或回滚时也不撤销统计集合：统计是
跨帧诊断，失败帧不应插入；只在即将 `kOk` 返回前更新 `culled_ids_`）。

位姿：`estimate.T_W_B` 仍为第一轮 LM 写回的 `window.back().T_W_B`（不重优）。

- [ ] **Step 2: 合成单测**

| 用例 | 断言 |
|---|---|
| `CullsPersistentHighReprojLandmark` | ≥4 帧观测的毒点 → `outliers_culled≥1`；公开面无 `landmarks_W`，用行为：下一帧再喂同 id 时该 id **不在** `num_shared` 交集（先被当新点 backproject）；`observationTimestamps(id)` **仍在**（不删 track_times） |

| `KeepsInliersUnderThreshold` | 干净平移场景 → `outliers_culled==0` |
| `DisabledSkipsMeanReprojCull` | `enable_outlier_cull=false` → `outliers_culled==0`，`reproj_rms_after_cull_px == reproj_rms_after_px` |
| `PoseEqualsFirstLmWithoutReopt` | 触发 cull 的帧：`estimate.T_W_B` 与「同初值关掉 cull」对照位姿一致（或与写回后、cull 前缓存的位姿一致——实现时可在测试侧关 cull 跑孪生） |

| `CheiralityClearsWindowObservations` | behind-camera 删点后窗口无该 id 幽灵观测（下一帧图规模/无异常即可） |
| 既有 PnP / re-anchor / diagnostics | `ctest -R phad_estimator_tests` 不回归 |

毒点注入：对某一 landmark 的 `left_pixel` 加大幅偏移（如 +40 px），保持
`disparity_px`，连续 ≥4 个 accepted 帧；窗口填满后 BA 后 mean 应 > 3 px。
