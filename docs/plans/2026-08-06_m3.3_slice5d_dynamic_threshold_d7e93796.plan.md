# M3.3 Slice ⑤d 动态关键帧阈值（DKB-SLAM 运动自适应）

**Goal:** 消除序列间阈值冲突——MH 系列（直线运动）和 V1_01（快速旋转）对关键帧
密度有相反需求。用运动自适应阈值使直线时 T→30px（稀疏 KF，保留 MH 改善），
旋转时 T→10px（密集 KF，修复 V1_01 退化）。

**Architecture:** 改动集中在 `apps/offline_vo_session.cpp`（`KeyframeSelectorState`
+ `isKeyframeImpl`），不涉及 estimator。决策度量保持未补偿视差，新增旋转/平移
历史环形缓冲和 DKB 公式计算 T。

**Tech Stack:** 既有 C++20 / Eigen；无新依赖。

Issue：[#27](https://github.com/Nothand0212/phad-vio/issues/27)，Part of
[#23](https://github.com/Nothand0212/phad-vio/issues/23)。

## 背景

### 阈值冲突（5 个量化数据点）

| 配置 | MH_01 ATE | MH_05 ATE | V1_01 ATE | V1_01 kf_rate |
|---|---:|---:|---:|---:|
| ⑤c 30px | 0.063 ✓ | 0.306 ✓ | 0.514 ⚠️ | — |
| ⑤c 10px | 0.098 险 | 0.482 ✗ | 0.234 ✓ | 56.0% |
| ⑤b 10px | 0.059 ✓ | — | 0.425 ✓ | 56.2% |

MH 系列偏好稀疏 KF（30px），V1_01 偏好密集 KF（10px）。固定阈值无法同时最优。

### DKB-SLAM 公式（调研验证，RGB-D 无 IMU → 纯双目可迁移）

```
Δθ̄ = 最近 N=10 帧平均旋转角变化（deg）
Δt̄ = 最近 N=10 帧平均平移变化（m）
w_θ = Δθ̄ / (Δθ̄ + Δt̄ + 1e-5)
w_t = Δt̄ / (Δθ̄ + Δt̄ + 1e-5)
M_θ = log(1 + w_θ·Δθ̄)
M_t = log(1 + w_t·Δt̄)
F = (M_θ+M_t) / [log(1 + w_θ·45°) + log(1 + w_t·10m)]
T = 30 − F·(30−10)       // T∈[10,30] px
```

效应：直线运动 w_t→1, F→0, T→30px（稀疏 KF）；快速旋转 w_θ→1, F→1, T→10px
（密集 KF）。

## 已对齐决策

| 决策点 | 结论 |
|---|---|
| 旋转信号来源 | 位姿链恒速外推（`last_accepted` 旋转差，免费） |
| 统计窗口 | N=10（DKB 原版） |
| 阈值范围 | T∈[10,30] px |
| 旋转累积强制 KF | 加（累计旋转 >45° 即使视差小也强制） |
| 决策度量 | **保持未补偿视差**（旋转需要密集 KF，V1_01 证据） |
| 修改范围 | 仅 `apps/offline_vo_session.cpp` |

## Task 1：运动历史环形缓冲

`KeyframeSelectorState` 增加：

```cpp
// Slice ⑤d: motion history for adaptive threshold (DKB-SLAM).
static constexpr std::size_t kMotionWindowSize = 10;
std::deque<double> rotation_deg_history;   // per-frame rotation angle (deg)
std::deque<double> translation_m_history;  // per-frame translation (m)
// Accumulated rotation since last keyframe (force-kf rule).
double accumulated_rotation_deg = 0.0;
```

Session 循环中，每次 `update.status == kOk` 且 `update.estimate` 有值后
更新历史：

```cpp
if ( update.status == kOk && update.estimate.has_value() )
{
  kf_state.last_accepted_rotation = update.estimate->T_W_B.linear();
  // Compute inter-frame rotation angle and translation delta from
  // last accepted pose chain.
  if ( prev_pose_valid ) {
    double dR_deg = rotationAngleDeg(prev_R, cur_R);
    double dt_m = (prev_t - cur_t).norm();
    kf_state.rotation_deg_history.push_back(dR_deg);
    kf_state.translation_m_history.push_back(dt_m);
    // Trim to N.
    while (kf_state.rotation_deg_history.size() > kMotionWindowSize)
      kf_state.rotation_deg_history.pop_front();
    // … same for translation.
    // Accumulate rotation.
    kf_state.accumulated_rotation_deg += dR_deg;
  }
}
```

`rotationAngleDeg` 实现：`acos(clamp((trace(R_cur * R_prev^T)-1)/2), -1, 1)) * 180/π`。

## Task 2：DKB 动态阈值公式

在 `isKeyframeImpl` 中，用计算的 T 替换常量 `kKeyframeParallaxPx`：

```cpp
double computeAdaptiveThreshold(const KeyframeSelectorState& state) {
  if (state.rotation_deg_history.size() < kMotionWindowSize)
    return 30.0;  // not enough history; default to sparse

  double sum_R = 0, sum_t = 0;
  for (auto& d : state.rotation_deg_history) sum_R += d;
  for (auto& d : state.translation_m_history) sum_t += d;
  double dR_mean = sum_R / kMotionWindowSize;
  double dt_mean = sum_t / kMotionWindowSize;

  const double eps = 1e-5;
  double w_theta = dR_mean / (dR_mean + dt_mean + eps);
  double w_t     = dt_mean / (dR_mean + dt_mean + eps);

  double M_theta = std::log1p(w_theta * dR_mean);
  double M_t     = std::log1p(w_t * dt_mean);

  const double theta_max = 45.0, t_max = 10.0;
  double denom = std::log1p(w_theta * theta_max) + std::log1p(w_t * t_max);
  double F = denom > 0 ? (M_theta + M_t) / denom : 0.0;

  const double T_min = 10.0, T_max = 30.0;
  return T_max - F * (T_max - T_min);
}
```

在 `isKeyframeImpl` 中：
```cpp
// Rule 4: use adaptive threshold instead of constant.
const double T = computeAdaptiveThreshold(state);
if ( parallax_avg > T ) return true;
```

删除 `constexpr double kKeyframeParallaxPx = 30.0` 常量（将被动态 T 替代）。
