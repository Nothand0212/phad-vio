# M4.4 fixed-epoch IMU shadow probe 实施计划

设计：
[`m4.4-keyframe-shadow-probe-design.md`](../research/m4.4-keyframe-shadow-probe-design.md)

本文档描述当前约定，不是绝对约束，会随项目开发修订。

## 1. 实施顺序

1. estimator gyro rotation helper 与定向 tests；
2. gate alternative evidence 只读 seam 与 tests；
3. shadow accumulator/writer 与 tests；
4. session/bench CLI-only 接线和 config hash 回归；
5. Python analyzer 与 synthetic tests；
6. Release build、unit；
7. 完整 MH_01 sidecar run、主产物字节门和分析文档。

每一步保持 production `decision.selected` 只来自 B0 `pose_lag`。任何主产物差异都先
修 probe 隔离，不进入 guard 设计。

## 3. 定向命令

```bash
cmake -S . -B build -DCMAKE_EXPORT_COMPILE_COMMANDS=ON
cmake --build build --target \
  phad_estimator_tests phad_apps_tests phad_vo_bench -j2

./build/phad_estimator_tests --gtest_filter='ImuRotationTest.*'
./build/phad_apps_tests \
  --gtest_filter='KeyframeEpochGateTest.*:KeyframeShadowProbeTest.*:VoBenchCliTest.*'
python3 -m py_compile \
  scripts/keyframe_shadow_probe.py \
  scripts/keyframe_shadow_probe_test.py
python3 scripts/keyframe_shadow_probe_test.py
ctest --test-dir build --output-on-failure -L unit
```

## 5. 收口条件

本计划完成只表示 fixed-epoch evidence 已可靠采集。分析文档必须把事实、推断和
live-counterfactual 缺口分开；未出现机制证据时允许结论为“没有 guard 可晋级”。
不在本计划 commit、push、merge、关闭 issue 或实现 production guard。
