# M3.3 PnP stereo 一致性仲裁

**Goal:** 在 MH_02 首次错误 proposal 进入 graph/lifecycle 之前切断因果链，同时保留
健康场景中 PnP 相对恒速 guess 的收益。

**Architecture:** `StereoVoEstimator::Impl::tryPnpInit()` 继续负责 OpenCV
`solvePnPRansac`，但成功结果先在私有 helper 中与 `poseInitialValue()` 产生的 guess
对拍。两者只使用 RANSAC shared inlier 集，并按 GTSAM rectified stereo
measurement `(uL,uR,v)` 计算未白化 RMS；通过后才由 `update()` 采用 pose 和原
inlier mask。所有 mutation 保持在仲裁之后。

**Tech Stack:** 既有 C++20 / Eigen / OpenCV calib3d / GTSAM / GTest /
`phad_vo_bench` / `phad_traj_eval`；无新依赖。

Issue：[#25](https://github.com/Nothand0212/phad-vio/issues/25)，Part of
[#23](https://github.com/Nothand0212/phad-vio/issues/23)。

## 已对齐的决策

| 决策点 | 结论 |
|---|---|
| 模块边界 | estimator PIMPL；public `update()` test seam；不新增公开接口 |
| 支持集 | PnP 返回的 shared inlier indices；proposal 与 guess 使用完全相同的点 |
| score | `(uL,uR,v)` 未白化 RMS；非有限/cheirality 无效 |
| 采用 | proposal RMS ≤ guess RMS + `stereo_sigma_px`；guess 无效且 proposal 有效时采用 |
| fallback | guess + full measurement；`pnp_success=false`、`pnp_inliers=0` |
| 非目标 | 不改配置/hash/CSV/summary，不修 cull/reopt/零度 pose，不动 frontend/apps |
| 验收顺序 | synthetic RED → estimator → MH_02 prefix → MH_01 → MH_05 → 条件式 11 条 |

## Task 1：建立 public seam RED

修改 `tests/estimator/stereo_vo_pnp_test.cpp`：

1. 增加靠近 optical axis、depth 有变化的非退化 landmarks；
2. 用连续健康帧建立窗口与恒速 guess；
3. target frame 从错误 z-translation pose 取 left pixel，从健康 guess 取 disparity；
4. 另加 probe id：已有一次历史观测，target left pixel 为明显 RANSAC outlier；
5. 断言期望 fallback 后 `pnp_success=false`、`pnp_inliers=0`，且 probe 因第二次观测
   进入 graph；estimate finite。

先只运行新用例，记录当前实现的失败断言。若当前实现未稳定接受错误 PnP，调整合成
几何而不是修改生产路径；必须证明 RED 由缺少 stereo 仲裁造成。

目标命令：

```bash
cmake --build build --target phad_estimator_tests -j2
build/phad_estimator_tests \
  --gtest_filter=StereoVoPnpTest.FallsBackWhenPnpStereoRmsIsWorseThanGuess
```

## Task 2：最小实现

只改 `phad/estimator/stereo_vo_estimator.cpp`：

- 在 `tryPnpInit()` 收集与 OpenCV 输入平行的 shared observation references；
- 增加私有 `stereoRmsAtPose()`，仅依赖现有 calibration、`body_P_sensor`、
  `landmarks_W` 与 inlier indices；
- 明确检查 index、finite、`z>0`、投影与 residual；
- 对 proposal 与 guess 评分并按设计仲裁；拒绝时清空 inliers，返回默认失败结果；
- 通过后才设置 `PnpInitResult::success/T_W_B/inlier_indices`；
- 不改 `update()` 的 mask、track_times、rollback 或诊断赋值结构。

实现遵循现有 C++ naming/style，不新建通用 scorer abstraction，不新增配置和日志。
