# M4.4 initialization truth audit 探针实施计划

设计：
[`m4.4-vio-init-truth-probe-design.md`](../research/m4.4-vio-init-truth-probe-design.md)

本文档描述当前约定，不是绝对约束，会随项目开发修订。

## 1. Vertical slice

本次只交付：production static detector snapshot → apps 单行 CSV → EuRoC truth
analyzer → MH_01 选刀。现有 `vio_state.csv`、factor graph、初始化数值与 config
均不改变。

## 2. 测试先行顺序

1. estimator synthetic 红测试固定一次事件及已知 bias/statistics；
2. apps writer 红测试固定 33 列 schema、事务与失败路径；
3. CLI/session 红测试固定 CLI-only/hash/IMU-on 合同；
4. Python 红测试固定 EuRoC frame/timestamp 与派生量；
5. 最小实现直至定向 tests 变绿；
6. 完整 unit 与主产物隔离门；
7. MH_01 audit 与结果文档。
