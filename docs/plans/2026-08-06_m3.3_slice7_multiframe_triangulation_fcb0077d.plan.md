# M3.3 Slice ⑦ 多帧三角化

**Goal:** 补上"只用立体视差定深度"的结构缺陷。V2 低纹理走廊 SAD 右目成功率
仅 9-22%（estimator 饿死），但帧间平移 0.3-1m >> 立体基线——多帧三角化是
SVO 在 V2 成功的核心机制。

**Architecture:**
1. **glue 通道**：`toKeyframeMeasurement` 让 `kNoRightMatch` + `track.length>=2`
   的 track 进 estimator（`disparity_px=0` 标记"立体失败"）
2. **buildGraph 过滤**：`disparity_px=0` 观测不进 BA 因子（避免退化立体因子），
   仅作多帧三角化的观测源
3. **seed 分支**：关键帧 seed 时，`disparity_px=0` 的新 landmark 用窗口内
   ≥2 帧观测做两帧 DLT（GTSAM `triangulatePoint3`），视角差 ≥1° + cheirality
   门限；立体正常保持单帧 backproject

**Tech Stack:** GTSAM `triangulatePoint3`（`gtsam/geometry/triangulation.h`）。
无新依赖。

Issue：[#27](https://github.com/Nothand0212/phad-vio/issues/27)，Part of
[#23](https://github.com/Nothand0212/phad-vio/issues/23)。

## 已对齐决策

| 决策点 | 结论 |
|---|---|
| 深度来源 | 立体优先，多帧三角化补充 |
| 立体失败标记 | `disparity_px=0`（新增语义）|
| 三角化方法 | 两帧 DLT（GTSAM triangulatePoint3）|
| 视角差门限 | ≥1°（ORB-SLAM2 1.15°）|
| cheirality | 两帧相机前方检查 |
| 触发 | 关键帧 seed 时，立体失败的新 landmark |
| 非关键帧 | 仍不 seed（⑤c 不变）|
| buildGraph | `disparity_px=0` 不进 BA 因子 |
| 立体正常 | 保持单帧 backproject |

## Task 1：glue 通道改造

`apps/stereo_vo_glue.hpp`：

```cpp
for ( const frontend::TrackObservation& observation : tracks.observations )
{
  if ( observation.status == frontend::StereoStatus::kValid )
  {
    measurement.observations.push_back( { id, left_pixel, disparity_px } );
  }
  else if ( observation.status == frontend::StereoStatus::kNoRightMatch &&
            observation.length >= 2 )
  {
    // Slice ⑦: stereo failed but track is stable — multi-frame triangulation
    // candidate (disparity_px=0 marks "no stereo depth").
    measurement.observations.push_back( { id, left_pixel, 0.0 } );
  }
}
```

注意：`StereoObservation.disparity_px` 语义扩展——`0` = 无立体视差。

## Task 3：GTSAM triangulatePoint3 接入

确认 API（`gtsam/geometry/triangulation.h`），实现：

```cpp
// 两帧 DLT：窗口内找该 landmark 的 ≥2 帧观测（位姿 + 左目像素）
std::optional<Eigen::Vector3d> triangulateFromWindow(
    LandmarkId id, const WindowFrame& current, const std::deque<WindowFrame>& window )
{
  // 收集含 id 的帧（当前帧 + 历史）
  // 取与当前帧视角差最大的两帧（或最近两帧）
  // gtsam::triangulatePoint3(T_W_left1, p1, T_W_left2, p2, &point)
  // 检查: point 在 world 系, 两帧相机前方, 视角差 >= 1°
}
```

视角差计算：两相机中心到点的夹角（或两观测射线夹角）。

## Task 4：seed 分支

关键帧 seed 循环中，`disparity_px <= 0` 的观测：

```cpp
if ( observation.disparity_px <= 0.0 )
{
  auto point = triangulateFromWindow( observation.id, candidate, window );
  if ( !point ) continue;  // 三角化失败，不 seed
  landmarks_W[observation.id] = *point;
  continue;
}
// 立体正常路径（现有）
```
