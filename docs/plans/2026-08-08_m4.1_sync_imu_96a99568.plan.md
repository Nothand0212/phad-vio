# M4.1 sync pushImu 与 StereoImuPacket

设计稿：[M4 接入 IMU 设计](../research/m4-imu-integration-design.md) §3（D4/D5/D6、C1/C2/C12）。
总图 issue：[#30](https://github.com/Nothand0212/phad-vio/issues/30)；本片 issue：[#31](https://github.com/Nothand0212/phad-vio/issues/31)。
前置：M3.2 `StereoPairSynchronizer`（`4cf55ca` 基线、42 键 `default_773ea011`）。

## 切片划分

单 slice（数据路径,不涉及估计器）。改动集中在 `phad::sync` + `phad/sensor` 类型 + `apps/StereoPairStream`。

## 已对齐的决策（grill 定案,见设计稿 §1.2）

| # | 决策 | 定案 |
|---|---|---|
| D4 | Packet 携带内容 | 原始 IMU 样本（含两端插值）;预积分在 estimator 构造,不在 sync |
| D5 | 插值规则 | 段 `[t_prev, t_cur]` 左端样本归新段;右端 = 恰在 t_cur 的插值样本;ΣΔt ≡ 图像间隔;在 tryPop() 配对时完成 |
| D6 | 大间断 | > 0.5 s（进 config）→ imu_gap;estimator 跳因子不跳帧（M4.2 消费） |
| C1 | 实现位置 | sync 内完成,IMU 独立队列,未配对时只缓存 |
| C2 | 越界样本 | 计入 dropped_imu,不参与插值 |
| C12 | 显式出口 | est.tum / diag.csv 字节级不变 |

## 步骤

### 步骤 1:pushImu 与 IMU 队列（todo: imu-push-queue）

- `StereoPairSynchronizer` 增加 `pushImu(ImuMeasurement)`:
  - 返回 `PushStatus`(逆序 / 重复 / 非有限 → sticky;非法 stamp 语义与图像路径一致);
  - 有界队列(`max_queue` 复用现有选项,或 IMU 专属上界),溢出 drop-oldest;
- 诊断扩展: `pushed_imu` / `dropped_imu` / `dropped_imu_overflow` /
  `max_imu_queue` / `imu_gap_count`,并入 `StereoPairDiagnostics`;
- sticky 语义: `pushImu` 置位后与图像路径互不干扰(各自 sticky 独立)。

### 步骤 2:packet 类型（todo: packet-type）

- `phad/sensor` 新增 `StereoImuPacket`:
  ```cpp
  struct StereoImuPacket {
    sensor::StereoFrame            frame;    // 已配对双目（left stamp = t_cur）
    std::vector<ImuMeasurement>    samples;  // 原始 + 两端插值样本
    common::Timestamp              t_prev;   // 上一帧 left stamp（首帧为 t0）
    bool                           imu_gap;  // 段不完整（大间断）
  };
  ```

### 步骤 3:边界插值与 imu_gap（todo: boundary-interpolation / imu-gap-detection）

- 配对成功时,从 IMU 队列取 `(t_prev, t_cur]` 区间样本:
  - 左端 = 恰在 t_prev 的原样本,否则线性插值;
  - 中间 = 严格落在区间内的原样本;
  - 右端 = 恰在 t_cur 的线性插值样本;
  - ΣΔt 按段内相邻样本差累加 ≡ t_cur − t_prev(不变式,测试断言);
- 帧间间隔 > gap 阈值 → `imu_gap = true`(阈值进 config,CLI 可调);
- 早于首帧 / 晚于末帧样本计入 `dropped_imu`(C2)。

### 步骤 4:测试（todo: sync-tests）

纯内存单测矩阵(设计稿 §3.3 逐项):

| 用例 | 断言 |
|---|---|
| 恰在样本上 | 直接用原样本,无插值误差,ΣΔt 精确 |
| 两样本之间 | 线性插值,ΣΔt ≡ 图像间隔 |
| 缺样 | 段仍成立,ΣΔt 精确 |
| 重复 / 逆序 IMU | sticky 拒绝 |
| 大间断 | imu_gap = true |
| 越界样本 | dropped_imu 计数 |
| 溢出 | drop-oldest + dropped_imu_overflow 计数 |

M3.2 现有配对测试必须零回归(左右配对行为不变)。
