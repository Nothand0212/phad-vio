# M4.4 B gyro-first 视觉惯性融合实施计划

设计：
[`m4.4-gyro-visual-fusion-design.md`](../research/m4.4-gyro-visual-fusion-design.md)

本文档描述当前约定，不是绝对约束，会随项目开发修订。

## 1. Vertical slice

本片只交付：static gyro seed → window raw gyro PIM → pose-only AHRS factor + shared bg
→ stereo BA pose。accelerometer、gravity、velocity 不进入 production graph；不新增 legacy
开关或双实现兼容层。

## 2. 测试先行顺序

1. factor synthetic tests 固定 residual 方向、Pose3 translation 零 Jacobian、bias recovery；
2. estimator tests 固定 acc invariance、gap、zero-overlap 与 transaction；
3. 最小实现删除 `CombinedImuFactor` consumer 与 `V/B` graph variables；
4. 定向 tests、完整 unit、IMU-off byte sentinel；
5. MH_01 单序列 production run；
6. exact-common VIO/VO 双指标 gate；
7. 仅在通过后扩展 11/11。

## 3. 预计文件

## 6. 回退与停止条件

所有修改保持在未提交工作区；不 commit/push。factor/transaction test 失败先修合同，
不通过加 noise knob 掩盖。MH_01 未严格优于 VO 时不恢复 Combined 路径，也不直接进入
full inertial；下一刀必须由 gyro residual/bg/correction probe 选择。

## 7. B2：non-blocking static initialization

MH_05 phase split 已证实：gyro graph 仅在最后 260 帧激活，但 VIO 在此之前已因
0.5 s static init 拒掉 11 个视觉帧，accepted-keyframe epoch 与 VO 分叉。B2 不调
noise、alignment window 或 tracker，只修正生命周期：

1. static window 在旁路累计；视觉从第一帧按 VO 合同 seed/update；
2. pending 时以 diagnostics 暴露，不返回仅由 init 导致的 `kRejected`；
3. ready 只设置 gyro bias seed/audit，不用 gravity rotation 重锚视觉窗口；
4. timeout 仍 sticky `kFailed`，gap 仍重置检测窗；
5. activation 需同时满足 init ready 与 alignment support，且从下一 update 建 factor。

先写测试固定以下红门：alignment window 未到时，IMU-on 与 IMU-off 的 status、pose、
window/prior/keyframe feedback 序列一致；init snapshot 恰发布一次；known-bias factor 不
发生 absolute-bias 二次校正。实现后先复跑 MH_01/MH_05，任一序列不同时严格改善
ATE/RPE 即停止，不扩 11/11。

## 8. B3：visual initialization ownership

B2 MH_01 active support 的 raw gyro prediction 与 PnP 后 graph initial ATE 仅差
`-7.3e-6 m`，而二者都比配对 VO 差约 `0.0133 m`；posterior 相对 graph initial
主要改善 RPE。B3 因而只改正常 overlap frame 的 initial-value ownership：

1. 始终计算 gyro prediction并写 probe，但不覆盖视觉恒速 `guess_T_W_B`；
2. PnP 继续以 visual guess 求完整 pose/inliers，graph initial 取 PnP 成功值或 visual
   fallback；
3. AHRS factors/shared bg/covariance、100 s activation、static audit 全部不变；
4. re-anchor 无正常视觉 basin，仍允许 gyro rotation prediction；
5. synthetic 红测试用 gyro spike + stationary visual + disabled PnP，固定
   `predicted_T != graph_initial_T == visual guess`。

B3 先重跑 MH_01。若 ATE/RPE 未同时严格优于 VO，保留日志并重新选择 bias/factor
模型，不用调 factor scale 掩盖 initialization 问题。

## 9. B3 后归因与下一探针

B3 MH_01 为 VIO `0.0833210/0.0168992 m`，paired VO
`0.0809641/0.0177812 m`：ATE FAIL、RPE PASS。rolling bias probe 表明当前约
0.5 s graph window 的 bias estimate step 中位数 `4.322e-3 rad/s`，远大于约
`1e-6 rad/s` 的 reference step，故不引入 per-frame random-walk bias。

临时 covariance scale 的 9 点 MH_01 sweep 也没有双指标通过点；scale 接口与测试
随即删除，不进入产品合同。下一步只新增离线 staged alignment probe：gyro bias 已知、
stereo scale 固定，先解 velocities + gravity，并报告 condition、measurement residual、
gravity tilt 与一步 translation prediction。只有该探针出现不依赖 GT runtime 输入、且
有明确裕量的候选，才另写 full-inertial production 计划。
