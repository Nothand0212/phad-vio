# M3.3 Slice ⑤c 非关键帧进窗口 BA

**Goal:** 所有帧进窗口参与 BA（VINS/OKVIS/Basalt 设计），消除非关键帧位姿
质量差的根本来源。V1_01 目标接近基线 0.173。

**Architecture:** 删除非关键帧的 PnP-only 提前返回（⑤b 加入的
`update(keyframe=false)` 分支）与 pose-only 精修（`solvePnPRefineLM`）。非关键帧
走完整 BA 路径（push 窗口 → buildGraph → LM），但**不 seed 新 landmark**（仅关键
帧）、**不触发 reanchor**（overlap_broken → kRejected）。窗口驱逐 Basalt 式：
7 关键帧 + 3 temporal。

**Tech Stack:** 既有 GTSAM / OpenCV / Eigen。无新依赖。

Issue：[#27](https://github.com/Nothand0212/phad-vio/issues/27)，Part of
[#23](https://github.com/Nothand0212/phad-vio/issues/23)。

## 已对齐的决策

| 决策点 | 结论 |
|---|---|
| 非关键帧 | 进窗口参与 BA（同路径） |
| 非关键帧 seed | 不（仅关键帧） |
| 非关键帧 reanchor | 不（overlap_broken → kRejected） |
| pose-only 精修 | 删除（solvePnPRefineLM 块移除） |
| 窗口 | Basalt 7KF + 3 temporal（总 10） |
| 驱逐 | 优先 pop 最老非关键帧；关键帧上限 7 |
| window_size | 10（config 不变） |

## Task 1：WindowFrame 加 is_keyframe 字段

`stereo_vo_estimator.cpp`：

```cpp
struct WindowFrame
{
  std::uint64_t                  frame_index = 0;
  common::Timestamp              timestamp{ 0 };
  Eigen::Isometry3d              T_W_B = Eigen::Isometry3d::Identity();
  std::vector<StereoObservation> observations;
  bool                           is_keyframe = true;  // Slice ⑤c
};
```

`update()` 构造 candidate 时设置 `candidate.is_keyframe = keyframe`。

## Task 3：非关键帧走完整 BA 路径

删除非关键帧的提前返回（当前 `:1358-1388`），让流程继续到 backproject / push /
BA。加 gate：

```cpp
// 仅关键帧 seed 新 landmark
if ( keyframe )
{
  for ( observation : candidate.observations ) { backproject... }
}
```

注意：非关键帧的 `candidate.observations` 已被 PnP mask 过滤（`filtered`）。
非关键帧不 seed 意味着这些 masked-out 观测仍写入 track_times（保持现有语义）。

`overlap_broken && !keyframe` → kRejected（现有，保留）。

## Task 4：Basalt 窗口驱逐

替换 `:1430-1434` 的简单 pop_front：

```cpp
// 总上限 window_size=10
while ( window.size() > window_size )
{
  // 优先 pop 最老非关键帧（非最新）
  auto nkf_it = window.end();
  for ( auto it = window.begin(); it != window.end(); ++it )
  {
    if ( !it->is_keyframe && it->frame_index != window.back().frame_index )
    { nkf_it = it; break; }
  }
  if ( nkf_it != window.end() ) window.erase(nkf_it);
  else window.pop_front();
}
// 关键帧上限 7
while ( count_nonkeyframe(window) > 7 ) pop 最老关键帧;
```

等等——"关键帧上限 7"意味着：如果窗口里关键帧 > 7，pop 最老关键帧。但
Basalt 是 7 KF + 3 temporal = 10。如果关键帧数 > 7（例如旋转段每帧 KF），
则窗口会变成 8 KF + 2 temporal = 10？不——Basalt 强制 7 KF。修正：

```cpp
while ( keyframe_count > 7 ) pop 最老关键帧;  // 上限 7 KF
while ( window.size() > 10 ) pop 最老非关键帧; // temporal 上限 3
```

顺序：先保证 KF ≤ 7，再保证总数 ≤ 10（temporal ≤ 3）。
