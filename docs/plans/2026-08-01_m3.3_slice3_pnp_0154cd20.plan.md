# M3.3 Slice ③ PnP 初值 + RANSAC 剔时序外点

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 用窗口活点集 `landmarks_W` 上的 `solvePnPRansac` 提供更稳的位姿初值，并在优化前丢掉本帧 RANSAC 外点观测。

**Architecture:** 只改 `phad::estimator` 正常路径（PIMPL 内调 OpenCV）；公开头无 OpenCV。首段 / re-anchor 不跑 PnP。失败回退现有 `poseInitialValue()`，不引入新拒帧门。诊断经 session → bench 落盘。

**Tech Stack:** C++20、OpenCV `calib3d`（`solvePnPRansac`）、GTSAM（既有 BA）、GTest、`phad_vo_bench`。

Issue：[#23](https://github.com/Nothand0212/phad-vio/issues/23)。  
设计见 [M3.3 Slice ③ 设计](../research/m3.3-slice3-pnp-design.md)，  
开源对照见 [Slice ③ 开源对照](../research/m3.3-slice3-pnp-open-source-refs.md)，  
对照基线 [Slice ②](../research/m3.3-slice2-baseline.md)（`764d3b2` / `default_a962bc8b`）。

## Global Constraints

- C++ 命名 / 风格遵循 `docs/agents/cpp-naming.md` 与 `docs/agents/cpp-style.md`（Allman、2 空格、`m_` 成员）。
- 不新增库；不改 `phad::frontend` / `phad::eval`；公开头不暴露 OpenCV / GTSAM。
- 不做永久删 `landmarks_W`、frontend track 同步删除、chi2 外点、关键帧。
- 提交 subject 带 `(#23)`；短生命周期分支（建议从 `main` 开 `m3.3`）。
- MH_01：ATE ≤ **0.1073** m，`segments=1` / `reanchors=0`；**不**要求 `est.tum` 逐字节相同。
- A/B 按 commit：即使 `enable_pnp_init=false`，新字段进 `flattenConfig` 也会换 `config_hash`，不可与 `a962bc8b` 按目录并表。

## 已对齐的决策

| 决策点 | 结论 |
|---|---|
| 主交付 | `solvePnPRansac` 初值 + 优化前本帧 shared 外点掩码 |
| 求解器 | estimator PIMPL + `PRIVATE opencv_calib3d` |
| 对应点 | `landmarks_W ∩` 当前观测；上限 = `num_shared`（窗口活点集，非全局地图） |
| guess / fallback | `poseInitialValue()`；失败或不达 `min_pnp_inliers` → 不 cull、不拒帧 |
| 弱 inlier | RANSAC 收敛但 inliers ∈ [4, min) → 同 fallback，不掩码 |
| 掩码作用域 | 只改本帧 `WindowFrame.observations`；`landmarks_W` / frontend 不动 |
| `track_times` | **按 measurement 全量写**（含被掩码 id）；`num_observations` 保持测量原值 |
| 配置 | `enable_pnp_init` 默认 true；`pnp_reproj_px=2.0` / `confidence=0.99` / `min_pnp_inliers=10`；iterations **显式 100** |
| 诊断 | `diag.csv` 14→16；`summary` 加 `pnp_successes` / `pnp_fallbacks` |
| PnP↔guess 门 | 不加（YAGNI） |

### Task 2: PnP 初值 + 本帧掩码

**Files:**
- Modify: `phad/estimator/stereo_vo_estimator.cpp`（正常路径，约 `candidate.T_W_B = poseInitialValue()` 一带）

**Interfaces:**
- Consumes: Task 1 选项 / 诊断字段
- Produces: 正常路径 `pnp_success` / `pnp_inliers`；成功时 `candidate.observations` 已去 shared 外点

- [ ] **Step 1: 在 Impl 增加私有辅助（草图）**

```cpp
struct PnpInitResult
{
  bool              success = false;
  Eigen::Isometry3d T_W_B   = Eigen::Isometry3d::Identity();
  std::vector<int>  inlier_indices;  // indices into the shared correspondence list
};

[[nodiscard]] PnpInitResult tryPnpInit(
    const KeyframeMeasurement& measurement,
    const Eigen::Isometry3d&   guess_T_W_B ) const;
```

对应点：仅 `landmarks_W` 中存在的观测。  
坐标：

1. `T_B_left` ← `body_P_sensor` / `calibration.T_B_left_rectified()`  
2. `T_W_left_guess = guess_T_W_B * T_B_left`  
3. OpenCV 要的是 **world→left**（`P_left = R P_W + t`）：`T_left_W = T_W_left.inverse()` → `rvec/tvec`  
4. `cv::solvePnPRansac(pts3d, pts2d, K, noArray(), rvec, tvec,  
   /*useExtrinsicGuess=*/true, /*iterationsCount=*/100,  
   /*reprojectionError=*/pnp_reproj_px, /*confidence=*/pnp_confidence,  
   inliers, cv::SOLVEPNP_ITERATIVE)`  
5. 成功后 `T_W_left = T_left_W.inverse()`，`T_W_B = T_W_left * T_B_left.inverse()`  
6. 检查有限性；`inliers.size() >= min_pnp_inliers` 才 `success=true`

`K = [[fx,0,cx],[0,fy,cy],[0,0,1]]`；畸变空。

- [ ] **Step 2: 改正常路径（保持 track_times 全量）**

替换逻辑要点（伪代码对齐设计 §4）：

```text
guess = poseInitialValue()
pnp_success = false; pnp_inliers = 0
candidate.observations = measurement.observations

if enable_pnp_init && num_shared >= min_pnp_inliers:
  auto pnp = tryPnpInit(measurement, guess)
  if pnp.success:
    candidate.T_W_B = pnp.T_W_B
    按 inlier 集合过滤 candidate.observations 中的 shared 外点（新 id 保留）
    pnp_success = true; pnp_inliers = inliers.size()
  else:
    candidate.T_W_B = guess   // 不 cull
else:
  candidate.T_W_B = guess     // 含 !enable 或 shared 不足

// CRITICAL: track_times 仍遍历 measurement.observations（全量）
for (obs : measurement.observations) track_times[id].push_back(...)

// 新 id backproject：只对尚不在 landmarks_W 的 id，观测来自
// 掩码后的 candidate.observations（或等价：新 id 本就不在 PnP 集合，可仍扫 measurement 中新 id）
```

首段 / re-anchor：**不调用** `tryPnpInit`；诊断保持 `pnp_success=false`。

所有返回路径写入 `result.diagnostics.pnp_success` / `pnp_inliers`（拒帧路径保持默认 0/false 即可）。

  C -- 否 --> G[T = guess 不 cull]

  G --> J
