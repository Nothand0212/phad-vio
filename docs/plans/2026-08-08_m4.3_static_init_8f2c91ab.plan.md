## 本次讨论定案的增量决策

| # | 决策点 | 定案 |
|---|---|---|
| A | init 数据来源 | 零 sync 改动：init 期帧被拒，其 IMU 段在 estimator 内累积（复用 pending 拼接的共享边界去重），检测窗口从首个有段帧开始（MH_01 首帧零段无样本）；首帧前样本仍由 sync 按 C2 计入 dropped_imu |
| B | t0 与虚拟帧 | t0 = 检测通过时缓冲首样本时刻（≈ 首帧 t_1）；虚拟无观测帧 X(t0) 入窗口（frame_index 正常递增，T=R_W_I0，V=0，B=bias0，is_keyframe=false）；缓冲全量转 pending（pending_from = t0），首条预积分段 = [t0, t_cur]（检测所用 IMU 段进入第一条预积分，D10）；虚拟帧无观测，被驱逐/保留均安全（C3 重积分覆盖） |
| C | 检测与失败语义 | 滑动窗口检测（每次 update 对累积缓冲尾部 ≥ 窗口长度部分测方差）：通过 → 定 t0；方差超限 → 继续累积下帧重试；段 gap → 缓冲重置重试；总时长超 imu_init_timeout_s → 失败返回原因（C9，不静默用伪初始化冒充）；init 完全在 estimator 内部（session 无原始 IMU 通路），状态经 UpdateDiagnostics 暴露 |
| D | 播种锚 | init 完成后首帧仍在 !initialized 分支播种（min_seed_observations 门不变），seedSegment 锚 = Predict(R_W_I0, 0, bias0, [t0, t_k]) 而非 Identity |
| E | 重力测量优先 | g = \|mean(accel)\| 优先，imu_gravity 兜底（C10）；init 完成后 imu_params 按测量 g 重建（预积分构造用 shared_ptr，重建仅一次，旧因子不受影响） |
| F | diag 字节回归语义 | M4.3 增 6 个 bias 列后无法与 M3.3 参考逐字节相同——IMU-off 时新列恒 0，原列与 `c1d3481` 的 IMU-off 参考逐列相同，M4.3 重跑 IMU-off 立新参考（原列逐字节 + 新列恒 0）作为回退锚 |
| G | dropout 注入 | CLI 放 session 层裁剪观测（不进 config_hash）；机制证据已核实：IMU-on 观测全清 → overlap_broken 放行（`stereo_vo_estimator.cpp:1547` 图 = 仅 IMU 因子 + priors 有解）；IMU-off 零观测 → PnP 失败 → 拒帧冻结 |

## 步骤

### 步骤 1:init 机制（todo: init-mechanism）

- `EstimatorOptions` 增 4 键：`imu_init_window_s=0.5`、`imu_init_gyro_std=1e-2`、
  `imu_init_accel_std=2e-2`、`imu_init_timeout_s=5.0`（进 config_hash，§7）。
- `Impl` 增 init 状态机：
  ```cpp
  enum class InitPhase { kNone /*IMU-off*/, kCollecting, kReady, kFailed };
  InitPhase init_phase = InitPhase::kNone;
  std::vector<sensor::ImuMeasurement> init_imu;   // 累积缓冲（去重拼接）
  common::Timestamp                   init_t0{ 0 };
  gtsam::imuBias::ConstantBias        init_bias0;
  Eigen::Isometry3d                   init_R_W_I0;  // roll/pitch, yaw=0
  double                              init_g = 0.0;
  std::string                         init_failure;
  ```
- `update()` 入口（enable_imu 且 init 未完成）：
  - 段 gap → 清缓冲重新累积（不连续样本无检测价值）；
  - 否则按 pending 拼接去重规则把本帧段追加进 `init_imu`；
  - 缓冲尾部样本跨度 ≥ `imu_init_window_s` → 检测：
    - gyro/accel 方差（或 std）< 阈值 → 通过：t0 = 缓冲首样本时刻；
      `gyro_bias = mean(gyro)`；`gravity_dir = normalize(mean(accel))`；
      `R_W_I0`：世界 Z 与 -gravity 对齐（roll/pitch），yaw=0（C5）；
      `init_g = |mean(accel)|`（C10，若非有限则回退 `imu_gravity`）；
      `acc_bias = mean(accel) − init_g·gravity_dir`（残差）；
      虚拟帧播种进窗口；`pending_imu = init_imu`、`pending_from = t0`、
      `pending_gap = false`；`imu_params` 按 `init_g` 重建；
      `init_phase = kReady`；
    - 方差超限 → 缓冲丢弃前部（滑窗）继续累积，下帧重测；
  - 超时（`buffer 末样本 − 缓冲起点 > timeout` 且从未通过）→
    `init_phase = kFailed`、`init_failure = "stationary detection failed:
    variance exceeded (gyro std=... > ...)"`；
  - 帧返回 `kRejected` + `diagnostics.init_pending = true`（失败帧
    `init_failed = true` + `init_failure_reason`）；**不**进入后续图流程。
- `kReady` 后首帧（!initialized）：`seedSegment` 锚 =
  `imuPredict(pending_imu, gap)`（从虚拟帧 R_W_I0/V=0/bias0 Predict [t0, t_k]），
  失败回退 Identity；min_seed_observations 门照旧（不足 → 拒，段挂 pending，
  下帧重试）。播种成功 → `initialized = true`，候选帧段 = pending（含
  [t0, t_k] 全段），后续照常。
- `UpdateDiagnostics` 增：`bool init_pending`、`bool init_failed`、
  `std::string init_failure_reason`（IMU-off 恒 false/空，不进 diag.csv）。
- 虚拟帧：`WindowFrame{ frame_index = next_frame_index++, timestamp = t0,
  T_W_B = R_W_I0, velocity_W = 0, bias = bias0, observations = {},
  is_keyframe = false, imu_samples = {}, t_prev = t0 }`；最老帧 priors 锚定
  （C11 放松 sigma 沿用）；buildGraph 对 虚拟帧→首帧 对正常建
  CombinedImuFactor（段 = 首帧 imu_samples = [t0, t_k]）。

### 步骤 2:诊断扩展（todo: diag-bias）

- `UpdateDiagnostics` 增 `Eigen::Vector3d bias_gyro`、`bias_acc`：接受帧 =
  优化后回写值（`stereo_vo_estimator.cpp:2104` 同源），被拒帧 = 上一接受值，
  IMU-off 恒 0。
- `VoDiagRow`（session）增 6 列：`bias_gyro_x/y/z`、`bias_acc_x/y/z`
  （IMU-off 恒 0.0，保证 F 定案）。`writeDiagCsv` 同步扩展。
- `FrameCounts` 增 `init_dropped_frames`：session 侧按 `init_pending` 计数，
  进 summary.json（C8），不进 config_hash；`init_failed` → `SessionError` →
  bench `kFailed`（C9）。
- bench `flattenConfig` 增 4 键（步骤 1 的 options 键）。

### 步骤 3:dropout 注入（todo: dropout-cli）

- session CLI：`--dropout-start-frame <n>`、`--dropout-frames <n>`、
  `--dropout-keep-ratio <0..1>`（默认 off；三参数齐备才激活；不进
  config_hash，参照 `enable_probe_b` 模式）。
- 机制：帧号 ∈ [start, start+frames) 时，session 对 `measurement.observations`
  做无放回子采样（keep-ratio 0 = 全清；0.3 = 保留 ~30%）后再传 estimator；
  前端照跑不注入（观测裁剪只影响估计器）。
- 合成测试（`tests/estimator` 或 session 级）：
  - IMU-on：注入期每帧 accepted（图 = 仅 IMU 因子），位姿由预积分外推
    连续（相对真值偏差 ≤ 阈值），恢复后 50 帧内 ATE 回基线（无永久损伤）；
  - IMU-off 对照：注入期拒帧（PnP 失败冻结语义），恢复时重锚 → 对齐税
    复现（与 M3.3 同源行为，仅断言"冻结 = 无新轨迹点"）。

## 测试矩阵

合成对拍（`tests/estimator/stereo_vo_imu_test.cpp` 追加，不动现有）：

| 用例 | 断言 |
|---|---|
| 静止 0.5 s 检测通过 | init_pending 期间拒帧；通过后首帧播种；R_W_I0 的 Z 轴与 -gravity 对齐（角误差 < 1e-2 rad）；gyro_bias ≈ 注入 bias（< 1e-3 rad/s） |
| 首段积分 | 首条预积分 ΣΔt = t_cur − t0（误差 < 采样周期）；静止首帧位姿 ≈ R_W_I0（位移 < 1 cm） |
| 检测后运动 | 静止 init 后匀速段：轨迹逐帧 ≈ 真值（预积分外推正确起步） |
| 运动中拒绝 | 全运动段：init 超时失败，init_failure_reason 非空（C9），不冒充成功 |
| gap 重置 | 累积中插 gap 段 → 缓冲重置，gap 后静止 0.5s → 检测通过，t0 在 gap 后 |
| 已知 bias 收敛 | 伪初始化 0 → 30s 后 bias 趋近注入值（gyro < 1e-3 量级） |
| IMU-off | init 不激活（init_pending 恒 false），原链行为不变（现有测试回归） |

注入测试（步骤 3）：IMU-on 连续性 + 恢复、IMU-off 冻结对照。

## 风险与对策

| 风险 | 对策 |
|---|---|
| 门① MH_01 ATE 不达 0.100（bias prior 或阈值不当） | 先跑数归因（yaw 对齐后 residual 构成）；按 C15 扫 bias prior；阈值扫参（§5.1） |
| 虚拟帧与驱逐/KF 逻辑交互 | 虚拟帧无观测无 KF 标志；最老帧驱逐时 C3 重积分覆盖；实施时核对驱逐谓词 |
| accel bias 可观测性（开放问题 3） | init 只给残差粗糙值；收敛由 BetweenFactor rw 与 V prior 承载；跑数观察，不达标再扫参 |
| 注入期 landmark 表清空后恢复慢 | M4.2 已证 overlap 断裂恢复（合成测试）；注入测试断言 50 帧内回基线 |
| IMU-off 字节回归破坏 | enable_imu=false 完全走原路径（init 状态机 kNone 不激活；bias 列恒 0） |
| 检测窗口恰好在运动边界（方差抖动） | 滑动重试 + 超时（宽容）；MH_01 静止期 ~2.5s 冗余 0.5s 窗口 |
