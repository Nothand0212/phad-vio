# M3.3 Slice ⑥ 前端加固

**Goal:** 修复 V 系列前端跟踪崩溃（V2_03 观测中位仅 4 个）。三份调研确认：
前端跟踪是主因（非后端），缺 LK 初始猜预测 + CLAHE 两个关键 trick。

**Architecture:** 改动集中在 `phad/frontend/stereo_tracker.{hpp,cpp}`：
1. LK 初始猜预测（常速中值流 + `OPTFLOW_USE_INITIAL_FLOW`）
2. CLAHE 预处理（左右目，一次修复 GFTT/LK/SAD 三处）
3. F 矩阵 RANSAC 几何校验（LK+FB 后）
4. 参数微调（quality 0.003、金字塔 4 层）

**Tech Stack:** OpenCV（calcOpticalFlowPyrLK / createCLAHE / findFundamentalMat）。
无新依赖。

Issue：[#27](https://github.com/Nothand0212/phad-vio/issues/27)，Part of
[#23](https://github.com/Nothand0212/phad-vio/issues/23)。

## 已对齐的决策

| 决策点 | 结论 |
|---|---|
| LK 初始猜 | 常速中值流 + OPTFLOW_USE_INITIAL_FLOW |
| 预处理 | CLAHE（clip 3.0, tile 8x8，左右目）|
| 几何校验 | F 矩阵 RANSAC（3px, 0.99）|
| quality_level | 0.01 → 0.003 |
| 金字塔 | 3 → 4 层 |
| 特征数量 | 保持 200（非主因）|
| 修改范围 | stereo_tracker.{hpp,cpp} + 选项默认值 |
| 框架外 | ORB 描述子（不做）|

## Task 1：LK 初始猜预测

`stereo_tracker.cpp`：

1. Impl 新增 `std::optional<cv::Point2f> median_flow;`
2. `process()` 的 LK 调用前，若 `median_flow` 有值，`curr_pts` 预填
   `prev_pts[i] + *median_flow`
3. LK 调用加 `cv::OPTFLOW_USE_INITIAL_FLOW` 标志 + 显式 TermCriteria
4. FB 检查通过后，收集幸存 track 位移取中值更新 `median_flow`
5. 无幸存（全灭）时清空 `median_flow`

## Task 2：CLAHE 预处理

`process()` 入口：

```cpp
const cv::Mat left_raw  = toGrayMat( rectified.left );
const cv::Mat right_raw = toGrayMat( rectified.right );
cv::Ptr<cv::CLAHE> clahe = cv::createCLAHE( 3.0, cv::Size( 8, 8 ) );
cv::Mat left, right;
clahe->apply( left_raw, left );
clahe->apply( right_raw, right );
```

`prev_left` 存 CLAHE 后的 `left`（前后帧预处理一致）。

## Task 3：F 矩阵 RANSAC

LK + FB 检查后、`detectNewTracks` 前：

```cpp
if ( survivors.size() >= 8 ) {
  std::vector<cv::Point2f> prev_f, curr_f;
  for ( survivors ) { prev_f.push_back( ... ); curr_f.push_back( ... ); }
  std::vector<uchar> geo;
  cv::findFundamentalMat( prev_f, curr_f, cv::FM_RANSAC, 3.0, 0.99, geo );
  // 保留 geo==1 的 track
}
```
