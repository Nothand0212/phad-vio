# M4.4 window-history 反事实探针实施计划

设计：
[`m4.4-window-history-counterfactual-probe.md`](../research/m4.4-window-history-counterfactual-probe.md)

本文档描述当前约定，不是绝对约束，会随项目开发修订。

## 1. Vertical slice

本片只增加一个离线 Python probe：读取现有 trajectory/state/raw IMU/GT，输出 phase
分解与六条 rolling displacement counterfactual。它不修改 C++ estimator、apps、
config、dataset 或 run artifacts。

## 2. 小步顺序

1. 提取可复用 raw IMU endpoint segment API；
2. 为 rigid alignment、body displacement 与 counterfactual 公式写 red tests；
3. 实现严格 loader、GT interpolation、phase metrics、horizon/bucket 汇总；
4. 加 CLI/JSON 与 malformed input tests；
5. 跑 MH_01 固定输入，记录 artifact hash 与选刀；
6. 只设计被证据支持的下一把 shadow，不在本片改 graph。

## 3. 预计文件

- `scripts/imu_translation_alignment_probe.py`（公开既有 segment helper）；
- `scripts/vio_window_history_probe.py`；
- `scripts/vio_window_history_probe_test.py`；
- `scripts/README.md`；
- 本设计/计划结果章节。

## 4. 验证

```bash
.venv/bin/python scripts/vio_window_history_probe_test.py
.venv/bin/python scripts/imu_translation_alignment_probe_test.py
.venv/bin/python scripts/vio_state_probe_test.py
.venv/bin/python -m py_compile scripts/vio_window_history_probe.py
git diff --check
```

MH_01 output 写到 benchmark run 外的独立 probe JSON；不覆盖既有 artifact。M4.4 的
最终门仍是 exact-common translation ATE 与 1 s RPE 均严格 `VIO < VO`。
