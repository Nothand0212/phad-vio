# M4.2 estimator 机制（X/V/B + CombinedImuFactor + 伪初始化）

设计稿：[M4 接入 IMU 设计](../research/m4-imu-integration-design.md) §4（D3/D8/D9/D12、C3/C4/C5/C11/C15）。
issue：[#32](https://github.com/Nothand0212/phad-vio/issues/32)。
前置：M4.1（`7026ebf`，packet 数据路径 + `StereoPairStream::nextPacket`）。
分支：m4（用户指示：后续所有工作直接提交 m4，不再短生命周期分支）。

## 切片划分

单 slice（estimator 机制）。改动集中在 `phad/estimator` + `apps/offline_vo_session` + `apps/phad_vo_bench` + `tests/estimator`。

## 已对齐的决策（grill 定案,见设计稿 §1.2/§4）

| # | 决策 | 定案 |
|---|---|---|
| D3 | enable_imu 开关 | 默认 true，进 config_hash；IMU-off 恒走原 M3.3 链 |
| D8 | 初值 | 位姿 = preint.Predict(X,V,B)；PnP/恒速保留为 imu_gap / IMU-off 兜底 |
| D9 | 回滚语义 | IMU-on：回滚不覆盖位姿与 IMU 段，只回滚 landmark/观测/窗口结构；失败帧段挂 pending |
| D12 | re-anchor 退役 | IMU-on 时不可达；窗口重建只清 landmark 表，位姿连续外推；segments/reanchors 恒 1/0 |
| C3 | 预积分位置 | estimator 在 buildGraph 时对窗口每对相邻帧即时重积分（原始样本存 WindowFrame） |
| C4/C5 | 伪初始化 | bias=0、v0=0、g=9.81007（进 config） |
| C11 | 首帧 priors | X prior sigma 放松至 1e-2；V prior 1.0 m/s；B prior gyro 1e-3 / acc 1e-2（量级） |
| C15 | V/B prior | 中等 sigma，不扫参 |

## 步骤

### 步骤 1:类型扩展（todo: imu-types）

- `KeyframeMeasurement` 增：
  ```cpp
  std::vector<sensor::ImuMeasurement> imu_samples;  // 帧间段 [t_prev, timestamp]
  common::Timestamp                   t_prev{ 0 };
  bool                                imu_gap = false;  // IMU-off 恒 true
  ```
- `EstimatorOptions` 增：`enable_imu=true`、`imu_gravity=9.81007`、
  `imu_acc_noise_nd=2.0e-3`、`imu_gyr_noise_nd=1.6968e-4`、`imu_gyr_rw=1.9393e-5`、
  `imu_prior_pose_sigma=1e-2`、`imu_prior_vel_sigma=1.0`、
  `imu_prior_bias_gyro_sigma=1e-3`、`imu_prior_bias_acc_sigma=1e-2`。

### 步骤 2:窗口状态与预积分参数（todo: imu-window）

- `WindowFrame` 增：`Eigen::Vector3d velocity_W{0,0,0}`、
  `gtsam::imuBias::ConstantBias bias{0,0,0,0,0,0}`、`imu_samples`、`t_prev`、
  `imu_gap`（enable_imu=false 时恒缺省，不进因子图）。
- `Impl`：`std::shared_ptr<gtsam::PreintegratedCombinedMeasurements::Params> imu_params`
  在构造时按 §2.3 一次换算（`MakeSharedU(g)` + `acc_nd²` + `gyr_nd²` + `gyr_rw²`），
  仅 enable_imu 时创建。
- pending 拼接：`std::vector<sensor::ImuMeasurement> pending_imu; bool pending_gap;`
  - 每帧：`samples = pending_imu + measurement.imu_samples`（共享边界去重：两段
    首尾同 stamp 时只留一个），`gap = pending_gap || measurement.imu_gap`；
  - 接受帧 → 段入 WindowFrame，pending 清空；被拒帧 → `pending_imu += 本帧段`、
    `pending_gap |= 本帧 gap`（§4.4 "失败帧的 IMU 段照收"）。

### 步骤 3:因子图（todo: imu-graph）

- `buildGraph`（enable_imu=true 时）：
  - 最老帧：X prior（`imu_prior_pose_sigma`）、`PriorFactor<Velocity>(0,
    imu_prior_vel_sigma)`、`PriorFactor<ConstantBias>(0, gyro/acc sigmas)`；
  - 相邻非 gap 对：从 j 帧 `imu_samples` 即时构造
    `PreintegratedCombinedMeasurements(params, biasHat)`（biasHat = i 帧 bias 当前值）
    → 按序 `integrateMeasurement(acc, gyro, dt)` → `CombinedImuFactor(X_i, V_i,
    X_j, V_j, B_i, B_j, preint)`；`BetweenFactor<ConstantBias>(B_i, B_j, Δbias=0,
    rw_sigma = imu_gyr_rw·√dt, imu_acc_rw·√dt)`；
  - gap 帧：不建 V/B 变量、跳过其 IMU 因子；gap 后第一帧（无入链）加 V/B
    weak prior（同一组 priors）防 indeterminant；
  - enable_imu=false：完全不建 V/B 与 IMU 因子（字节回归）。
- values 初值：V = 上一帧 V（Predict 输出优先），B = 上一帧 B（首帧 0）。

### 步骤 4:初值链与伪初始化（todo: imu-init）

- `poseInitialValue()` 扩展：IMU-on 且当前帧段非 gap（且窗口非空）→ 用
  `PreintegratedCombinedMeasurements(params, last_bias)` 对当前段样本积分 →
  `preint.Predict(last_T, last_V, last_bias)` → `(pose_pred, vel_pred)`；
  否则原恒速/PnP 链。
- 伪初始化：首帧种子段 `seedSegment` 时 V=0、B=0（prior 已含）；g 进 config。
- 非 KF 帧：段照收照积（§4.6 不拒帧）。

### 步骤 5:re-anchor 退役与回滚（todo: imu-reanchor）

- IMU-on：`overlap_broken` 路径改为：清 `landmarks_W`（重建表），
  candidate 照常（Predict 初值）进窗口，播种照常（新 id backproject），
  `segment_id` 不增、`enable_reanchor` 门与非 KF 门放行（观测不足不拒帧）；
  `pending_seed_obs` 累积逻辑跳过。
- `restore()`：IMU-on 时**不**回滚 `last_accepted_T_W_B` / `prev_accepted_T_W_B` /
  pending 段（D9），只回滚窗口/landmarks/计数。
- 初始化（首段）门不变：首帧仍要求 min_seed_observations（地图不能为空）。

### 步骤 6:session 与 bench（todo: imu-session）

- `offline_vo_session.cpp`：`stream.next()` → `stream.nextPacket()`；frame 走
  原流程，packet 的 `samples/t_prev/imu_gap` 填进 `KeyframeMeasurement`；
  `--no-imu` 时填空段 + gap=true（或 estimator 内部 enable_imu=false 直接忽略）。
- `phad_vo_bench.cpp`：`--no-imu` CLI；`flattenConfig` 增 10 个新键
  （enable_imu、imu_gravity、4×噪声密度、4×prior sigma）。

### 步骤 7:测试（todo: imu-tests）

合成对拍（新文件 `tests/estimator/stereo_vo_imu_test.cpp`，不动现有）：

| 用例 | 断言 |
|---|---|
| 静止 0.5 s | 位移 ≈ 0、旋转 ≈ 0（合成 IMU = g + 0 角速度）；pnp_success 恒 false（D8） |
| 匀速 0.3 m/s | 逐帧位姿 ≈ 真值；累计位移相对误差 < 1%（ΣΔt 尺度） |
| 恒定角速度 ω=0.2 rad/s | 姿态角误差 < 0.02 rad（rad-vs-deg 隐含：按 rad 合成才闭合） |
| 已知 bias | 静止 + bias → 位姿不漂移（< 3 cm，无估计则漂移 ≈ 6 cm 可检出） |
| 噪声 IMU | 高斯噪声（密度量级×10）下轨迹 < 5 cm（协方差=密度² 权重失当会漂移） |
| 两样本最小段 | 左端 + 右端整段一步积分，位移仍精确（ΣΔt 语义） |
| imu_gap | 跳因子不崩，gap 帧 PnP 兜底（pnp_success=true），链断恢复 < 10 cm |
| pending 拼接 | 被拒帧（空观测）段保留，成功帧拼接后 ΣΔt = 2 图像间隔，位姿 ≈ 真值 |
| overlap 断裂 (D12) | 全新 id 帧仍 ok，segment_id 恒 0，新路标进窗口，后续帧继续 |
| IMU-off 等价性 | enable_imu=false 走原链：PnP 初值复现，轨迹仍贴合真值 |

IMU-off：现有 67 测试（含 10 个 M3.3 语义用例显式 enable_imu=false）零回归。

## 风险与对策

| 风险 | 对策 |
|---|---|
| gap 帧 B 变量悬空 → LM indeterminant | gap 后第一帧 V/B weak prior（同一组 priors） |
| 被拒帧段链断裂 | pending 拼接 + 共享边界去重（ΣΔt 不变式仍成立） |
| IMU-on 时 yaw 未对齐（伪初始化） | M4.2 出口不门控（记录）；M4.3 静止初始化对齐 roll/pitch |
| IMU-off 字节回归破坏 | enable_imu=false 完全走原路径（V/B 不进 graph） |
| preint 重积分开销 | 窗口 ≤10 帧 × 每段 ≤10 样本 × 每帧 ≤3 次 buildGraph，可忽略 |
