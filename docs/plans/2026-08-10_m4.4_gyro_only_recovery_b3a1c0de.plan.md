# M4.4 gyro-only recovery 实施计划

设计：
[`m4.4-gyro-only-recovery-design.md`](../research/m4.4-gyro-only-recovery-design.md)

本文档描述当前约定，不是绝对约束，会随项目开发修订。

## 1. Vertical slice

本片只恢复最近的健康运行层：删除 B5 full stage，使 IMU-on runtime 从 pure visual
warm-up 进入 gyro-only AHRS graph 后不再自动切 mode。它保留 static truth audit、gyro
bias alignment、AHRS factor、state/objective probe 与所有既有 VO 行为。

不新增 config/CLI knob，不实现 fixed-lag、new factor、robust threshold、noise sweep 或
full candidate。历史 B5/B6 artifacts 与离线 scripts 不删除。

## 2. TDD 小步顺序

1. 在 `StereoVoImu` public seam 增加长时 accelerometer-invariance test，观察旧代码因
   full activation 红；
2. 删除 full activation/history 与 transaction backup/restore；先让 mode 生命周期绿；
3. 删除 full graph/prediction/state/options/CMake module，由编译错误驱动清理调用点；
4. 更新 state writer 的 full-mode 红测试为 non-gyro objective misuse/schema test；
5. 更新 config snapshot/CLI tests，确认 full-only keys 消失且 state path仍不进 hash；
6. 定向测试 → 完整 unit/Python → `git diff --check`；
7. MH_01 主三文件先与 B3 byte gate，再分析完整 objective。

## 4. 定向验证

```bash
cmake -S . -B build -DCMAKE_EXPORT_COMPILE_COMMANDS=ON
cmake --build build --target phad_estimator_tests phad_apps_tests phad_vo_bench -j2
build/phad_estimator_tests --gtest_filter='StereoVoImu.*'
build/phad_apps_tests --gtest_filter='VioStateProbeTest.*:VoBenchCliTest.*'
.venv/bin/python scripts/gyro_graph_objective_probe_test.py
.venv/bin/python scripts/vio_state_probe_test.py
.venv/bin/python scripts/vio_vo_common_support_test.py
ctest --test-dir build --output-on-failure -L unit -j2
git diff --check
```

额外静态门：production C++/CMake/tests 中不得残留 `full_inertial_active`、
`kFullVisualInertial`、`ImuAlignmentFrame` 或 `gtsam::ImuFactor`。

## 5. MH_01 与停止条件

1. run 使用完整 `meta.json.config_canonical_text`；state path 不进 config hash；
2. `est.tum/kf.tum/diag.csv` 与 `m44_gyro_visual_init_b3` 任一不一致：停止 objective
   解释，先定位行为差异；
3. byte gate 通过后要求 1680 gyro rows、每行 objective valid；
4. full objective 不支持 boundary anomaly：不实现 robust candidate，转下一设计；
5. 即使 B3 byte gate 通过，也不运行 MH_05，因为已知 MH_01 ATE 门失败；下一 production
   candidate 仍须从 MH_01 重新开始。
