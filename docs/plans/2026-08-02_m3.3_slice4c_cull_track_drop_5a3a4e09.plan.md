# M3.3 Slice ④c Cull 后丢 Track + 拒复生

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 切断「永久删地图点 → 同 `LandmarkId` XYZ 重生」路径：estimator 拒复生 + session 回传 `dropTracks`，使 MH_01 在默认 cull 下恢复健康锚。

**Architecture:** `culled_ids_` 跨帧拒 backproject；本帧 `culled_landmark_ids`（mean-cull ∪ cheirality）经 `OfflineVoSession` 交给 `StereoTracker::dropTracks`。无 `estimator→frontend` 依赖。`diag.csv` 仍 18 列。

**Tech Stack:** C++20（`std::span`）、GTSAM（既有）、GTest、`phad_vo_bench`。

Issue：[#24](https://github.com/Nothand0212/phad-vio/issues/24)（续；称 Slice ④c；Part of [#23](https://github.com/Nothand0212/phad-vio/issues/23)）。  
设计见 [M3.3 Slice ④c 设计](../research/m3.3-slice4c-cull-track-drop-design.md)，  
复生对照 [cull-id-rebirth](../research/m3.3-cull-id-rebirth-open-source-refs.md)，  
⑤前锚 / A/B [slice5-baseline §0–2](../research/m3.3-slice5-baseline.md)。

## Global Constraints

- C++ 命名 / 风格：`docs/agents/cpp-naming.md`、`docs/agents/cpp-style.md`（Allman、2 空格、`m_`）。
- 不新增库；**禁止** `phad::estimator` → `phad::frontend`；不改 `phad::eval`。
- **不**拆 `TrackId≠LandmarkId`（§8 后续）；**不**改 mean-cull 阈值/最少观测；**不**扩 `diag.csv`（仍 **18** 列）。
- `outliers_culled` / `unique` **只**计 mean-reproj cull；cheirality 进列表与 `culled_ids_`，不计 outliers 计数。
- 列表仅**提交成功路径**填充；`restore()` 后 `culled_landmark_ids` 必须为空。
- 提交 subject 带 `(#24)`；短生命周期分支（续 `m3.3`）。
- MH_01：ATE ≤ **0.099263** m，`segments=1` / `reanchors=0`；无长 failed 簇。
- MH_05：只诊断；对照 ④b `3855395` / `default_65273570`；**不**硬门 ATE &lt;1 m。
- **出口顺序**：编码 → **MH_01（Task 4）→ MH_05（Task 5）→ 条件全序列（Task 6）**。
- 工作树可能已有诊断用 `block_culled_rebirth=false` / `--block-culled-rebirth`：本计划**改为默认 true**，CLI 改为 `--allow-culled-rebirth`。

- [ ] **Step 3: 最小实现**

`types.hpp`：

```cpp
bool block_culled_rebirth = true;  // false → 允许同 id 重生（单测 A/B）

// UpdateDiagnostics:
std::vector<common::LandmarkId> culled_landmark_ids;
```

`stereo_vo_estimator.cpp`（要点）：

1. `update()` 开头将 `result.diagnostics.culled_landmark_ids.clear()`。
2. `dropCheiralityLandmarks`：每个真正 erase 的 id → `culled_ids_.insert` + 若走提交路径则 push 到**局部 vector**（或在写 diagnostics 前收集）；**不要**增加 `outliers_culled`。
3. mean-cull 循环：既有 `outliers_culled++` / unique；同时 push 本帧列表 + 已有 `culled_ids_`。
4. 正常路径 / `seedSegment` backproject：若 `block_culled_rebirth && culled_ids_.count(id)` → `continue`（seed 跳过该观测；勿因跳过导致空 seed 误成功——若过滤后无有效点仍按现有失败语义）。
5. 所有 `restore()` 调用后：`result.diagnostics.culled_landmark_ids.clear()`（且不要在 restore 前把列表写入 result；推荐：局部 `std::vector<LandmarkId> frame_culled`，仅在最终 `kOk`/成功提交赋值给 `result.diagnostics`）。
6. 失败路径：不赋值或赋空。
