## Phase 1：MH_03 回归根因诊断

**背景**：PnP 仲裁使 MH_03 ATE 从 1.121→1.336 m（+19.2%），但无 failed、无
reanchor——纯 PnP 决策退化。已知在 i≈1388 仲裁改变了 PnP 采用（旧路径接受 58-inlier
proposal [132.709 px RMS]，新路径回退到 guess [4.082 px]）。两条路径的 drift
morphology 随后分化。

**诊断步骤**（细节留给独立子计划）：

1. 对 `zombie-age` vs `PnP` 的 `est.tum` 做逐帧 diff，确认首次偏离帧 index 与后续
   分叉点
2. 对仲裁改变决策的帧，审计 proposal vs guess stereo RMS——判断是误拒还是正确拒绝
3. 反事实验证：临时对受影响的帧放宽仲裁，确认 ATE 方向
4. 根因归类（误拒 / guess 退化 / 下游 cull 集合差异），产出
   `docs/research/m3.3-mh03-regression-diagnosis.md`

**修复约束**：不调 `stereo_sigma_px` 全局值；可考虑收紧统计带（仅在 MH_03 决定）
或增加 proposal 二次验证。

**产出**：诊断文档 + GitHub issue（修复片）+ 全表前后对比。

**门控**：MH_01 不回归；不扩全序列直到 MH_03 恢复。

## Phase 3：Slice ⑤ 关键帧策略

**前置条件**：Phase 1 修复完成 + Phase 2 至少诊断完成。

**核心决策点**（对齐时逐项决定）：

- 关键帧/非关键帧的 landmark 处理差异

**产出**：`docs/research/m3.3-keyframe-design.md`（含开源对照）+ GitHub issue +
子计划 + 全表评估。

**不做**：不改 IMU 代码；不改 estimator 核心优化逻辑。

## Phase 4：M4 接入 IMU

**前置条件**：Phase 3 设计落地（或至少设计已定）+ M3.3 债务已清。

**现有基础**（直接复用）：
- `ImuMeasurement`/`ImuParameters`/`StereoImuCalibration` 类型（M1）
- `StereoImuDatasetReader::takeImu()` / `DatasetReplaySource` 三路时间归并（M1/M3.2）
- GTSAM 4.3 已链接；`phad::eval` ATE/RPE 可直接复用
- `StereoPairSynchronizer` 有显式 `pushImu` 扩展槽（M3.2）

**当前缺口**：`StereoPairStream` 丢弃 IMU 事件；无 `StereoImuPacket`；estimator
不认 `NavState`/`ConstantBias`/`PreintegratedCombinedMeasurements`；无 IMU 初始化。

**预拆分**（待 Phase 3 后对齐细化）：
- M4.1：`StereoImuPacket` + synchronizer `pushImu()` + 图像边界 IMU 线性插值
- M4.2：GTSAM preintegration 参数 + `PreintegratedCombinedMeasurements` +
  `ImuFactor` + 状态 X→X/V/B
- M4.3：起始静止初始化（gyro bias → 重力方向 → roll/pitch → 零初速 → priors）
- M4.4：集成与全序列评估

**出口**（由 roadmap 给定）：MH_01 ATE 优于 M3.3 纯 VO（即 < 0.098784 m）；
视觉退化时轨迹连续；bias 从扰动收敛；时间错位可检测。
