### 2.3 Exact time/observation/block structure

`t0` 由 Slice 2 最终 exact eligibility predicates 选出：

```text
t_mid      = t0 + 50000000000 ns
t_split    = t0 + 100000000000 ns
full fit   = t_prev >= t0    && t_cur <= t_split
early half = t_prev >= t0    && t_cur <= t_mid
late half  = t_prev >= t_mid && t_cur <= t_split
validation = t_prev >= t_split
```

mid-straddling interval 不进 halves、可留 full fit；split-straddling 不进 fit/validation。两 half
从相同权威初值独立 refit，使用相同 objective/weights/solver/Jacobian/termination；validation 只
用 full-fit bias。权威初值和这些 solver details 仍属 Slice 2。

对 (k\ge0)：

\[
B_k=[t_{split}+k10^9,\ t_{split}+(k+1)10^9]\ \mathrm{ns}.
\]

首 interval 必须 exact 起于 block 左端，末 interval exact 止于右端，相邻 exact 首尾，且全部
eligible/同 segment。每个 `(bias arm, packet)` 只调用一次 Q2 helper，再 chronological
right-compose；不重采样、不重做 sync、不重复 shared endpoint interval、不 merge/partial。visual
rotation 是 `R_WB(a)^T R_WB(b)`，不是 adjacent rotations 的另一实现。按 (k) 排序，缺块不
压紧。

\[
r_{0,k}=Log(\Delta R^{imu}_{B_k}(0)^T\Delta R^{vis}_{B_k}),\quad
r_{b,k}=Log(\Delta R^{imu}_{B_k}(\hat b)^T\Delta R^{vis}_{B_k}),
\]

\[
d_k=\lVert r_{0,k}\rVert^2-\lVert r_{b,k}\rVert^2\ [rad^2].
\]

near-\(\pi\) 与缺块后的 HAC calendar-lag/run 规则仍属 Slice 2。

对 validation 中每个满足最终 eligibility predicates 的 held-out packet interval (p)，使用该
packet 完全相同的 visual endpoints，并对 zero/full-fit bias 两臂分别恰调用一次 Q2 helper，记录
\(r_{0,p}\)、\(r_{b,p}\) 与
\(d^{adj}_p=\lVert r_{0,p}\rVert^2-\lVert r_{b,p}\rVert^2\ [rad^2]\)。禁止重采样、merge、
partial integrate、跨 gap 拼接或改换 visual endpoints。adjacent observations 与 1 s blocks
共用 packets，不得混作独立 samples 或重复扩大 support；它们是 mandatory supporting
scientific gate，但不改变 sole primary 仍为完整 1 s block。其完整 inference 属 Slice 2 blocker。

## 3. Slice 2：完整 protocol amendment blocker

### 3.1 Input/schema/eligibility/errors

- packet `status` exact value；diag ok exact column/value；segment/exact timestamp join；
- `est.tum` decimal timestamp 无损到 `int64_t ns` 的 grammar、禁止舍入、overflow；
- duplicate/missing/out-of-order/nonfinite/frame/quaternion 与 packet/sample count/shared endpoint；
- 所有 local exclusion/error 的唯一 stable enum，以及 hard/inconclusive mapping/priority；
- runtime hash-before-parse 与四文件之外任何 path/open 的拒绝合同。

### 3.2 Solver/Jacobian/rank/uncertainty

- residual stack order、weights/whitening (W)、rank matrix (J)，明确 no robust loss；
- optimizer/library/version/all parameters、authoritative init、additive bias update；
- termination/iteration、no fallback/restart/clamp、nonconvergence classification；
- rank evaluation point/matrix，SVD threshold
  `epsilon * diagSize * sigma_max`，其中 Eigen 3.4 默认的
  `diagSize = min(rows,cols) = 3`，condition descriptive；
- covariance/df、finite checks、deterministic ordering/threading/locale/floating contract；
- analytic Jacobian 与独立 central finite difference step/norm/absolute-relative tolerance；
- outcome 外 3 个 full-fit bias uncertainty budgets。

### 3.3 Sole primary、12 equivalence、adjacent gate 与 exact inference

primary sample 是完整 1 s block 的 `d_k [rad^2]`。须冻结 HAC autocovariance/normalization、
Bartlett weights、small-sample correction、`L=floor(4*(n/100)^(2/9))`、Normal/t、df、negative
variance/small-n、gap calendar-lag/run 与 sensitivity rule。

12 项结构候选：3 half-bias differences、3 validation residual means、3 normalized-time slopes、
3 centered-speed slopes。half covariance 未定；validation 建议联合回归
`r_axis=beta0+beta_t*x_t+beta_s*x_s+eps`，但 time/speed source/formula/center/scale、OLS/weights、
design rank、covariance、distribution/df 均须冻结。sample unit 是完整 1 s block。

equivalence 固定 allocation：`alpha_E=0.025`，`alpha_j=alpha_E/12`；每项 TOST 两个
one-sided tests 各使用 `alpha_j`，CI coverage `1-2*alpha_j`，并严格位于 margin 内。critical
distribution/df/covariance 仍待冻结。

adjacent paired observations 构成另一个 mandatory supporting scientific gate，不是第二 primary，
也不加入上述 12 项 family。必须冻结其 exact estimand/aggregation、packet-level
autocorrelation/normalization/small-sample、segment 与 calendar-gap/run 处理、alpha/multiplicity
以及如何与 sole primary/12 项 family 共存、outcome 外 practical margin/effect、严格
`>`/`<`/equality/nonfinite boundary 与 sensitivity。现有 family allocation 不自动给 adjacent
分配 alpha，旧 adjacent residual/RMSE hints 不自动成为 threshold。

### 3.4 Prospective support 与 outcome 外 budgets

- prefix-only primary `d`-like series definition 与 long-run variance；
- outcome 外 primary design alternative rad²、`delta_loss`、target power；
- sample-size/power equation、ceil/overflow/infeasible；不得以已知 support cap requirement；
- 12 equivalence precision/power rules 与 design alternatives；
- adjacent gate 的 prefix-only prospective variance/support/power、design alternative 与 required
  packet/run/segment support；不得把同一 packets 的 adjacent/1 s 两路重复计为独立 support；
- outcome 外 3 half-bias、3 residual-mean、3 time-slope、3 speed-slope margins，以及 adjacent
  practical margin/effect 与 design alternative。

缺 prerequisite/required support 为 `INCONCLUSIVE`；support/前置充分后任一 sole primary、12
equivalence 或 adjacent scientific gate 失败为 `HYPOTHESIS_FAIL`；identity/schema/integrity/
computation/publish 为 `HARD_ERROR`；三类科学门全部按冻结 protocol 实际执行并通过才 `PASS`。
未冻结、未实现或未执行 adjacent gate 时任何情况下不得 `PASS`，但不能冒充 adjacent
hypothesis 已失败。优先级固定为 hard → inconclusive → hypothesis fail → pass。Q5 `0.001 rad`
不能跨维度推导任何 budget。
