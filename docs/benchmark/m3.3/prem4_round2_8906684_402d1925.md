## 4. 核心机制：re-anchor 对齐税（所有变体统一）

匹配层与播种层全清扫后，机制归纳：

1. **匹配质量不是瓶颈**：变体 4/5/6 的段内加权 RMS（0.538-0.841）全部
   ≤ baseline（0.889），零均值启动段 ATE 0.517 vs baseline 1.245。
   暗帧"多产出的匹配"质量是够的（零均值无饱和裁剪，优于 ③ 的全局 add）。
2. **覆盖率提升 = re-anchor 数量提升**：暗帧能播种 → 段数 10 → 30-68。
   每个新段只带自身观测、锚误差无法被全局修正 → 段错位贡献
   +2.739 → +3.9~+5.6m，与 ATE 退化成比例。
3. **对齐税与 re-anchor 数量/门槛无单调关系**：39 次 → +4.106m，
   30 次（seed 门 20）→ +4.677m —— 提高门槛只是把 re-anchor 换成了
   更晚更远的锚（错位更大）。CV 外推锚也不是主犯：关掉 CV（变体 5）
   段内更好（0.538）但锚错位更大（+5.121）。
4. **baseline 的 10-obs 单帧门是质量门**：只放行足以滋养健康段的富帧，
   暗帧的 10-15 obs（零均值/③ 解锁后）滋养出的段 1-3 帧即死。

结论：**在纯 VO 架构内（无 IMU、无全局约束），覆盖率的代价是 re-anchor
对齐税，该税无法在匹配/播种层消除** —— 与 Census 否决同构：一切"让暗帧
工作起来"的干预都从 re-anchor 门放行短命段，而段错位正是 ATE 主犯
（B2 已量化 75%/84.5%）。

## 7. 残存与 M4 指引

- **首段专用累积**（Exp E，变体 7，已否决）：唯一未触碰 re-anchor 门的
  变体 —— 只把 V2_03 首段饿死期缩短（rejected 913 → 904，覆盖 0.758 →
  0.766），但多出 1 次 re-anchor（9 → 10），段错位 +2.862 > +2.739，
  ATE 3.642 仍微劣于门。结论：**首段饿死不是 V2_03 的绑定约束** ——
  覆盖缺口只是"症状"，re-anchor 设计本身才是。代码保留在
  `--estimator-enable-accumulated-seed` 后供 M4 复测。
- **M4 结构性修复方向**（本轮数据强化了全部三条）：
  1. IMU 预积分先验 → re-anchor 锚来自 IMU 外推（消除 CV 锚错位），
     段间错位税结构性消失；
  2. 关键帧 + 全局 covisibility 约束（VINS 式）→ 段不再"只带自身观测"；
  3. 若 M4 前仍要做纯 VO：锚质量门（新段跟踪 N 帧验证后才提交锚）——
     但本轮数据表明对齐税与门槛无单调关系，优先级低于 M4。
- 覆盖 0.758 缺口（913 帧）是数据侧已知限制（cam1 暗 + cam0 缺帧）；
  匹配层证明可以解锁覆盖（0.975），但纯 VO 架构下解锁覆盖的代价是
  对齐税 —— 决策权在 M4。
